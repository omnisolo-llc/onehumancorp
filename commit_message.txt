Title: 🛡️ Sentinel: [Hybrid Security Fix] Prevent Local File Traversal in Blob Storage

Description:
Severity: High
Vulnerability: Path Traversal in LocalProvider
Impact: In Standalone Mode, `getLocalPath` in `srcs/server/storage/local_provider.go` stripped leading slashes but remained vulnerable to absolute paths (e.g., `C:\Windows\...` or `/etc/passwd`) passed directly, bypassing directory isolation boundaries and potentially exposing the host file system.
Fix Details:
- Updated `getLocalPath` signature to return an `error`.
- Hardened validation using `filepath.IsAbs` to explicitly reject absolute paths.
- Enforced strict bounding check using `filepath.Join` and `strings.HasPrefix(cleanPath, basePath + string(filepath.Separator))`.
- Updated all callers in `ListBlobs`, `ReadBlobMetadata`, and `GetBlobURL` to handle the new return signature appropriately.
