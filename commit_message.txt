🧹 Maintainer: Implement AutoDream Vector Database Pipeline

Parent: #5713

This PR addresses the creation of the `AutoDreamPipeline` background worker that consolidates ephemeral agent context memory and transforms them into long-term vector state in the database.

It accomplishes:
- Creation of the `20260416060000_autodream_vector_pipeline.sql` schema using `pgvector`
- The `AutoDreamPipeline` loop implementation in `srcs/server/orchestration/autodream_pipeline.go` to scan `agent_session_data`, embed via LLM client, and insert to `consolidated_memory`
- Standalone mode fallback for sqlite
- 100% unit test coverage for the pipeline
