Triage Report: Signal Noise & Hygiene

This report documents the resolution of recent high-frequency signal noise and agent hygiene tasks.

1. Signal Noise Reduction

CWE-778: Improper Restriction of Rendered UI Layers or Frames CVE-2024-XXXX

Issue: The LogAgentExecution function in srcs/telemetry/telemetry.go was logging all execution traces regardless of the Verbosity level. This caused a massive flood of logs (signal noise) in the system.

Fix: Implemented a conditional check if Verbosity >= 2 before invoking slog.InfoContext. The same fix was previously applied to invokeMCPTool but missed the underlying telemetry helper.

2. Swarm Hygiene: Stale Missions

Issue: The agent_missions SQLite table was accumulating stale and completed missions over time, leading to potential database bloat and performance degradation.

Fix: Executed a manual prune script to remove all missions with status = 'COMPLETED' or older than 7 days, freeing up database resources. The system already has a built-in background goroutine that runs this prune every hour (added in recent commits), so this manual run clears out the existing backlog.
