# Site publication contract gate

Compiles the complete maintained publication store and builder database module with real common tenant binding. Tests require an explicit disposable PostgreSQL database, canonical table statements, and a real restricted LOGIN with forced RLS. No provider, payment, DNS, CDN deployment or public customer publication is performed.

This first stage certifies the atomic receipt/snapshot store only. Actual worker rendering, mounted HTTP/public delivery and browser acceptance remain later gates in the reviewed publication plan. Source fingerprints and root-lock dependency equivalence are mandatory.
