# Agent Service Go Package

The Go package at import path `github.com/onehumancorp/mono/srcs/proto/agentservice`
is generated by Bazel from `srcs/proto/agent_service.proto`.

Do not check in generated `*.pb.go` files here.

Use `//srcs/proto:agent_service_go_proto` as the source of truth.

`agent_service.proto` now carries both the gRPC control plane and the proto-
first runtime configuration messages used to launch the standalone C++ builtin
agent daemon.

This keeps generated protobuf code out of source control, but it also means
plain `go test` and non-Bazel-aware editor tooling will not see the generated
types unless they understand Bazel outputs.
