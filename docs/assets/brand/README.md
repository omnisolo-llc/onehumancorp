# OmniSolo identity

Selected design: **A — Human first**, approved by the user on 2026-09-15. The primary assets below now use this design. Earlier concepts remain in `original/` and `refinements/`.

The symbol expresses **one human coordinating a company of agents**.

See the [complete brand explanation and usage guide](../../brand/identity.md), including the Omni/Solo meaning, Plan–Act–Learn story, and implied triangle.

- **Central person:** the solo owner and human decision maker.
- **O-shaped orbit:** OmniSolo and the shared workflow connecting business operations.
- **Three satellite nodes:** the AI agent team, expressed through **Plan** (research and organize), **Act** (execute through tools), and **Learn** (retain context to inform future work). These are symbolic roles, not a count of agents or a fixed architecture mapping.
- **Blue:** the existing interface accent, `#0066FF`. Teal distinguishes the agents.

The three agent nodes are spaced 120 degrees apart. Their positions imply a triangle, but no triangle is drawn and it carries no separate brand meaning. The intended reading is a person within an O-shaped orbit.

## Assets

- `omnisolo-icon.svg`: blue rounded app tile, white person and orbit, mint nodes.
- `omnisolo-mark.svg`: transparent blue/teal symbol for light backgrounds.
- `omnisolo-mark-mono.svg`: transparent single-color symbol using `currentColor`. Inline it to inherit CSS color; when loaded through an image element, it defaults to black.

- `omnisolo-logo.svg`: selected icon with the OmniSolo name and “Empowering your solo success.” slogan. This lockup uses system fonts, so lettering can vary by device.

All icon and mark SVGs use a 64-unit viewBox, vector geometry, accessible titles/descriptions, and no fonts, scripts, or external resources. Prefer 32 px or larger for the full symbol; check the 16 px rendering for favicon use. Preserve the surrounding space and aspect ratio. For a white mark on dark backgrounds, inline the monochrome SVG with `color: white`.

These are design assets. Existing application and installer icons have not been replaced.
