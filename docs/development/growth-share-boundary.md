# Configured growth sharing boundary

The customer-referral editor has a real Rust `/api/v1/growth/customer-referral/embed` route, but its preview previously invented `/ref/<first six tenant characters>` without a customer-specific referral receipt. That placeholder is removed and preview Copy/social actions are visibly unavailable. Configured amounts and the actual embed remain. Embed copying uses the shared clipboard feedback hook and acknowledges actual completion. The parameter is `hide_branding`, matching `CustomerReferralEmbedQuery`; the server's existing exact-Pro database decision is unchanged.

The share-to-unlock generator has an actual Next `/unlock` preview destination. Its social controls now request an X/WhatsApp draft for that encoded preview, without claiming that a post was sent or a reward was unlocked. Both the generator and destination preserve all opaque query values, including tenant and theme. Clipboard feedback waits for the platform and retires stale completions. The default message and nearby instructions no longer claim an unlock that never happened.

A code in this preview is carried in the URL and is not secret or access-controlled. There is still no share-verification, customer-specific referral attribution, reward eligibility or automatic redemption workflow here. Configured tenant values come from display settings and are not authentication proof. Existing plan-hook owner lifetime and public embed policy are separate boundaries; this change does not grant plans, credits, referrals, rewards or tracking counts. Other public embed wording remains outside these three editor/destination files.

Focused DOM tests exercise real components and the shared clipboard hook with recorded platform boundaries. They cover actual configured URL round-trips, correct Rust query spelling, pending/rejected/stale clipboard results, and absence of invented customer links or enabled unsupported actions. The Playwright flow reads the real clipboard and visits that exact local preview while retaining locked/unavailable assertions. Actual hosted browser execution remains pending.
