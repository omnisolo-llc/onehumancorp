# SQLite Encryption Standards

## 1. Scope
Defines the cryptographic standards for all local SQLite databases utilized in OHC Standalone installations.

## 2. Standards
* **Cipher**: AES-256 in CBC mode (default for SQLCipher).
* **Key Derivation**: PBKDF2-HMAC-SHA512.
* **Page Size**: 4096 bytes minimum.

## 3. Key Management
* The Master Key (`OHC_SQLITE_KEY`) must be generated securely upon first application launch using a cryptographically secure pseudo-random number generator (CSPRNG).
* The Master Key must be securely stored in the host operating system's native secure enclave or credential manager (e.g., macOS Keychain, Windows Credential Locker).
* The application must never log the `OHC_SQLITE_KEY` to disk.

## 4. Secure Erase
* `PRAGMA secure_delete = ON` must be enforced. This ensures deleted content is overwritten with zeros, preventing forensic recovery of deleted records.

## 5. Enforcement
* Initialization routines must strictly enforce these PRAGMAs before executing any schema creations or migrations.
