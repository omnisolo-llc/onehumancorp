# Observability and Security Metrics

## 1. Metrics Gathering
Prometheus and OpenTelemetry capture internal metrics to identify security incidents and performance bottlenecks.

## 2. Key Security Metrics
* `auth.failure_rate`: Spikes indicate potential brute-force or credential stuffing attacks.
* `db.lock_contention`: Monitored to ensure `SKIP LOCKED` queries are functioning correctly.
* `tenant.cross_access_denials`: Counts instances where RLS policies explicitly blocked a query. A non-zero value indicates a severe application bug or active exploit attempt.

## 3. PII Redaction
* Telemetry pipelines automatically redact Personally Identifiable Information (PII) before logging.
* Passwords, tokens, and user inputs are masked.

## 4. Standalone Metrics
* Standalone telemetry is strictly opt-in.
* If opted-out, the local wrapper disables all external metric transmission, operating completely offline.

## 5. Alerting
* Alerts are routed to the Sentinel team (L7) if critical security thresholds are breached.
