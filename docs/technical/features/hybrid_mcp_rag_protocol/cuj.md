# Hybrid MCP RAG Protocol: Bridging Standalone to Cloud

## Critical User Journeys (CUJ)

1. **System Startup:** Operator spins up the OHC cluster with KAIROS layer in Hybrid Mode.
2. **Local Memory Generation:** Standalone agent generates a new episodic memory and stores it in the local SQLite DB.
3. **Background Sync:** The Sync Daemon detects new un-synced memories and upserts them to the Cloud Orchestration engine (PostgreSQL).
4. **Cloud Retrieval:** A different cloud-based agent queries the global pgvector index to retrieve the insight generated by the standalone agent.
