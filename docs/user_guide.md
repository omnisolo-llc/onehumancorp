# OHC User Guide

## Dashboard
The dashboard is the main entry point to OHC. From here, you can manage your business, view active agents, and check your inbox.

## Setup Wizard
The setup wizard helps you build your online storefront, storing data securely in the Real Database Data.

## UI Styling
The OHC UI utilizes modern design tokens, including:
- Typography: Outfit (headings) + Inter (body)
- Touch Targets: 44x44px minimum bounds
- Glassmorphism: backdrop-filter blur(20px) saturate(200%)

## Features
Ensure your business uses these features directly inside the application rather than dealing with the deprecated Setup Wizard (Mocked) workflows.
