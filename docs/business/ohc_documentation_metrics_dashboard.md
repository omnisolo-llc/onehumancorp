# OHC Documentation Metrics Dashboard

To ensure our documentation remains effective, we need a centralized view of key performance indicators (KPIs). This document outlines the proposed metrics for the OHC Documentation Dashboard.

## 1. Primary KPIs

These metrics indicate the overall health and effectiveness of the Help Center.

*   **Self-Service Success Rate (SSSR)**: The percentage of Help Center sessions that *do not* result in a support ticket creation within 24 hours. (Target: >85%)
*   **AI Agent Resolution Rate**: The percentage of AI chat interactions where the user explicitly indicates satisfaction (e.g., thumb-up) or implicitly indicates resolution (e.g., closes chat and resumes work without escalating).
*   **Time to First Value (TTFV) - Guided vs. Unguided**: Compare the average time it takes a new user to complete key setup tasks (e.g., add first product) for users who engage with Walkthroughs versus those who skip them.

## 2. Content Quality Metrics

These metrics help us identify specific articles that need improvement.

*   **Article View Count**: Which articles are most popular? High view counts indicate areas where the UI might be confusing and could benefit from better proactive design.
*   **Feedback Score**: The ratio of positive to negative feedback on individual articles.
*   **Bounce Rate**: The percentage of users who open an article and immediately close the Help Center, suggesting the content was not what they expected based on the title or search result.

## 3. Search Effectiveness Metrics

These metrics evaluate the search functionality.

*   **Top Search Queries**: What are users searching for most often?
*   **Zero-Result Search Rate**: The percentage of searches that return no articles. (Target: <5%)
*   **Search Refinement Rate**: How often users have to modify their search query to find what they need. A high rate indicates poor fuzzy matching or confusing article titles.

## 4. Technical Performance Metrics

These metrics ensure the Help Center is fast and reliable.

*   **Help Center Load Time**: The time it takes for the Help Center overlay to become interactive. (Target: <200ms)
*   **Search Latency**: The time it takes to return search results. (Target: <100ms)
*   **Video Playback Error Rate**: The percentage of video tutorial views that encounter playback errors.
