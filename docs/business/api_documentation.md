# API Documentation

> **Note**: This section is hidden behind the Advanced Mode toggle.

## OpenAPI Integration
The OHC API reference is powered by an OpenAPI specification and rendered natively using Swagger UI components embedded within the Tauri shell.

### Accessing the API
Users can generate API Keys via Settings -> Advanced -> API Keys.
The API base URL for Cloud mode is `https://api.onehumancorp.com/v1/`.
