# Transaction Fee Optimization Report

By routing high-value transactions (>$500) through ACH (`us_bank_account`) instead of standard credit card processing, we significantly reduce transaction fees.

- **Standard Credit Card Fee**: 2.9% + 30¢
- **ACH Fee**: 0.8% (capped at $5.00)

**Cost Savings Example**:
On a $1,000 transaction:
- Credit Card: $29.00 + 0.30 = $29.30
- ACH: $1000 * 0.8% = $8.00 (capped at $5.00) -> $5.00
- **Total Savings**: $24.30 per high-value transaction.
