# Interactive Walkthroughs Definition

## 1. Store Setup Walkthrough
- **Trigger**: First-time login.
- **Steps**:
  1. Welcome: "Let's set up your store in 3 easy steps."
  2. Select Theme: "Choose how your website looks to your customers."
  3. Add Product: "Add your first product so people can start buying."
  4. Connect Bank: "Link your bank so you can get paid directly."

## 2. Agent Activation Walkthrough
- **Trigger**: Navigating to AI Agents tab for the first time.
- **Steps**:
  1. Welcome: "Meet your AI team."
  2. Select Agent: "Choose a Marketing or Support agent to hire."
  3. Grant Permissions: "Tell your agent what it is allowed to do."
  4. Launch: "Your agent is now working in the background!"

## 3. Accept Your First Payment Walkthrough
- **Trigger**: Navigating to the Payments tab.
- **Steps**:
  1. Welcome: "Get ready to accept money from customers."
  2. Choose Method: "Select if you want to be paid online or in person."
  3. Link Account: "Connect your bank account securely."
  4. Success: "You're all set to get paid!"
