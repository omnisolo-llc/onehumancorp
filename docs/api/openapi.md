# OHC Advanced API Reference

> **Note:** This section is for Advanced Users (like computer programmers) who want to connect other computer systems directly to One Human Corp. If you are just running your store normally, you do not need to read this page!

If you are a developer building custom checkouts or syncing inventory, welcome.

## Authentication
All API endpoints require a Bearer token in the Authorization header.
Tokens can be generated in Settings > Advanced > Developer APIs.

## Endpoints

### `GET /api/v1/products`
Returns a cursor-paginated list of products for the authenticated tenant.

**Response:**
```json
{
  "data": [
    {
      "id": "prod_123",
      "name": "Artisan Bread",
      "price": 500,
      "currency": "USD"
    }
  ],
  "next_cursor": "cXdlcnR5"
}
```

### `POST /api/v1/payments/intent`
Creates a new payment intent. Must be idempotent.

**Request:**
```json
{
  "amount": 500,
  "currency": "USD",
  "idempotency_key": "unique_id_here"
}
```
