# Hybrid MCP RAG Protocol

This document provides documentation for the Hybrid MCP RAG Protocol, which bridges Standalone SQLite databases to Cloud PostgreSQL databases for seamless agentic context synchronization.

## Objective
To allow users the choice of offline execution (SQLite) or cloud-native execution (PostgreSQL) without losing contextual RAG capabilities.
