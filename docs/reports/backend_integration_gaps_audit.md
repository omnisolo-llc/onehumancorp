# Backend Integration Gaps Audit Report\n\n## Findings\n\n1. **/api/v1/supply-chain/low-stock/route.ts returns mock data**\n   The Next.js backend route `/api/v1/supply-chain/low-stock` currently returns a hardcoded list of low stock materials, rather than querying the actual PostgreSQL database or making a gRPC call to the `supply_chain` service implemented in the Rust backend.\n\n2. **Missing HTTP Routes in Rust Server**\n   Although there is a gRPC service `SupplyChainService` in `src/server/api/supply_chain.rs`, the corresponding HTTP routes (e.g. via axum routing) do not seem to be explicitly mounted under `/api/v1/supply-chain` in `src/server/lib.rs`. This creates a gap where the frontend relies on Next.js mock API routes instead of the true backend.\n\n## Recommendation\n\nThe Next.js mock routes for supply chain should be removed and the requests from the UI should be fulfilled by the Rust server by mounting the `SupplyChainService` HTTP endpoints.\n\n
