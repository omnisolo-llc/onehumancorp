# [Feature] The Silent Ambassador (Proactive Customer Success Agent)

## Problem Statement
Solopreneurs like Maya (baker) and Carlos (handyman) lose up to 30% of their potential sales due to slow response times in direct messages and emails. They are too busy fulfilling orders or providing services to answer repetitive questions, but current AI tools require manual prompting, which is just as time-consuming.

## Research Report
- **Finding:** App Store reviews for competing platforms (Shopify, Wix) highlight that managing customer communications across multiple channels is a massive pain point.
- **Source:** Reddit r/smallbusiness shows users complaining about missing leads on Instagram because they were on a job.
- **Comparison:** Shopify Sidekick requires the user to ask it a question. It is reactive. OHC needs a proactive teammate.

## Design Doc
- **High-Level Architecture:**
  - **Entity Types:** `CustomerMessage`, `DraftReply`, `ApprovalEvent`.
  - **Key Relationships:** `CustomerMessage` belongs to a `Tenant`. `DraftReply` is generated by the AI Agent and linked to a `CustomerMessage`.
  - **Integration Points:** Event mesh listens for incoming messages. Agent reads business memory (FAQs, past interactions).
- **UI Wireframes/Screen Flow:**
  - **Mobile UX (375px first):**
    1. Push notification: "Draft reply ready for Carlos."
    2. Tap notification -> Opens OHC app to the Action Feed.
    3. Feed shows incoming message and AI-drafted reply.
    4. Two big buttons: [Approve & Send] [Edit].
- **AI Agent Integration:** Agent is triggered autonomously via pub/sub when a new message arrives.

## Implementation Prompt
**User-Facing Outcome:** The user receives a notification with a perfectly drafted response to a customer inquiry. With one tap, the message is sent. The business owner never has to type "Yes, we are open until 5 PM" again.
**Critical User Journey:**
1. Customer sends message on Instagram or Website.
2. OHC AI drafts response based on business context.
3. Owner receives 1-tap approval notification.
4. Owner approves, response is sent instantly.
**Acceptance Criteria:**
- Agent must trigger automatically without a user prompt.
- UI must allow 1-tap approval or manual editing.
- Response must use contextual business memory.
