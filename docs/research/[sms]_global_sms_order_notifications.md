# Global SMS Order Notifications

**Priority:** P0
**Estimated Scope:** Small

## Problem Statement
Many customers, especially in emerging markets or non-technical demographics, do not check email reliably. They need order confirmations and appointment reminders via text message.

## Research Report
### Evaluated Tools
- **Twilio:** The industry standard. Huge global reach, reliable, but slightly expensive.
- **MessageBird / Vonage:** Good alternatives, often slightly cheaper internationally.

### Recommendation
Use Twilio for reliability and ease of integration. We will need to manage opt-ins carefully to comply with local regulations (e.g., A2P 10DLC in the US).

### Pricing Estimate
Roughly $0.01 - $0.05 per message depending on the destination country.

### Cloud vs. Standalone
- **Cloud:** Easy API integration.
- **Standalone:** Easy API integration.

## Design Doc
### Integration Flow
1. User enables 'SMS Notifications' in Settings.
2. When an order is placed or an appointment is 24 hours away, OHC triggers a Twilio API call.
3. Customer receives a plain-text SMS with key details.
4. (Optional) Allow business owners to send custom broadcast SMS to opted-in customers.

## Implementation Prompt
Implement automatic SMS notifications. When a customer books an appointment or places an order, they should receive a text message confirmation. Also, send a reminder text 24 hours before any scheduled appointments. Keep the messages short and clear.
