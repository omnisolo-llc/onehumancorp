# Automated Booking and Calendar Sync

**Problem Statement**: Manual back-and-forth scheduling wastes time and leads to double bookings.

**Research Report**: Google Calendar and Outlook APIs are standard. Tools like Calendly dominate but charge per user. Integrating direct calendar sync allows custom booking pages without extra subscriptions. Works well in both Cloud and Standalone (with custom API keys).

**Design Doc**: Connect Google/Outlook account. Set availability rules. Shareable booking link that auto-creates calendar events.

**Implementation Prompt**: Create a booking page feature that syncs with Google Calendar to prevent double booking and allows clients to self-schedule.

**Priority**: P1
**Estimated Scope**: Medium
