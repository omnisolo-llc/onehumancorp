**Title**: Proactive AI Action Feed Dashboard (The "Teammate" UI)

**Problem Statement**:
Small business owners like Carlos (Handyman) and Priya (Boutique) are overwhelmed by standard SaaS dashboards. They don't want to navigate menus to check inventory, draft emails, or analyze data. They want to be told what needs their attention and resolve it in seconds. Current tools treat AI as a reactive chatbot (e.g., Shopify Sidekick) or a one-time builder (Durable). Users suffer from "Operational Fatigue" (Top 10 SMB Pain Point #2).

**Research Report**:
*   **Competitor Gap**: Shopify requires navigating to specific apps. Wix is complex. Durable has a CRM but relies on the user to initiate actions.
*   **Pain Point Data**: 68% of SMBs report "Operational Fatigue" (managing multiple apps/inboxes).
*   **OHC Differentiation**: The "Teammate" philosophy. Agents proactively monitor the event mesh (e.g., NATS) and queue up suggested actions.
*   **Source Data**: *ohc_ai_differentiation_manifesto.md*, *smb_pain_points_top_10.md*.

**Design Doc**:
*   **Architecture (High Level)**:
    *   `Event Source`: NATS hybrid event mesh triggers autonomous agents.
    *   `Agent Backend`: Agents (e.g., The Ambassador, The Vigilant Manager) process events (e.g., "new DM received", "inventory low").
    *   `Database`: Agents write proposed actions to an `agent_missions` or `action_feed` table with a `status` (pending, approved, rejected).
    *   `Frontend`: A mobile-first, TikTok-style vertical feed of "Action Cards".
*   **UI/UX Flow (Mobile 375px)**:
    1.  User opens app -> Lands directly on the "Action Feed" (Home).
    2.  Card 1: "Draft Reply: Maya asked about vegan cakes." -> Shows AI drafted response. Buttons: [Approve & Send] [Edit] [Dismiss].
    3.  Card 2: "Low Stock Alert: Sourdough Bread (2 left)." -> Button: [Mark Sold Out] [Order More].
    4.  Card 3: "Marketing: New product added. Post to Instagram?" -> Shows generated image/caption. Button: [Publish].
    5.  User swipes or taps to clear the feed. "Inbox Zero" feeling.

**Implementation Prompt**:
Implement a unified, mobile-first "Action Feed" dashboard. This is the primary interface for the user post-onboarding. It should consume proposed actions generated by backend AI agents and present them as simple, one-tap approval cards. The CUJ is: User logs in, sees 3 pending AI tasks, taps "Approve" on two, "Dismisses" one, and reaches an empty, satisfying "All caught up!" screen in under 30 seconds.
