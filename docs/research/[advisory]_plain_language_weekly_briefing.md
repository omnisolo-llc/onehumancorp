# [Advisory] Plain-Language Weekly Business Briefing (The Business Advisor)

## Title
Implement the "Business Advisor" Agent for Plain-Language Financial Insights

## Problem Statement
Small business owners frequently experience "Financial Fog" (Ranked #9 in Top 10 SMB Pain Points). Analytics dashboards on existing platforms are modeled after Google Analytics—filled with complex line charts, funnel drop-offs, and jargon like "conversion rate" or "bounce rate." Non-technical founders (like Fatima the Food Cart Operator) struggle to extract actionable meaning from these charts. They need someone to simply tell them: "What happened this week, and what should I do next?"

## Research Report
*   **Competitor Landscape:** Shopify and Wix offer robust, traditional analytics dashboards. They are desktop-optimized and visually dense. GoDaddy offers simplified metrics but lacks deep analysis.
*   **User Evidence:** Users state, "I just want to know if I'm making money or losing money without exporting a CSV." And, "The charts look nice but I don't know what they mean."
*   **OHC Differentiation:** OHC replaces the default complex chart dashboard with a human-readable, plain-language briefing generated by the Business Advisor Agent. It synthesizes revenue, inventory, and marketing data into a short, actionable narrative delivered weekly.

## Design Doc
*   **Core Entities:** `WeeklyMetrics`, `AdvisoryBriefing`.
*   **Key Relationships:** A scheduled cron job (via the Hybrid Task Scheduler) triggers the Advisory Agent weekly. The Agent aggregates data from Orders, Marketing, and Inventory, passes it to the LLM for synthesis, and generates an `AdvisoryBriefing`.
*   **Integration Points:**
    *   **Trigger:** Scheduled cron task (e.g., every Sunday at 8:00 AM).
    *   **Logic:** The agent pulls 7-day metric rollups. The prompt instructs the LLM to write a friendly, concise summary with 1-2 recommended actions.
    *   **Output:** Generates a Briefing object that is displayed prominently on the mobile dashboard and sent via Push Notification.
*   **UI/UX Flow (Mobile-First, 375px):**
    1.  User wakes up on Sunday and sees a push notification: "Your Weekly Business Briefing is ready."
    2.  User taps it and opens the app to an "Instagram Story" style full-screen view.
    3.  Screen 1: "Great job! You made $1,450 this week (up 12% from last week)." (Large text, clean typography).
    4.  Screen 2: "Your best seller was the Vegan Chocolate Cake. Tuesday was your busiest day."
    5.  Screen 3: "Action Step: You have 5 abandoned carts. Tap here to send them a 10% discount code."
    6.  User taps the button, which seamlessly transitions them to the Marketing Agent's recovery flow.

## Implementation Prompt
Build the data aggregation pipeline, the LLM synthesis prompt, and the Story-style UI for the Weekly Briefing.
1.  Implement the backend cron worker to aggregate weekly revenue, top-selling products, and marketing engagement metrics.
2.  Design the LLM prompt to ingest this JSON data and output a structured, plain-language narrative. Enforce a strict "No Jargon" constraint in the prompt.
3.  Design the data model to persist the `AdvisoryBriefing` so the user can review past weeks.
4.  Develop the frontend UI using a full-screen, tap-to-advance "Story" pattern. Ensure the final screen includes a dynamic, actionable deep-link button (e.g., "Recover Carts", "Restock Items", "Create Promo").
