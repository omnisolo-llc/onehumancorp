# Automated Booking and Calendar Sync

**Priority:** P1
**Estimated Scope:** Medium

## Problem Statement
Service-based business owners (like barbers, consultants, or tutors) waste hours emailing back and forth to find meeting times. Double-booking is a constant risk if they use multiple calendars.

## Research Report
### Evaluated Tools
- **Google Calendar API:** The gold standard for personal and business use. Essential for conflict resolution.
- **Cal.com / Calendly:** Powerful scheduling engines, but we can build a simpler, native version within OHC to keep users in our ecosystem.

### Recommendation
Build a native booking page within OHC that syncs two-way with Google Calendar. This avoids third-party subscription costs for the user.

### Pricing Estimate
Google Calendar API is free for standard usage limits.

### Cloud vs. Standalone
- **Cloud:** Seamless OAuth and real-time webhook sync.
- **Standalone:** OAuth requires a local callback handler; sync may rely on periodic polling.

## Design Doc
### Integration Flow
1. User connects their Google Calendar via Settings.
2. User sets their working hours and service durations.
3. OHC generates a public booking link (e.g., `onehumancorp.com/book/acme-corp`).
4. Customers visit the link, see available slots (filtered by Google Calendar conflicts), and book.
5. OHC creates the event in Google Calendar and notifies the business owner.

## Implementation Prompt
Implement a feature allowing users to connect their Google Calendar. Create a public-facing booking page where their customers can select a time slot for a service. The available slots must automatically exclude times where the user is already busy on Google Calendar. When a booking is made, it should appear in OHC and sync to the connected Google Calendar.
