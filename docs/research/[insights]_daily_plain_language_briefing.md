# [insights]_daily_plain_language_briefing

## Title
Daily Plain-Language Business Briefing

## Problem Statement
Traditional analytics dashboards (charts, graphs, conversion rates) are intimidating for users like Fatima or Leo. They don't want to analyze data; they want to be told what is happening and what to do next.

## Research Report
- **Competitor Analysis:** Shopify Analytics is comprehensive but requires interpretation. GoDaddy provides basic traffic numbers. Neither tells the user *what action to take*.
- **User Pain Points:** High cognitive load trying to understand if the business is healthy. Users ignore analytics tabs entirely.
- **Source:** Behavioral analytics showing low engagement with traditional dashboard pages among micro-SMBs.

## Design Doc
- **Core Entities:** `DailyMetricSnapshot`, `AIBriefingInsight`.
- **Architecture Flow:**
  1. Nightly batch job aggregates sales, traffic, and inventory data (`DailyMetricSnapshot`).
  2. LLM analyzes the delta against historical trends.
  3. LLM generates 3 concise, plain-language bullet points (`AIBriefingInsight`), e.g., "You had 10 abandoned carts yesterday. I've drafted recovery emails for them."
  4. Briefing is delivered via push notification or SMS each morning.
- **Mobile UX Flow:** A "Story" style interface (similar to Instagram Stories) that users tap through to review their daily update, ending with actionable buttons.
- **AI Integration:** Data-to-text generation using strict prompting to ensure optimistic, actionable, and jargon-free language.

## Implementation Prompt
Implement the Daily Plain-Language Briefing feature. Replace complex chart-based dashboards with a feed of actionable, text-based insights generated by AI. The Critical User Journey involves the user receiving their morning briefing, reading 3 synthesized points about their business health, and executing at least one recommended action directly from the briefing card. Acceptance criteria: The underlying logic must successfully translate raw numeric metrics (sales, views) into human-readable advice without using technical marketing terms.

## Priority
P2

## Estimated Scope
Medium
