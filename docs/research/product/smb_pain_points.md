# Top SMB Pain Points

Based on analysis of r/smallbusiness, r/ecommerce, Trustpilot, and App Store reviews.

1.  **"I don't know how to build a website."**
    *   *Symptom:* Selling entirely through Instagram DMs or WhatsApp. No central catalog.
2.  **"I miss messages because I'm busy."**
    *   *Symptom:* Lost revenue. Customers go to competitors if not answered in 5 minutes.
3.  **"Writing descriptions takes forever."**
    *   *Symptom:* Stale catalog. Owner doesn't add new items because it's too much work.
4.  **"I use too many apps."**
    *   *Symptom:* Chaos. Square for POS, Instagram for marketing, Excel for inventory, WhatsApp for communication.
5.  **"I can't afford a marketer or accountant."**
    *   *Symptom:* Stagnant growth. Disorganized finances.
