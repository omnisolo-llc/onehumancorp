# Automated Shipping Rates and Labels

**Priority:** P2
**Estimated Scope:** Medium

## Problem Statement
Product-based business owners struggle with calculating accurate shipping costs at checkout and manually copying addresses to carrier websites to print labels.

## Research Report
### Evaluated Tools
- **Shippo / EasyPost:** Both offer excellent APIs aggregating multiple carriers (USPS, FedEx, UPS, local carriers).
- **Sendle:** Great for small businesses, focused on carbon-neutral and simpler pricing.

### Recommendation
Integrate with Shippo to provide real-time rates and label generation. It abstracts the complexity of dealing with individual carriers.

### Pricing Estimate
Shippo charges a few cents per label. We can pass this cost on or absorb it.

### Cloud vs. Standalone
- **Cloud:** Full integration possible.
- **Standalone:** Full integration possible as it's outbound API calls.

## Design Doc
### Integration Flow
1. User enters their package dimensions and weight on a product or order.
2. OHC calls Shippo API to get real-time rates to display to the customer.
3. When the order is placed, user clicks 'Generate Label'.
4. OHC purchases the label via Shippo and downloads a PDF for the user to print.
5. Tracking number is automatically emailed to the customer.

## Implementation Prompt
Create a feature for physical product sellers to manage shipping. It should automatically calculate shipping costs during checkout based on the customer's address. After purchase, the business owner should be able to click a single button to generate and print a shipping label, automatically sending tracking info to the buyer.
