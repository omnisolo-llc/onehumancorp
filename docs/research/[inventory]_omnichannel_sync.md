# [Inventory] Omnichannel Sync for Boutiques (Priya)

## Title
Omnichannel Inventory Sync for Boutiques

## Problem Statement
Priya, a 35-year-old boutique owner, wants an online presence but struggles with inventory sync between her physical store and website.

## Research Report
A critical pain point identified in Trustpilot reviews for Square and Shopify is inventory mismatches leading to overselling.

## Design Doc
- **UI Flow:** Single inventory truth dashboard.
- **Architecture:** `Product` inventory counts linked seamlessly across `POS_Transaction` and `Online_Order`.
- **AI Agent Integration:** Predictive low-stock alerts.

## Implementation Prompt
Create a unified inventory management backend that updates in real-time across both POS and online sales channels, alerting the user when stock falls below AI-predicted thresholds.
