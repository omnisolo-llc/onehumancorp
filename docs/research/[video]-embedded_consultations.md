# Embedded Video Consultations

## Problem Statement
Sharing external Zoom links looks unprofessional and forces clients to leave the business's branded experience.

## Research Report
Daily.co and Whereby evaluated. Both allow embedding video calls directly into a web app. Daily.co has more flexible APIs. Works in both modes.

## Design Doc
When an online meeting is booked, generate a Daily.co room link. Embed the room UI directly in the OHC client portal so customers don't need to install anything.

## Implementation Prompt
Integrate embedded video calls for online appointments. Provide a 'Join Meeting' button in the client portal that opens the video call without leaving OHC.
