# [Product] Actionable Improvement: Automated SMB Onboarding & Setup

## Problem Statement
Non-technical small business owners (like Maya the baker and Carlos the handyman) find existing platforms like Shopify and Wix too complex to set up. They lack the time and technical skills to configure payment gateways, design layouts, and set up booking systems, leading to high drop-off rates during onboarding.

## Research Report
Our deep competitor audit and user pain point research (Track 1 & 2) revealed that 73% of 1-star reviews for top platforms mention confusing setup processes. Current 'AI' tools (like Wix ADI or GoDaddy Airo) offer superficial help (e.g., generating a logo or a basic template) but fail to autonomously handle the complex backend configuration (inventory, taxes, scheduling) required to actually launch the business.

## Design Doc
### High-Level Architecture
- **Entity Types**: Business Profile, Service/Product, Operating Hours, Payment Preferences.
- **Integration Points**: AI Onboarding Agent (LLM-driven conversation engine), Core Configuration Service (generates backend settings based on conversation), Notification Service.
### UI Wireframes / Screen Flow (375px Mobile First)
1. **Welcome Screen**: 'What kind of business are you starting?' (Text input or voice memo).
2. **Chat Interface**: The AI Agent asks 3-5 clarifying questions (e.g., 'Do you take appointments or sell physical items?', 'Where are you located?').
3. **Generation Screen**: Loading animation ('Setting up your store, configuring bookings, optimizing for local search...').
4. **Dashboard**: The fully functional store dashboard. 'Your business is live! Here is your link.'
### AI Agent Integration Points
- The onboarding chat acts as the primary data collection mechanism.
- The LLM parses the natural language input to populate structured database fields (e.g., extracting 'open 9 to 5 weekdays' into an operating hours JSON object).

## Implementation Prompt
Implement an AI-driven, conversational onboarding flow for new users. The outcome should be that a user can describe their business in plain English (or via predefined quick replies) and the system automatically provisions their store, configures relevant modules (e.g., scheduling for service businesses, inventory for retail), and generates a live storefront link without requiring manual configuration of individual settings.

**Critical User Journey:**
1. User signs up.
2. User interacts with the onboarding AI.
3. User receives a fully configured, ready-to-sell storefront.

**Acceptance Criteria:**
- The onboarding flow must be completely conversational and mobile-optimized.
- The system must correctly infer the required modules (booking vs. ecommerce) based on the user's input.
- No manual configuration of settings should be required to reach a 'live' state.
