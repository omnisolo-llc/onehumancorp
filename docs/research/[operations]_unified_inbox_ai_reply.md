## Title: Unified Inbox with AI Draft Replies

## Problem Statement
Founders spend hours every week answering repetitive questions across multiple apps.

## Research Report
- Users lose track of cross-platform conversations.

## Design Doc
### High-Level Architecture
- **Entity Types**: `Conversation`, `Message`.
- **UI Screen Flow**: Main Inbox -> Chat Thread -> AI Suggestion Chip.
- **AI Agent Integration**: `SupportAgent` generates draft responses based on inventory.

## Implementation Prompt
Implement the Unified Inbox data models and UI. Ensure the UI enforces strict motion constraints.

P1
