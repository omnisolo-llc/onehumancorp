# Unified Unified Inbox for Social Channels

**Priority:** P0
**Estimated Scope:** Large

## Problem Statement
Small business owners often miss customer inquiries because they are spread across Instagram DMs, Facebook comments, TikTok, and WhatsApp. Constantly switching apps is overwhelming and leads to lost sales.

## Research Report
### Evaluated Tools
- **Meta Graph API (Facebook & Instagram):** Highly reliable but complex OAuth setup. Crucial for most retail and service SMBs.
- **WhatsApp Business API:** Essential for global reach, especially in LATAM and India.
- **ManyChat:** Great visual flow builder, but OHC should provide a simpler built-in inbox rather than forcing users to learn a complex tool.

### Recommendation
Integrate directly with Meta Graph API and WhatsApp Business API to aggregate messages into a single OHC inbox. This works in Cloud mode via webhooks. For Standalone mode, we may need a lightweight polling mechanism or direct API connections.

### Pricing Estimate
Meta APIs are generally free for basic usage; WhatsApp charges per conversation after a free tier.

### Cloud vs. Standalone
- **Cloud:** Standard OAuth and webhook ingestion.
- **Standalone:** Will require localized OAuth flows and potentially polling if webhooks cannot reach the local machine.

## Design Doc
### Integration Flow
1. User navigates to Settings > Social Media.
2. Clicks 'Connect Facebook/Instagram' and completes the OAuth flow.
3. OHC begins receiving messages via webhooks (Cloud) or polling (Standalone).
4. Messages appear in a unified 'Inbox' view within the OHC app.
5. User replies from the OHC app, and the response is routed back to the native platform.

## Implementation Prompt
Create a unified inbox feature that allows users to connect their Instagram and Facebook accounts. When a customer messages them on either platform, the message should appear in OHC. The business owner should be able to type a reply in OHC and have it sent back to the customer on the original platform. Ensure the setup process is entirely guided and doesn't require the user to understand API keys or webhooks.
