# Integrated Email Marketing Campaigns

## Problem Statement
Exporting customer lists to third-party tools like Mailchimp is cumbersome and leads to fragmented data.

## Research Report
Resend and SendGrid evaluated. Resend has excellent developer experience and simple pricing. SendGrid has better deliverability for mass marketing but is harder to use. Resend chosen for ease of use.

## Design Doc
Allow business owners to select customers from their OHC list and send batch emails using Resend. Provide simple templates. Track open rates using webhooks.

## Implementation Prompt
Add an 'Email Campaign' feature where owners can select an audience, write an email using a rich text editor, and send it. Show open rates next to the campaign.
