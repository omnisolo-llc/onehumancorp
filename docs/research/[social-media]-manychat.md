# Title: Integrate ManyChat for Social Media Integration

## Problem Statement
Business owners are overwhelmed by DMs across Instagram, WhatsApp, and Facebook. They miss messages and lose sales.

## Research Report
**Advantages:** Fast API, great WhatsApp support, visually intuitive.
**Risks:** Meta API changes can break integration.
**Pricing:** $15/month Pro plan.
**Cloud/Standalone Support:** Cloud and Standalone supported.

## Design Doc
A unified inbox tab in the OHC dashboard where all social messages appear seamlessly, looking like a simple chat app.

## Implementation Prompt
Implement the integration with ManyChat such that the business owner experiences A unified inbox tab in the OHC dashboard where all social messages appear seamlessly, looking like a simple chat app.. Do not focus on technical intricacies but on seamless user experience. Ensure all acceptance criteria related to ease-of-use and reliability are met.

## Estimated Scope
