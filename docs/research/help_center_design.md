# In-App Help Center Design

## Overview
A searchable, beautifully designed help portal accessible from a "?" button in every major screen.

## Screen Design
- **AppBar**: Title "Help Center".
- **Search Bar**: A search text field at the top.
- **Categories Grid/List**:
  - Getting Started
  - My Store
  - Payments
  - AI Agents
  - Marketing
  - Account & Billing
- **Article Viewer**: Tapping a category or search result opens the article or list of articles. For simplicity, we can have static dummy content for the articles using plain language.

## E2E Test
- User clicks "?" button on Dashboard.
- Navigates to Help Center.
- Searches for a topic or clicks a category.
- Views the content.
