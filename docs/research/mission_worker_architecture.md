# Mission Worker Architecture Document

## Overview
The MissionWorker continuously polls the agent_missions table for tasks and processes them,
bridging the gap between cloud and standalone modes.

* Handles robust queue draining using FOR UPDATE SKIP LOCKED
* Cross Mode support
* Observability and Tracing Integration
* Skeptical verification
* Undercover mode payload validation
