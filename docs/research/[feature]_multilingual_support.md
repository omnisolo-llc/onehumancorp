# Feature: Native AI Translation & Localization

## Problem Statement
Non-native English speakers (Fatima) are locked out of digital entrepreneurship because platform backends and support are overwhelmingly English-first.

## Research Report
- **Data:** High abandonment rates in LATAM and among immigrant business owners in the US when using Shopify/Squarespace.
- **Competitive Landscape:** Platforms offer translated interfaces, but generated content, error messages, and customer support remain heavily English-biased.
- **Conclusion:** OHC must be natively multilingual, not just the UI, but the AI agents, the generated storefront, and customer notifications.

## Design Doc
- **Architecture:**
  - Entity: `MerchantProfile` (with `preferred_language`), `LocalizationContext`.
  - Integration: Deep integration of translation LLM at the API gateway layer for all user-facing strings and agent interactions.
- **UI/UX:**
  - 375px mobile view: Language selection at very first touchpoint. All subsequent interactions, including AI chats, are in that language.
- **AI Agent Integration:** All agents must detect the user's preferred language and operate fluently within it, including translating customer messages on the fly (e.g., customer texts in English, Fatima sees it in Spanish, Fatima replies in Spanish, customer receives English).

## Implementation Prompt
Implement deep Multilingual Support. Ensure the MerchantProfile stores a language preference. Build an interception layer so that all AI agents converse with the merchant in their preferred language. Implement real-time translation for the unified inbox so merchants can converse with customers in different languages seamlessly.
