# Vibe-Based Generative Design

## Title
Vibe-Based Generative Design

## Problem Statement
Founders struggle with design decisions. Choosing templates, colors, and fonts is overwhelming and often results in amateur-looking storefronts.

## Research Report
*   **Competitor Analysis:** Wix relies on templates or basic AI assistance. Shopify relies on paid themes.
*   **User Evidence:** "I built it, but it looks bad."
*   **OHC Differentiation:** Instead of templates, owners describe their "vibe" (e.g., "modern rustic bakery"), and the system generates a cohesive, premium design system instantly.

## Design Doc
*   **Architecture:** Design token generation system powered by LLMs.
*   **Mobile UX Flow (375px focus):** Text input for "vibe" -> preview of generated design system -> 1-tap apply.
*   **AI Integration Points:** LLM for mapping text to design tokens (colors, typography, spacing).

## Implementation Prompt
Implement a feature allowing users to apply a complete design system to their storefront by simply describing the desired "vibe" in plain language.
