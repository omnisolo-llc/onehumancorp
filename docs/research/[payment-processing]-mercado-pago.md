# Title: Integrate Mercado Pago for Payment Processing

## Problem Statement
Stripe isn't available or preferred in LATAM. Businesses need a local, trusted payment provider with fast settlement.

## Research Report
**Advantages:** Huge market share in LATAM, supports local payment methods.
**Risks:** Regional only, requires separate integration from global providers.
**Pricing:** Percentage per transaction varies by country (e.g., ~4%).
**Cloud/Standalone Support:** Cloud and Standalone supported.

## Design Doc
A simple toggle in the 'Payments' setting to 'Enable Mercado Pago'. Checkout flows automatically show local payment options (e.g., PIX, Boleto).

## Implementation Prompt
Implement the integration with Mercado Pago such that the business owner experiences A simple toggle in the 'Payments' setting to 'Enable Mercado Pago'. Checkout flows automatically show local payment options (e.g., PIX, Boleto).. Do not focus on technical intricacies but on seamless user experience. Ensure all acceptance criteria related to ease-of-use and reliability are met.

P1
