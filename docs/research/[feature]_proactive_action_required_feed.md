# [feature] Proactive "Action Required" Dashboard Feed

## Title
Implement Proactive "Action Required" Dashboard Feed for 1-Tap AI Approvals

## Problem Statement
Small business owners suffer from immense "Operational Fatigue" (Ranked #2 pain point). Managing a business online often means constantly switching between apps to reply to DMs, restock inventory, or schedule social media posts. This reactive workflow steals time away from their actual craft (e.g., baking, consulting). The platform needs to shift the burden of initiating work from the user to the AI.

## Research Report
- **Pain Point Mapping:** Directly addresses "Operational Fatigue" (68% frequency) and "Communication Lag" (40% frequency).
- **Competitive Landscape:** Shopify and Wix rely on the user to log in and look for things to do (e.g., checking an inbox or an inventory tab). AI is only invoked when the user asks for it (e.g., Shopify Sidekick).
- **Strategic Opportunity:** Treat AI as a proactive Teammate. By having background agents monitor the business event mesh, OHC can pre-compute solutions to problems before the owner even knows they exist, presenting them as simple 1-tap approvals.

## Design Doc
### High-Level Architecture
- **Entity & Trigger:** The Dashboard Feed consumes events from the hybrid event mesh (e.g., `MessageReceived`, `InventoryThresholdReached`). Background AI agents process these events and generate `DraftAction` proposals.
- **Core Action:** The Dashboard surfaces these proposals in a unified, priority-sorted feed. The user reviews the AI's proposed action and approves it with a single tap.
- **UI/UX Flow (Mobile First, 375px):**
  - The main dashboard replaces traditional static metrics with a dynamic "Action Required" feed.
  - **Card Example 1:** "Customer asked about vegan options. Draft reply: 'Yes, all our cakes can be made vegan!' [Approve & Send]"
  - **Card Example 2:** "Vanilla extract is running low based on recent sales. Add to shopping list? [Approve]"
  - The UI uses premium Glassmorphism and ensures touch targets are large (≥ 44x44px) for quick, on-the-go management.

## Implementation Prompt
Implement the "Action Required" unified feed on the mobile dashboard. This feed must subscribe to drafted actions generated by the various AI departments (Customer Success, Operations). Design the UI cards to clearly explain the context of the AI's proposal and provide a prominent, 1-tap approval button that executes the action and dismisses the card. Ensure the UI strictly adheres to the OHC Mobile-First and Visual Excellence constraints.
