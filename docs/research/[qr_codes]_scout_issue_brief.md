# Issue Brief: Dynamic QR Code Generation for Menus and Products

## Problem Statement
Physical businesses want to bridge the offline-to-online gap, but generating and managing QR codes requires third-party tools.

## Research Report
QR codes are now universally understood. Providing native generation for products, menus, or the entire storefront allows easy physical marketing.

## Design Doc
**Architecture:**
- QR code generation utility.
**AI Integration:**
- None.

## Implementation Prompt
Implement a feature to generate dynamic QR codes for any product or page. Acceptance criteria: A user can successfully generate and download a mock QR code image that resolves to a specific product URL.

## Priority
P3

## Estimated Scope
Small
