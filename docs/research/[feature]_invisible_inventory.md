# Feature: Invisible One-Tap Inventory Upload

## Problem Statement
Uploading products is the biggest friction point. Boutique owners (Priya) hate filling out forms for titles, descriptions, SEO tags, weights, and categories for every single item.

## Research Report
- **Data:** Reddit r/ecommerce shows product data entry is the most outsourced and hated task.
- **Competitive Landscape:** Most platforms require manual entry. Some have "generate description" buttons, but still require the user to fill the rest of the form.
- **Conclusion:** OHC must allow a user to simply snap a photo, and the AI does the rest.

## Design Doc
- **Architecture:**
  - Entity: `Product`, `Media`.
  - Integration: Mobile camera API to vision LLM, extracting metadata to populate the `Product` entity.
- **UI/UX:**
  - 375px mobile view: A massive camera button. User takes a picture, sees a loading spinner ("AI is analyzing..."), and then sees a fully populated product page ready to publish.
- **AI Agent Integration:** Vision agent analyzes the image, identifies the item, writes a SEO-optimized description, and suggests pricing based on market data.

## Implementation Prompt
Build the One-Tap Inventory Upload feature. Provide a mobile-first UI with a camera capture mechanism. Send the captured image to a Vision AI agent. The agent must return a structured payload containing a title, description, category, and estimated price. Automatically populate the product creation form with this data and allow the user to 1-tap publish.

P1
