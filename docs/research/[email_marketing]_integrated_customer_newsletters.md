# Integrated Customer Newsletters

**Priority:** P2
**Estimated Scope:** Medium

## Problem Statement
Business owners want to email their past customers about promotions, but exporting lists from their CRM to Mailchimp is tedious and often gets forgotten.

## Research Report
### Evaluated Tools
- **Resend / SendGrid / AWS SES:** Developer-focused APIs. Great deliverability but require us to build the UI.
- **Mailchimp:** Market leader, but expensive for small lists and requires maintaining a separate tool.

### Recommendation
Use Resend for the underlying delivery engine (due to its modern API and good deliverability) but build a simple, plain-text focused campaign composer directly inside OHC.

### Pricing Estimate
Resend is very affordable (often free for small volumes), significantly cheaper than standard Mailchimp plans.

### Cloud vs. Standalone
- **Cloud:** Straightforward API integration.
- **Standalone:** Same API integration, but user might need to provide their own API key if we don't proxy it through our cloud infrastructure.

## Design Doc
### Integration Flow
1. User navigates to 'Customers' tab.
2. Clicks 'Send Newsletter' to selected customers.
3. A simple WYSIWYG editor appears.
4. OHC formats the email and sends it via the Resend API.
5. Basic analytics (open rates) are displayed back in OHC.

## Implementation Prompt
Build a newsletter tool that lets business owners select customers from their OHC database and send them a bulk email. The interface should look like composing a regular email, not a complex marketing tool. Use a reliable third-party API for delivery, but abstract the complexity so the user just clicks 'Send'.
