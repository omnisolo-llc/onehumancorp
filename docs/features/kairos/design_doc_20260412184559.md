# Master Design Doc: KAIROS Orchestration

## 1. Overview
This document consolidates the architectural vision for the KAIROS Orchestration Engine.

## 2. Shared Task List & Teammate Mesh
- Tasks will be stored using a Hybrid Approach: PostgreSQL (Cloud-Native) and SQLite (Standalone).
- Inter-agent realtime communication over Redis Pub/Sub channels (Cloud) and Mutexes/In-Memory (Standalone).
- State Machine ensures deterministic tracking (`PENDING` -> `ASSIGNED` -> `IN_PROGRESS` -> `REVIEW` -> `COMPLETED`).

## 3. AutoDream Data Pipelines
- Scans `agent_session_data` and `.agent-task/memory/*.yml`.
- Vector embeddings stored using `pgvector` for long-term memory retrieval.

## 4. Sub-Agent Orchestration Queue
- Uses Redis ZSETS or SQLite mutexed tables for concurrency and isolation.
