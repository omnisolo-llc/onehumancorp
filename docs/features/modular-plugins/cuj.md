# Core User Journey: Capability Plugin Mesh

1.  **Actor:** Autonomous Agent
2.  **Trigger:** Agent encounters a task requiring a capability not currently in its context.
3.  **Action:** Agent queries the MCP Gateway for matching `CapabilityManifests`.
4.  **System Response:** MCP Gateway dynamically registers and injects the required capability into the Agent's context.
5.  **Result:** Agent successfully executes the task without human intervention or restart.
