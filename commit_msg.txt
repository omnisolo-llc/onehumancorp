[backend] Implement Growth API Request Quotas for Teams

Addresses issue #5831 to add an API layer for tracking and enforcing team API
request quotas.

- Implements `QuotaService` within `domain` to store and increment limit data
  using Rueidis instead of an in-memory map to support cluster setups.
- Implements `QuotaHandler` within `api` to route GET and POST requests to the
  service.
- Emits OpenTelemetry metrics for requests.
- Integrates into `main.go` using standard HTTP mux for routing.

Tested with `bazelisk test //srcs/server/...` for compliance.
