# OHC Hybrid Agentic OS - Day One Data Seeder Technical Documentation

## Architectural Overview
The \`deploy/scripts/ohc-seed-data.sh\` and its integration within \`ohc_hybrid_cli.sh\` represent a critical bridge between local Standalone Desktop execution and zero-configuration launch readiness.

## Zero Trust and SPIRE Principles
The mock seeder intentionally operates over local unauthenticated loopback during initial launch (`127.0.0.1:8080/api/dev/seed`). It bypasses OIDC/Spiffe explicitly to enable rapid non-technical user onboarding without breaking production security boundaries.

## Edge Computing Data Synchronization
When local SQLite data is populated via this seeder, the `SyncPendingMissions` daemon automatically captures the mock states and prepares them for an eventual merge strategy should the business choose to upgrade to Cloud Mode. The `health.rs` probe will accurately reflect \`local_to_cloud_sync_queue\` > 0 immediately after seeding.

## Impact on E2E testing
Playwright tests are configured to wait for the \`Launch Readiness\` mock data prior to running the \`Grandmother Test\`. This allows deterministic rendering of revenue charts, out of stock alerts, and agent activity lists.
