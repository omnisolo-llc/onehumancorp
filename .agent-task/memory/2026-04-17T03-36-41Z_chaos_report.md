# Chaos Report: Mailbox Corruption

## Problem Statement
The OHC Hybrid OS requires testing against filesystem corruption scenarios, particularly around `.agent-task/mailbox/`.

## Resolution
Added `CorruptMailbox` to the `ChaosMode` enum in `lib/resilience/chaos/chaos.go`. This chaos mode correctly simulates mailbox corruption by creating a `corrupt.msg` file if the directory exists.
Added full test coverage in `lib/resilience/chaos/chaos_test.go` and system testing in `tests/chaos/chaos_system_test.go`.
