# 🔬 Mission: Implement Observability Mode Parity for Postgres Transaction Retries

<div markdown="1" style="backdrop-filter: blur(20px); background-color: rgba(255, 255, 255, 0.03); padding: 20px; border-radius: 10px; font-family: 'Outfit', 'Inter', sans-serif;">

## Problem Statement
The OHC Hybrid Architecture (OHC-HA) dictates observability parity between Cloud-native (PostgreSQL) and Standalone (SQLite) modes. Currently, `telemetry.go` tracks `ohc_sqlite_retry_exhausted_total` for SQLite transaction failures due to retry exhaustion but completely lacks an equivalent metric for PostgreSQL (`ohc_postgres_retry_exhausted_total`). This creates an observability gap in the Swarm-as-Code telemetry system, preventing the identification of Postgres transaction retry limits or bottlenecks in high-concurrency multi-tenant K8s environments.

## Research Report
- Analyzed `srcs/server/telemetry/telemetry.go` and verified the existence of SQLite retry exhaustion metrics (`sqliteRetryExhaustedCounter`).
- Discovered that PostgreSQL telemetry is limited to lock contention (`postgresLockContentionCounter`), missing retry exhaustion analytics.
- To maintain Mode Parity and ensure full-spectrum observability, PostgreSQL needs an equivalent `Int64Counter` metric and function.

## Design Doc
- **Telemetry Update**: Add `postgresRetryExhaustedCounter metric.Int64Counter` to the global `var` block in `srcs/server/telemetry/telemetry.go`.
- **Initialization**: Initialize `postgresRetryExhaustedCounter` in `InitWithMeter` using `m.Int64Counter("ohc_postgres_retry_exhausted_total", metric.WithDescription("Total times a PostgreSQL transaction failed after exhausting retries."))`.
- **Functionality**: Implement `RecordPostgresRetryExhausted(ctx context.Context, operation string)` modeled after `RecordSQLiteRetryExhausted`.
- **Testing**: Update `telemetry_test.go` or `telemetry_extra_test.go` to assert the new `postgres_retry_exhausted` buffer metric and counter additions.

   ```go
   // RecordPostgresRetryExhausted increments the global counter for PostgreSQL transaction failed after exhausting retries.
   func RecordPostgresRetryExhausted(ctx context.Context, operation string) {
       payloadBytes, _ := json.Marshal(map[string]interface{}{
           "operation": operation,
       })
       if BufferMetricFunc != nil {
           _ = BufferMetricFunc(ctx, "postgres_retry_exhausted", string(payloadBytes))
       }
       if postgresRetryExhaustedCounter == nil {
           return
       }
       postgresRetryExhaustedCounter.Add(ctx, 1, metric.WithAttributes(
           attribute.String("operation", operation),
       ))
   }
   ```
