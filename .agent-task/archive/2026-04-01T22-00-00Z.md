# Problem Statement
Under high concurrency in Standalone Desktop mode, the local agent swarm causes "database is locked" errors in SQLite during task delegation.

# Research Report
The `OBSERVABILITY_AUDIT_REPORT.md` states that a dynamic concurrency limiter must be introduced in `DelegateMission` that parses `OHC_STANDALONE`. A package-level throttle already exists but currently checks `OHC_MULTITENANT` instead of `OHC_STANDALONE`.

# Design Doc
Update `acquireThrottle` and `releaseThrottle` in `srcs/server/orchestration/sip.go` to use `os.Getenv("OHC_STANDALONE") == "true"`. Update the associated test in `throttle_test.go`.

# Implementation Prompt
Update the `sip.go` file to use `os.Getenv("OHC_STANDALONE") == "true"` for throttling. Ensure tests pass.
