# Title: Implement Hybrid Agent Status Indicator Widget

## Problem Statement
The OHC Hybrid Agentic OS requires a visual component to display the current status and health of the local desktop agent versus the cloud orchestration agent. We need a premium, high-fidelity Flutter widget in the web app to visualize this hybrid state using Glassmorphism.

## Research Report
Currently, there is no widget in `apps/web/lib/widgets/` to display hybrid agent status. A dedicated `HybridAgentStatusWidget` is required to give users immediate visual feedback on whether their local agent is successfully synchronized with the cloud or running in standalone mode.

## Design Doc
1. Create `apps/web/lib/widgets/hybrid_agent_status.dart`.
2. Implement Glassmorphism styling (`sigmaX: 20.0`, `sigmaY: 20.0`, `Color.fromRGBO(255, 255, 255, 0.03)`).
3. Use 'Outfit' or 'Inter' typography.
4. Add micro-animations using `AnimationController` for status pulses (e.g. green pulse for synchronized, yellow for standalone).
5. Write tests in `apps/web/test/hybrid_agent_status_test.dart`.

## Implementation Prompt
Implement `HybridAgentStatusWidget` as a `StatefulWidget` displaying the local vs cloud connection status. Use smooth, looping pulse animations to indicate active status. Ensure adherence to the Visual Excellence Mandate.
