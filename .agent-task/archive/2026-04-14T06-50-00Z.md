# Mission: Enable YAML Support for Mission Ingestion Worker

## Problem Statement
The `MissionIngestionWorker` currently only vectorizes `.md` files in `.agent-task/missions/`. However, mission files are also allowed to be written as `.yml` files according to Swarm protocols.

## Research Report
We searched the codebase for usages of `.yml` and `.md` extensions for `.agent-task` and determined that `mission_ingestion.go` was restrictive. This aligns with Swarm memory guidelines that files in `.agent-task/` could use `.yml`.

## Design Doc
We will update `srcs/server/workers/mission_ingestion.go`'s `IngestMissions` method. It currently only handles `.md` files. We will expand the conditional check `if file.IsDir() || filepath.Ext(file.Name()) != ".md" {` to also allow `.yml`. Additionally, `strings.TrimSuffix(file.Name(), ".md")` will be made dynamic by getting `ext := filepath.Ext(file.Name())`.

## Implementation Prompt
Modify `mission_ingestion.go` logic and create a new unit test in `mission_ingestion_test.go` to verify successful parsing and insertion of a `.yml` mission file.
