# 🤖 KAIROS Orchestration: Shared Task List, Teammate Mesh, and autoDream Architecture

## Problem Statement
The OHC swarm requires a structured orchestration system to coordinate complex feature decomposition, task execution, and long-term memory consolidation. Without a shared task list, a realtime Teammate Mesh, and an autoDream pipeline, agents risk duplicating work, encountering race conditions, and losing historical context.

## Research Report
Based on OHC-HA (Cloud PostgreSQL and Local SQLite) and competitive analysis of distributed state machines, we need:
1. **Shared Task List**: A database-backed state machine (PostgreSQL `FOR UPDATE SKIP LOCKED` / SQLite Mutex) to prevent race conditions during distributed task execution.
2. **Teammate Mesh**: A realtime communication layer (Redis Pub/Sub in Cloud, Go channels in Standalone) to broadcast task state transitions.
3. **autoDream Pipeline**: A durable vector storage architecture (pgvector) to consolidate agent scratchpads into long-term memory (`consolidated_memory` table).
4. **Sub-Agent Orchestration**: A background queue to spawn isolated sub-agents dynamically.

## Design Doc

See `docs/architecture/KAIROS_AI_OS_ARCHITECTURE.md` (authored previously) for the detailed design, including schema definitions and sequence diagrams.

### Phase 1: Shared Task List Decomposition
PostgreSQL Schema:
```sql
CREATE TABLE IF NOT EXISTS shared_tasks_v3 (
    id TEXT PRIMARY KEY,
    organization_id TEXT NOT NULL,
    title TEXT NOT NULL,
    status TEXT NOT NULL DEFAULT 'PENDING',
    assigned_agent_id TEXT,
    dependencies JSONB,
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
```

### Phase 2: Teammate Mesh APIs
Broadcast endpoint: `POST /api/mesh/v2/broadcast` over `mesh:tasks` channel.

### Phase 3: autoDream Memory Architecture
Vector DB (pgvector) schema:
```sql
CREATE TABLE IF NOT EXISTS consolidated_memory (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    task_id TEXT REFERENCES shared_tasks_v3(id),
    content TEXT NOT NULL,
    embedding vector(1536),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
```

### Phase 4: Sub-Agent Queue
Background queuing logic to spawn isolated sub-agents in a production environment.
