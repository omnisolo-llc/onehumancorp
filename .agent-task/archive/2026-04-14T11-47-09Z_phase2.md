# Problem Statement
Agents need real-time synchronization during task decomposition and execution so that human orchestrators and other sub-agents see the system state change instantly.

# Research Report
The existing Teammate Mesh architecture can broadcast events. We need to integrate the state machine hooks of the new Shared Task List to trigger broadcasts on task creation and completion.

# Design Doc
Refer to `docs/architecture/kairos_task_decomposition_design.md`. Ensure all Teammate Mesh payloads follow OHC-SIP compliance.

# Implementation Prompt
Instrument the Task repository methods (implemented in Phase 1) to publish an event via `POST /api/mesh/broadcast` whenever a task state transitions (e.g., `PENDING` -> `IN_PROGRESS`). Add tests verifying the broadcast logic.
