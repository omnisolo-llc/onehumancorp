  "issue_description": "## Connected Accounts and Standing Authority Documentation\n\n### Setup and Connected Accounts\nConnected accounts in OmniSolo are established via the `ConnectionVault` (`src/server/api/tool_integrations.rs`). Provider credentials (e.g., Stripe, API keys) are bound directly to the `tenant_id` ensuring tenant isolation. A missing or revoked tenant key must never fall back to another payer.\n\n### Standing Authority and Budgets\nStanding authority for AI agents is strictly managed by the `BudgetManager` (`src/server/pricing/budget.rs`). Autonomous actions must acquire a `BudgetReservation` before executing external spend or provider API calls. All spend is idempotently settled into the `UsageLedger` and bound to the specific tenant and task to prevent unauthorized duplicate billing.\n\n### Superpowers Workflow Provenance\n- Loaded skills: `using-superpowers`\n- Revision hash: 5bf4e78011075bcfc0dc295f0724994cd123ee71\n- Checks performed: Codebase exploration of `tool_integrations.rs` and `budget.rs`.\n- Outcomes: Documented current product behavior for connected accounts and standing authority."
