issue_title: "Architecture Design: Native Rust Omnichannel Chat System (Chatwoot Replacement)"
issue_description: |
  The core strategic directive in RESEARCH.md is to "Integrate existing tools instead of rebuilding them." Requests to build native replacements for external services (such as Chatwoot) without explicit authorization, evidence, and an expansion gate must be rejected with a `no_work` finding. Building a native Rust omnichannel chat system violates this directive.
