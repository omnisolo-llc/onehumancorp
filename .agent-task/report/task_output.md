issue_title: "Research: AI Assistant Capabilities vs OHC Gaps"
issue_description: "The user requested research into AI Assistant Capabilities vs OHC Gaps, particularly identifying the lack of a native Rust-based omnichannel message ingest API, an AI Triage Agent, and a Zero-Setup AI Storefront. After auditing the codebase, it is confirmed that a native Rust omnichannel inbox already exists in \`src/server/api/inbox/webhook.rs\` which handles webhook ingest and parses messages. Additionally, the AI Triage Agent logic is already fully implemented in \`src/server/workers/message_triage_worker.rs\`, which processes incoming messages, classifies intent (e.g., 'Draft Quote', 'Draft Booking', 'Draft Reply'), and leverages an LLM to generate draft responses. The proposed 'TriageAgent' microservice architecture is already satisfied by the existing \`MessageTriageWorker\` and associated routing logic. No new implementation is needed as the core requirements are already present in the codebase."
