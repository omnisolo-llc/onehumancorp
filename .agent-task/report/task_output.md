issue_description: "The issue requests implementing a native Rust Omnichannel Gateway to replace external dependencies, including API endpoints to receive webhooks and trigger an AI Agent to draft a response. This capability already exists in the codebase. Specifically, 'src/server/api/omnichannel_webhook.rs' provides the '/api/v1/omnichannel/webhook' endpoint (mounted in 'src/server/lib.rs') that receives webhooks, inserts messages into the database, and dispatches an event to the department orchestrator to trigger the AI agent. Additionally, 'src/server/integrations/omnichannel' contains the models and traits for the omnichannel system, and 'src/server/integrations/whatsapp_cloud' contains the WhatsApp Cloud client and provider implementations. Therefore, the requested feature is already implemented and no work is required."
