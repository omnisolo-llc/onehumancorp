  # Research Report: The Unified Agent Feed (Mobile MVP)

  ## Problem Statement
  Business owners using OHC need a centralized place to view actionable insights, drafts, and updates from their AI agents. Currently, the system lacks a unified, mobile-first feed that aggregates these events into a "Unified Agent Feed". This feed should push critical updates, suggested actions, and drafted communications directly to the user's mobile device for review and approval. Without this, the platform feels more like a reactive dashboard than a proactive assistant.

  ## Research Report
  - **Competitor Analysis:** Competitors like Shopify provide standard dashboards and notifications, but often require navigating through complex menus or relying on reactive chatbots (e.g., Sidekick).
  - **OHC Gap:** OHC aims to provide an assistant-first approach. The proposed solution is an "Agent Feed" that acts as the central nervous system.
  - **Mobile Focus:** The target persona (e.g., Maya, Carlos) relies heavily on mobile devices (375px viewport).

  ## Design Doc
  - **Architecture Diagram:**
    ```mermaid
    graph TD;
        EventSource[Event Sources (Webhooks, Internal State)] --> AgentFeedAPI[Agent Feed API (Axum)];
        AgentFeedAPI --> AgentFeedDB[(PostgreSQL agent_feed_items)];
        AgentFeedDB --> MobileUI[Flutter/Tauri Mobile App (375px)];
    ```
  - **Mobile UX Flow:**
    1. User logs in and lands on the Dashboard.
    2. A tab or section for "Activity Feed" or "Agent Feed" is visible.
    3. The feed displays "Action Cards" with details and simple "Approve", "Edit", or "Discard" buttons.
    4. Tapping a card expands it for more details.
    5. Tapping "Approve" triggers an API call to update the state and dismisses the card with a visual transition.
  - **AI Agent Integration:** The feed ingests events generated by agents (e.g., drafted replies, restock suggestions) and presents them for user approval.

  ## Implementation Prompt
  - **Target Persona:** Maya the Baker.
  - **User Journey:** Maya opens the OHC mobile app, navigates to the Dashboard, and sees a unified feed of pending agent actions (e.g., draft Instagram reply). She reviews a card and taps "Approve". The action is executed and the card is removed.
  - **Acceptance Criteria:**
    - The "Unified Agent Feed" must be implemented in the mobile-first frontend (Tauri/Next.js prototype).
    - It must fetch data from the `/api/agent_feed` endpoint.
    - Action cards must be legible and fully functional on a 375px viewport (touch targets >= 44x44px).
    - It must support "Approve" / "Dismiss" actions that call the `{id}/state` endpoint.
    - E2E tests (`src/e2e/unified_agent_feed.spec.ts`, etc.) must pass.
