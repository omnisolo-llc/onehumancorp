  # Research Report: OHC Work Triage vs Market Leaders

  ## Market Mapping & Competitor Discovery

  ### Top 10 General Competitors
  1. WeCom (Tencent): Strong integration with WeChat ecosystem, robust CRM for small businesses, but heavy UI.
  2. DingTalk (Alibaba): Excellent operations and task management, deep ecosystem integration, complex setup.
  3. Feishu/Lark (ByteDance): Best-in-class collaboration and docs, rising AI features, less commerce-focused.
  4. Shopify: E-commerce giant, adding AI via Sidekick, but commerce-only.
  5. Square: Great POS and payments, adding AI features, but siloed operations.
  6. HubSpot: Powerful CRM, adding AI, but too complex/expensive for many micro-businesses.
  7. Notion: Excellent knowledge management, Notion AI is strong, but weak on transactional workflows.
  8. Microsoft Copilot: General productivity, deeply integrated into Office, but not an "owner operating system".
  9. Wix: Website builder adding AI capabilities, but limited backend operational depth.
  10. Stripe: Payments infrastructure, not an end-user work assistant.

  ### Top 10 AI-Native Competitors
  1. Shopify Sidekick (Commerce copilot)
  2. HubSpot ChatSpot (AI CRM assistant)
  3. Notion AI (Knowledge assistant)
  4. GitHub Copilot (Dev tool, analogous to specialized AI)
  5. Intercom Fin (AI customer service)
  6. Harvey (Legal AI, specialized)
  7. Glean (Enterprise search AI)
  8. Dust (Custom AI assistants)
  9. MultiOn (Autonomous browser agents)
  10. AutoGPT/BabyAGI (Autonomous task agents)

  ## Deep-Dive Competitor Audit: Shopify Sidekick

  **Capabilities:**
  - Answers questions about store performance (e.g., "Why are sales down?").
  - Executes tasks (e.g., "Put my summer collection on sale").
  - Modifies store design and settings.

  **Success Factors:**
  - Deeply integrated into the Shopify admin.
  - Conversational interface lowers the barrier to complex tasks.
  - Context-aware (knows the store's data).

  **User Sentiment:**
  - *Positive:* "Saves me time digging through menus. The context awareness is impressive."
  - *Negative:* "Still feels like a chatbot, not a proactive assistant. I have to know what to ask."

  ## OHC Gap & Pain Point Identification

  **OHC Feature Audit:**
  - Currently missing a unified "Work Triage" interface that surfaces actionable insights proactively.

  **Gap Matrix (OHC vs Competitors):**

  | Feature | OHC (Current) | Shopify Sidekick | WeCom | DingTalk |
  | :--- | :--- | :--- | :--- | :--- |
  | Proactive Action Suggestions | No | No | Limited | Limited |
  | Chat-based Task Execution | Limited | Yes | Yes | Yes |
  | Unified Message/Event Feed | No | No | Yes | Yes |
  | Frictionless Onboarding | Yes | Yes | No | No |
  | Small-Business Focus | Yes | Yes | No | No |

  **Unresolved Pain Points:**
  - Owners (like Maya and Carlos) don't have time to ask an AI what's wrong; they need the AI to tell them what to do.
  - "I don't want a chat box. I want a feed of the 3 most important things to do today."

  ## Focused Research & Agentic Solutions

  **Agentic Solution Design:**
  - A "Work Triage" feed on the mobile-first dashboard.
  - The AI Agent analyzes incoming DMs, payments, and calendar events.
  - It generates a prioritized list of "Action Items" (e.g., "Draft reply to Maya", "Send invoice to Carlos").

  ```mermaid
  graph TD
    A[Incoming Events: DMs, Payments, Calendar] --> B(WorkTriageAgent)
    B -->|Analyzes priority & context| C{Generates WorkItem}
    C --> D[Actionable UI Card in Feed]
    D -->|User taps 'Approve'| E[Action Executed by Agent]
  ```

  ## Design Doc

  **Architecture:**
  - **Entity:** `WorkItem` (id, tenant_id, source, priority, suggested_action, metadata).
  - **Agent:** `WorkTriageAgent` (listens to events via queue, generates `WorkItems`).
  - **UI:** A unified feed component on the home screen using OHC Premium Token library (translucent materials, clear hierarchy).

  **Mobile UX Flow (375px):**
  1. User opens app -> Sees "Today's Focus" list.
  2. Tap an item -> Opens context card with an AI-drafted suggested action (e.g., "Approve drafted reply").
  3. Tap "Approve" -> Action executes, item dismissed.

  ## Implementation Prompt

  **User-Facing Outcome:**
  The owner logs in and immediately sees a prioritized feed of actionable items generated by the AI assistant, consolidating messages, tasks, and alerts into a unified, glass-morphic UI.

  **Critical User Journey (CUJ):**
  1. Owner logs into OHC.
  2. Owner views the "Work Triage" feed.
  3. Owner reviews an AI-suggested action for a pending inquiry.
  4. Owner approves the action.

  **Acceptance Criteria:**
  - Implement a `WorkItem` data model and API.
  - Create a mobile-first UI component for the Work Triage feed.
  - Ensure the feed handles 0-state gracefully.
  - Add E2E Playwright tests verifying the CUJ.
