issue_description: "The issue requests implementing a custom Rust omnichannel chat system to replace 'ChatPlatform'. However, an audit of the codebase reveals that a native Rust omnichannel chat system is *already fully implemented*. The `src/server/domain/repository/omnichannel_repo.rs` contains the core multi-tenant models (`CustomerProfile`, `WorkItem`, `Inbox`, `Contact`, `Conversation`, `Message`, `AiDraft`, `AgentDraft`) and PostgreSQL persistence logic. The `src/server/services/chat/` module provides `ChatService` with multi-tenant RLS isolation. The `src/server/services/omnichannel_service.rs` uses this to manage `WorkItems` and LLM-generated drafts. Real-time webhooks (`src/server/api/omnichannel_webhook.rs` and `src/server/api/inbox/webhook.rs`) route incoming messages through the `orchestrator` (`src/server/orchestration/departments/`) to trigger AI agents. Since the requested functionality is already present natively within `onehumancorp/mono`, no further implementation is needed."
