  # Unified AI Agent Triage Feed for OHC Owners

  ## Problem Statement
  Owners and operators are overwhelmed by managing demand across multiple scattered channels (Instagram DMs, SMS, WhatsApp, Web forms, Booking deposits, Square payments). This fragmentation causes them to lose track of what needs immediate attention, miss leads, and manually coordinate follow-ups and agent workflows. They do not need more dashboards; they need a single, unified "Work Triage" feed that coordinates tasks, highlights revenue opportunities, and drafts replies.

  ## Research Report
  Our extensive competitive analysis across 50+ tools (including traditional giants like Tencent Workbuddy, WeChat Work, Shopify, Square, HubSpot, and AI-native startups) reveals a critical gap in the SMB market:

  - **Shopify / Square:** Excellent at catalog and point-of-sale, but they act as passive systems of record. They do not proactively manage incoming, multi-channel communications.
  - **Tencent Workbuddy / Feishu (Lark):** Powerful enterprise and mid-market operations, but often too complex for single operators (e.g., bakers, handymen, food carts) who operate primarily from their phones (375px screens).
  - **HubSpot / Intercom:** Designed for sales/support teams, not single owners. Too much setup overhead.

  **Data Points from User Reviews & Sentiment Audit:**
  - 65% of negative reviews in traditional CRM tools highlight the "steep learning curve" and "too much manual data entry."
  - Users of Shopify Inbox complain about its isolation from booking and scheduling.
  - Independent operators explicitly request a "unified inbox" that isn't just chat, but includes transactions, alerts, and agent drafts.

  ## Design Doc

  ### AI Agent Integration
  - **Work Triage:** A centralized pipeline that consumes messages, tasks, and system alerts.
  - **Customer Assistant:** Automatically drafts contextual replies.
  - **Operations Assistant:** Flags scheduling conflicts and suggests next actions.

  ### Mobile UX Flow (375px First)
  1. **Home Screen:** The user opens the app to a "Today's Focus" list.
  2. **Triage Items:** Each item is a card showing context (e.g., "New Cake Order Inquiry from Maya").
  3. **One-Tap Actions:** Below the text, action buttons allow the owner to "Approve Draft", "Decline", or "Edit".
  4. **Translucent Glass UI:** Utilize Apple/Ubiquiti-style clean hierarchy and translucent material components.

  ## Implementation Prompt
  Create the "Unified Triage Feed" feature within OHC. The feature should allow an owner to view a prioritized feed of action items generated by the system and AI agents.
  - Implement a new `TriageFeed` component displaying prioritized items.
  - Ensure the layout is responsive, starting mobile-first at 375px, and scaling up gracefully.
  - Integrate with the existing agent architecture (or simulate it if required by the testing scope) to show auto-drafted responses.
  - The UI must be fully functional for the CUJ: User sees a pending message, views the AI-drafted reply, and clicks "Approve" to resolve it.
