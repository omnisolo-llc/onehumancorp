issue_title: "Zero-Touch Platform Migration Engine: Autonomous Import from Legacy Competitors"
issue_description: |
  Many small business owners are trapped on legacy platforms due to migration pain. The Zero-Touch Platform Migration Engine acts as an invisible agent that handles the entire migration from competitors like Shopify and Wix asynchronously with zero technical input from the user. It moves catalogs, customer histories, and subscriptions, and enriches data via AI.

  ## Problem Statement
  Small business owners are trapped on legacy platforms (Shopify, Wix). Migration is an agonizing manual effort. The Zero-Touch Engine solves this by acting as an invisible agent handling migration asynchronously.

  ## Design Doc
  *   **Asynchronous & Invisible:** Migration happens in the background.
  *   **AI-Driven Enrichment:** Agents analyze product photos and descriptions to generate missing metadata.
  *   **Zero-Downtime Assurance:** Old store remains active until switch.
  *   **Multi-tenant Isolation:** Isolated namespaces for data privacy.

  ## Implementation Prompt
  Design and implement the `Zero-Touch Platform Migration Engine`. The system must accept a legacy store identifier and autonomously import products, customers, and order history into the OHC data model without manual mapping.
