outcome: blocked
issue_title: "Implement Custom Rust Omnichannel Chat System to Replace Chat system"
issue_description: |
  Implementation of the native Rust Omnichannel Chat System is blocked. According to the OHC operating contract and `RESEARCH.md` guidelines, new channels and integrations (such as web widget, email, SMS, and Instagram DMs) fall under "Gated expansion". This requires explicit evidence of retained-customer need, measurable value, and explicit strategy approval in `RESEARCH.md`, which are currently absent. Therefore, this expansion is blocked until the required prerequisites and evidence are documented.
