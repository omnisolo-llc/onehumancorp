# Tool Integration Research Q3

## [Social Media] Unified Inbox Integration
**Problem Statement:** Small business owners miss inquiries because messages are scattered across Instagram, Facebook, WhatsApp, and TikTok.
**Research Report:** Evaluating Meta Graph API and Twilio. Meta offers free tier; Twilio provides unified APIs but has per-message costs. Ideal for non-technical users if UI is abstracted.
**Design Doc:** OHC links to Meta/WhatsApp accounts. Incoming messages trigger webhook, storing messages in OHC Unified Inbox. Users reply from OHC.
**Implementation Prompt:** Implement a unified inbox view. Users can connect accounts and reply directly.
**Priority:** P1
**Estimated Scope:** Large
**Cloud/Standalone:** Cloud via webhooks, Standalone requires polling or tunnel.

## [Calendar] Automated Booking Sync
**Problem Statement:** Double-bookings ruin client trust.
**Research Report:** Google Calendar API and Cal.com API. Cal.com is open source and easier for Standalone.
**Design Doc:** Sync OHC appointments with external calendars. Conflict resolution blocks slots in OHC.
**Implementation Prompt:** Create a unified calendar view showing external and internal bookings.
**Priority:** P0
**Estimated Scope:** Medium
**Cloud/Standalone:** Both.

## [Email Marketing] Unified Campaign Manager
**Problem Statement:** Business owners struggle to export customer lists to Mailchimp manually.
**Research Report:** Resend vs SendGrid. Resend offers better DX and pricing for small tiers.
**Design Doc:** Send broadcast emails directly from OHC customer list. Track opens via webhook.
**Implementation Prompt:** Build a basic WYSIWYG email editor and audience selector.
**Priority:** P2
**Estimated Scope:** Medium
**Cloud/Standalone:** Cloud primary, Standalone via user-provided API key.

## [Payment Processing] LATAM Alternative Payments
**Problem Statement:** Stripe is not dominant in LATAM; users need Mercado Pago.
**Research Report:** Mercado Pago API has fast settlement in LATAM.
**Design Doc:** Integrate Mercado Pago Checkout Pro. Webhooks update invoice status.
**Implementation Prompt:** Add Mercado Pago as a payment provider option in settings.
**Priority:** P1
**Estimated Scope:** Medium
**Cloud/Standalone:** Both.

## [Shipping] Real-time Label Generation
**Problem Statement:** Manual label creation wastes hours per day for product sellers.
**Research Report:** Shippo vs EasyPost. EasyPost has more reliable international support.
**Design Doc:** Generate labels from OHC order view. Automatically email tracking to customer.
**Implementation Prompt:** Add a 'Generate Label' button to orders.
**Priority:** P2
**Estimated Scope:** Large
**Cloud/Standalone:** Both.

## [SMS] Reliable Global Notifications
**Problem Statement:** Low-English-proficiency users miss emails; SMS is critical.
**Research Report:** Twilio vs MessageBird. Twilio has better global coverage.
**Design Doc:** Send SMS reminders 24h before appointments.
**Implementation Prompt:** Add SMS notification toggle in appointment settings.
**Priority:** P1
**Estimated Scope:** Small
**Cloud/Standalone:** Both.

## [Video Conferencing] Auto-Meet Links
**Problem Statement:** Generating and pasting Zoom links for every online consultation is tedious.
**Research Report:** Zoom API vs Google Meet. Zoom is ubiquitous.
**Design Doc:** Auto-generate Zoom link upon booking confirmation.
**Implementation Prompt:** Add 'Online Meeting' location type that auto-generates links.
**Priority:** P2
**Estimated Scope:** Small
**Cloud/Standalone:** Both.
