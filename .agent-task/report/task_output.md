issue_title: "Omnichannel Loyalty & Rewards Engine"
issue_description: |
  Completed architectural gap discovery and system design for the "Omnichannel Loyalty & Rewards Engine". This feature resolves the critical pain point for SMB operators (like Priya and Fatima) of connecting offline in-person purchases with online digital identities without requiring customers to download new apps or merchants to install clunky hardware.

  The design implements an invisible, AI-driven retention system leveraging OHC's tokenized Buyer Identity and NATS event mesh. The CRM/Customer Success agents autonomously track points and dispatch dynamic rewards via SMS/WhatsApp, providing a true "zero-touch" loyalty experience.

  See the full design document at: `docs/research/[architecture]_omnichannel_loyalty_and_rewards_engine.md`.
