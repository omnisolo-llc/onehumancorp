issue_title: "GitHub Issue #36572: Native Rust WhatsApp Cloud API Integration for Work Triage"
issue_description: "The issue describes implementing native Rust WhatsApp Cloud API integration for Work Triage (P1). However, the requested integration is already fully implemented in the current native Rust codebase. The WhatsApp Cloud API provider is implemented in src/server/integrations/whatsapp_cloud, handling API sending via WhatsAppCloudClientWrapper. Additionally, src/server/api/meta_webhook.rs fully handles the incoming Meta webhooks (validating sha256 signatures), extracts messages, resolves the customer identity via process_omnichannel_message, and injects the payload into the ohc_job_queue using the message_triage job_type (and SKIP LOCKED behavior described in the issue). As the exact features specified in the issue's design doc are already functioning in native Rust, this is an explicit no-work finding."
