# Title: Implement KAIROS Orchestration Core

## Problem Statement
The OHC Swarm currently lacks a robust distributed system to decompose high-level feature requests, share tasks, communicate in real time, and persist architectural insights. We need to implement the KAIROS Orchestrator components (Shared Task List, Teammate Mesh APIs, AutoDream).

## Research Report
- Cloud-Native requires PostgreSQL `FOR UPDATE SKIP LOCKED` for task concurrency.
- Standalone mode requires SQLite compatibility (using Go's database.go wrapper that dynamically replaces `CREATE EXTENSION IF NOT EXISTS vector;` with `""` and `VECTOR(1536)` with `TEXT`).
- Teammate Mesh requires CentrifugeNode/Redis.
- RAG memories are stored in the `swarm_memory` table (defined in `005_sip.sql`), not hypothetical tables.
