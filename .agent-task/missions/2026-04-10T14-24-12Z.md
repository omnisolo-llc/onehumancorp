# Problem Statement
The Flutter application is using standard Material `Card` widgets across various screens instead of the `GlassCard` widget that fully adheres to the OHC Visual Excellence Mandate (Glassmorphism, 20px blur). This leads to visual inconsistency.

# Research Report
Audit reveals `Card()` is used in many screens (e.g., `channels_screen`, `cost_dashboard_screen`, `handoffs_screen`, `integrations_screen`, `meetings_screen`, `scaling_screen`, `security_screen`, `service_screen`, `settings_screen`).

# Implementation
- Abstracted `Card` widget into `GlassCard` in `srcs/app/lib/widgets/glass_card.dart`.
- Refactored all standard `Card()` usages to `GlassCard()` across screens.
- Added tests to ensure components render correctly.
