# KAIROS Orchestration: Shared Task List, Teammate Mesh, and AutoDream Architectural Consolidation

## Problem Statement
The OHC swarm currently lacks a centralized, distributed system for agents to securely coordinate, decompose, and track task execution across the hybrid architecture. Without a "Shared Task List" leveraging our Postgres backend and Redis Pub/Sub (Teammate Mesh), agents cannot effectively orchestrate complex, multi-step workflows.

## Research Report
Current agentic OS frameworks lack robust hybrid capabilities and unified state machines for tracking distributed multi-agent task execution. Communication often relies on disjointed APIs rather than a unified real-time mesh, leading to race conditions and loss of context during complex multi-step workflows.

For the OHC Hybrid Agentic OS, the KAIROS layer must rely on three core pillars:
1. **Shared Task List**: A distributed state machine tracking task dependencies using PostgreSQL `SKIP LOCKED` (for cloud horizontal scaling) and SQLite concurrent write handling for standalone mode.
2. **Teammate Mesh**: A real-time inter-agent communication layer built on Redis Pub/Sub using the central channel `mesh:tasks`.
3. **AutoDream**: Data pipelines leveraging `pgvector` for continuous long-term memory consolidation of completed tasks.

## Design Doc
### Architecture
1. **Shared Task List Schema:** Implement database tables for tasks and sub-tasks with state tracking (PENDING, RUNNING, DONE, FAILED). Include support for dependency tracking and sub-agent task decomposition. Ensure compatibility with both PostgreSQL and SQLite by using `TIMESTAMP` instead of `TIMESTAMPTZ`.
2. **Teammate Mesh APIs:** Build real-time pub/sub endpoints on top of Redis to broadcast task state changes. The primary channel will be `mesh:tasks`.
3. **AutoDream Pipeline:** Create pgvector schemas to store consolidated task outcomes as embeddings for long-term memory.
4. **Visual Aesthetics Mandate:** Ensure any corresponding documentation or dashboard UI designs strictly use OHC aesthetic tokens: `backdrop-filter: blur(20px) saturate(200%)`, `background: rgba(255, 255, 255, 0.03)`, and typography `'Outfit', 'Inter', sans-serif`.
