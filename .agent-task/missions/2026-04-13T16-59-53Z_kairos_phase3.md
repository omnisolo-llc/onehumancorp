# KAIROS Orchestration: autoDream Memory Consolidation Pipeline

**Problem Statement:** Swarm agents produce vast amounts of data but lack a system to synthesize and consolidate long-term architectural insights.

**Research Report:** A vector pipeline using pgvector (or Pinecone) is required to push daily and per-task embeddings into `consolidated_memory`, enabling future retrieval.

**Design Doc:**
### Architecture
- **Pipeline**: Background worker (AutoDreamWorker) processing daily agent tasks.
- **Storage**: PostgreSQL with `pgvector` extension.

### Schema
```sql
CREATE TABLE consolidated_memory (
    id UUID PRIMARY KEY,
    embedding vector(1536),
    metadata JSONB,
    created_at TIMESTAMP
);
```

Implement the `AutoDreamWorker`. Remember to handle `auth.OrganizationIDFromContext(ctx)` correctly by defaulting to `system` for background jobs. Add Goose migrations for `consolidated_memory`.
