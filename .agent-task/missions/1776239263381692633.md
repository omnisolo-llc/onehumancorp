# Swarm Observability Dashboard: Agent Mesh Realtime Stream Integration

## Problem Statement
The current Swarm Observability Dashboard displays agent task progress, but lacks a mechanism to view the realtime stream of Agent Mesh messages. We need to integrate the `AgentMeshMessageTile` into the dashboard to visualize inter-agent communications natively within the Flutter app.

## Implementation Details
1. Update `SwarmObservabilityDashboard` to parse and store incoming Agent Mesh messages from the WebSocket channel.
2. Add a section below the task list to display a scrollable list of `AgentMeshMessageTile`s.
3. Update tests in `swarm_observability_dashboard_test.dart` to cover the new message tile integration.
