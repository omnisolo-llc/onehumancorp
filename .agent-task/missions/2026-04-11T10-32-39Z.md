# Title: KAIROS AutoDream and Teammate Mesh Observability Panels in Grafana

## Problem Statement
The OHC Hybrid Architecture (OHC-HA) recently had critical OpenTelemetry metrics added to the backend for the KAIROS AutoDream vector RAG pipelines (`ohc_autodream_sync_duration_seconds`, `ohc_autodream_query_duration_seconds`) and Teammate Mesh coordination (`ohc_mesh_broadcast_total`). However, there is a gap in observability because these new backend metrics are not yet visualized in the primary Grafana provisioned dashboard (`deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json`). This lack of visualization hinders operators from monitoring the performance and throughput of AutoDream operations and Teammate Mesh broadcasts across Cloud-Native and Standalone modes.

## Research Report
**Market & Codebase Findings:**
1. **Metrics Available:** An audit of `srcs/server/telemetry/telemetry.go` confirms the existence and emission of `ohc_autodream_sync_duration_seconds`, `ohc_autodream_query_duration_seconds`, and `ohc_mesh_broadcast_total`.
2. **Dashboard Gap:** Reviewing `deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json` shows that these specific KAIROS orchestration metrics lack dedicated timeseries panels.
3. **Hybrid Context Requirements:** It's essential to visualize these metrics broken down by `deployment_mode` to compare the efficiency of the Cloud Postgres multi-tenant mode against the Standalone SQLite single-user mode.

## Design Doc
### Architecture Updates
- **Grafana Dashboards Update**: Modify `deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json` to include three new panels:
  - **AutoDream Sync Duration:** A timeseries panel displaying the P95 latency using the expression `histogram_quantile(0.95, sum by (le, deployment_mode) (rate(ohc_autodream_sync_duration_seconds_bucket[5m])))` and grouped by `deployment_mode`.
  - **AutoDream Query Duration:** A timeseries panel displaying the P95 latency using the expression `histogram_quantile(0.95, sum by (le, deployment_mode) (rate(ohc_autodream_query_duration_seconds_bucket[5m])))` and grouped by `deployment_mode`.
  - **Mesh Broadcast Total:** A timeseries panel displaying the rate of broadcasts using the expression `sum(rate(ohc_mesh_broadcast_total[5m])) by (deployment_mode)` and grouped by `deployment_mode`.

### UI / Grafana Guidelines (Visual Excellence)
Ensure the new native Grafana timeseries panels utilize standard JSON configurations that blend seamlessly with the existing glassmorphism-styled environment (relying on the OHC-SIP Stylistic Intent Profile injected elsewhere in the dashboard).
