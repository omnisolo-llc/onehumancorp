# Mission: Implement Persistent Growth Free-Tier Quota Tracking

**Title:** Persistent Free-Tier Quota Tracking
**Problem Statement:** The `handleQuota` endpoint in `srcs/server/dashboard/handlers_growth.go` is currently a stub returning hardcoded values (`{Used: 10, Max: 100}`). We need to persist and calculate accurate Free-Tier quotas to drive product-led growth (PLG) conversion to paid plans.

**Research Report:**
- Growth feature implementation is necessary for the Nova agent.
- There's no existing quota table.
- A new SQL migration should be added for `growth_quotas`.
- `handleQuota` in `srcs/server/dashboard/handlers_growth.go` should interact with a new `QuotaTracker` in `srcs/server/services/growth`.

**Design Doc:**
1. **Schema (`growth_quotas`):**
    - `id TEXT PRIMARY KEY`
    - `organization_id TEXT NOT NULL`
    - `resource_type TEXT NOT NULL`
    - `used INTEGER DEFAULT 0`
    - `max INTEGER DEFAULT 100`
    - `updated_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP`

2. **Growth Package (`quota.go`):**
    - Implement `QuotaTracker` with `GetQuota(ctx, orgID, resourceType)` and `IncrementQuota(ctx, orgID, resourceType, amount)`.

3. **Dashboard Integration:**
    - Inject `QuotaTracker` into `Server`.
    - Update `handleQuota` to parse `org_id` and `resource_type` from the request query parameters, and return actual values from the database using `QuotaTracker`.

4. **Observability:**
    - Add OpenTelemetry metrics for quota usage.

**Implementation Prompt:**
- Add `052_growth_quotas.sql` migration. Update `srcs/server/db/BUILD.bazel`.
- Add `srcs/server/services/growth/quota.go` and `quota_test.go`.
- Update `srcs/server/dashboard/server.go` to inject `QuotaTracker` and update `handleQuota`.
- Fix the stub test in `srcs/server/dashboard/handlers_growth_test.go`.
