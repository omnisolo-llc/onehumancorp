# Design Doc
### UltraPlan Flow
```mermaid
stateDiagram-v2
    [*] --> PROPOSE
    PROPOSE --> CRITIQUE
    CRITIQUE --> REVISE
    REVISE --> CRITIQUE
    CRITIQUE --> APPROVED
    APPROVED --> EXECUTE
    EXECUTE --> [*]
```

### Integration Points
- **State Machine:** Track phase transitions in a `ultraplan_deliberations` DB schema.
- **Mesh:** Broadcast events on the `mesh:ultraplan` channel.
- **Queue:** Sub-Agents must participate in the critique and review loops.
