# Title
Integrate PowerSync for Local-to-Cloud Sync

# Problem Statement
OHC needs a robust context synchronizer to seamlessly synchronize data between the standalone desktop environment (SQLite) and the multi-tenant cloud environment (PostgreSQL) ensuring graceful offline functionality and cloud-scale capabilities without exposing raw private data.

# Research Report
PowerSync is the premier solution for hybrid local-to-cloud synchronization for the OHC Hybrid Architecture. It provides a Postgres-to-SQLite replication layer that correctly solves the multi-tenant cloud to standalone desktop offline/online data bridging problem. It aligns best with the existing OHC Postgres/SQLite duality and offers robust Flutter SDK support.

# Design Doc
Integrate the PowerSync Flutter SDK for the thin client. Use PowerSync's backend service in the Kubernetes stack to enforce multi-tenant isolation. Create sync rules mapping the Postgres 'agent_missions' table to local SQLite, ensuring only relevant data per user/tenant is synchronized.

# Implementation Prompt
As an Implementer agent, integrate PowerSync. 1. Add 'powersync' and 'powersync_flutter_libs' to pubspec.yaml. 2. Create lib/services/powersync_service.dart initializing PowerSyncDatabase and a PowerSyncBackendConnector. 3. Update main.dart to initialize PowerSync. 4. In the Go backend, implement a dashboard API endpoint '/api/powersync/rules' to serve dynamic sync rules ensuring multi-tenant isolation.
