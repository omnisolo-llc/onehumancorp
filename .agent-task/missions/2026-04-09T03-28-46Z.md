# Problem Statement
The One Human Corp (OHC) Swarm currently lacks a centralized "KAIROS" orchestration framework to decompose complex feature requests, coordinate dependencies across agents, and persistently store consolidated memories. Without a durable Shared Task List, real-time Teammate Mesh APIs, and AutoDream Vector Consolidation data pipelines, agents operate in silos and cannot effectively collaborate on long-term multi-step workflows.

# Research Report
Based on OHC's hybrid cloud-native and standalone operating modes, the orchestration layer must support both PostgreSQL (Cloud) and SQLite (Standalone).
- **Shared Task List**: Requires a central database schema mapping agent assignments, dependencies, and state transitions to prevent deadlocks (Distributed State Machine).
- **Teammate Mesh**: Real-time communication must use highly available channels (Redis Pub/Sub) for Cloud mode while degrading gracefully in standalone environments.
- **AutoDream Pipeline**: Converting episodic memory into long-term embedded vector truth (pgvector / Pinecone) requires asynchronous data pipelines to run consistently in the background.

# Design Doc
- **Phase 1: Shared Task List Database Architecture**
  - **Schema Location**: `srcs/server/db/migrations/`
  - **Table**: `shared_tasks` (id, parent_id, title, description, agent_role, status, dependencies JSONB).
  - **Sequence Logic**: Implementing `FOR UPDATE SKIP LOCKED` for Postgres task claiming, degrading to application-level locks (`sync.Mutex`) or basic transactions for local SQLite.
- **Phase 2: Teammate Mesh APIs**
  - **Location**: `srcs/server/orchestration/`
  - **Transport**: Standardize Pub/Sub event payloads (`MeshEvent`) with topic routing. Integrate Redis for multi-pod environments.
- **Phase 3: AutoDream Data Pipelines**
  - **Location**: `srcs/server/pipeline/` (or similar)
  - **Logic**: A background scheduler/CRON that selects finalized episodes from `agent_missions`, generates embeddings via LLM APIs, and upserts them into the Vector DB (`autodream_memories`).
