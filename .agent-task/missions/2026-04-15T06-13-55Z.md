**Title:** Implement OHC Hybrid Agentic OS Core Orchestration

**Problem Statement:**
The KAIROS orchestrator needs a robust foundation for the OHC Hybrid Agentic OS. Currently, we lack the database schema for the Shared Task List, the API endpoints for the Teammate Mesh, the pgvector schema for AutoDream, and the background queue scaffolding for Sub-Agent Orchestration. These are essential to achieve Phase 1-4.

**Research Report:**
- Competitor analysis reveals that standalone local functionality (SQLite) combined with scalable cloud-native operations (PostgreSQL/Redis) is a significant competitive advantage.
- Reviewing KAIROS architecture, `docs/architecture/kairos_hybrid_agentic_os_master_design.md` defines the blueprints for these components.
- Distributed agent swarms require an explicit state machine for task claiming (`shared_tasks`), a low-latency pub/sub mesh (`Teammate Mesh`), persistent vector storage (`AutoDream`), and isolated job queues.

**Design Doc:**
1. **Shared Task List:** Implement the `shared_tasks` table schema in the database migrations. Ensure it supports `FOR UPDATE SKIP LOCKED` on PostgreSQL and is properly handled by `SqliteProvider`.
2. **Teammate Mesh:** Implement `POST /api/mesh/v2/broadcast` in the mesh APIs to broadcast state machine transitions.
3. **AutoDream:** Implement the pgvector table `autodream_memories` or equivalent for consolidating agent memory scratchpads.
4. **Sub-Agent Queue:** Implement the scaffolding for the background queue.

**Implementation Prompt:**
Dear Implementer (✨ Implementer):
- Reference the master design doc at `docs/architecture/kairos_hybrid_agentic_os_master_design.md`.
- **Phase 1 (Task List):** Create a database migration for `shared_tasks`. The schema must be standard PostgreSQL. Ensure `srcs/server/db/BUILD.bazel` is updated to include the new migration file.
- **Phase 2 (Mesh APIs):** Create an HTTP handler `POST /api/mesh/v2/broadcast` to allow agents to broadcast state transitions.
- **Phase 3 (AutoDream):** Add a database migration and initialization logic for the `autodream_memories` table (or similar) utilizing pgvector.
- **Phase 4 (Sub-Agent Queue):** Scaffold the queue architecture, ensuring background workers can pull decomposed jobs and spawn sub-agents.
- Ensure all tests pass (`bazelisk test //...`) and that hybrid compatibility is maintained.
