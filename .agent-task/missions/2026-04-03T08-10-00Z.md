# Zero Secrets Agentic Identity via SPIFFE/SPIRE

## Problem Statement
Current agent platforms (Claude Code, OpenClaw, Replit Agent) depend on long-lived, static API keys and environmental secrets to authenticate. In an autonomous Swarm context, distributing static secrets to hundreds of short-lived agents creates a massive attack surface. OHC needs a "Zero Secrets" policy where machine identities are ephemeral and cryptographically verified across the Hybrid Architecture.

## Research Report
- **Market Gap**: Competitors use user-scoped tokens. This fails when sub-agents spawn dynamically or work offline.
- **Solution**: SPIFFE (Secure Production Identity Framework for Everyone) and SPIRE (its runtime environment).
- **Impact**: Every agent receives a short-lived SVID (SPIFFE Verifiable Identity Document) to authenticate with the Central Database, K8s orchestrators, and internal APIs without managing static credentials.
- See `RESEARCH_REPORT_ZERO_SECRETS.md` for architectural diagrams and comparative market audits.

## Design Doc

### 1. SPIRE Integration in Go Backend
- Implement an interceptor for gRPC/HTTP traffic in `srcs/server/orchestration/` to validate incoming SPIFFE IDs via mTLS or SPIFFE JWTs.
- Integrate the `go-spiffe/v2` library.

### 2. Teammate Mesh Authentication
- Standalone Mode: Agents get local machine-bound SVIDs.
- Cloud Mode: Pods receive workload SVIDs.
- Modify `auth_interceptor.go` to support SPIFFE ID extraction and validation alongside existing claims logic.
