# Title: Implement Offline-to-Cloud State Sync for Swarm Memories (Hybrid MCP RAG Protocol)

## Problem Statement
Competitors in the Agentic OS market force a binary choice: trade privacy for cloud-scale execution, or trade scalability for local privacy. OHC needs to bridge this divide by enabling a "Hybrid MCP RAG Protocol". Currently, local SQLite RAG states are completely siloed from the cloud Postgres orchestration engine, preventing massive parallel cloud computation from leveraging local context securely.

## Research Report
- Based on the `RESEARCH_REPORT_HYBRID.md` market audit, pure cloud dependency (OpenClaw) and strictly siloed local states (Claude Code) are structural vulnerabilities.
- OHC's Hybrid Architecture (OHC-HA) can synchronize a local SQLite RAG state to the cloud Postgres orchestration engine via the OHC-SIP protocol.
- Sensitive RAG execution remains strictly private via local standalone Desktop mode. Generalized tasks requiring scaled compute can be securely delegated to the K8s multi-tenant cloud by syncing only sanitized context payloads.

## Design Doc
1. **Architecture**:
   - A background synchronizer daemon in the `orchestration` package.
   - The daemon reads from the local SQLite `swarm_truth_embeddings` and `agent_missions` tables.
   - Identifies entries marked for "Cloud Escalation".
   - Strips sensitive payload metadata (Sanitized Payload Injection).
   - Syncs payload to the Cloud Postgres `agent_missions` and `swarm_truth_embeddings` tables via a new gRPC/REST sync endpoint protected by SPIFFE/SPIRE.
2. **API Contracts**:
   - `POST /api/v1/sync/rag-state`: Accepts batched sanitized memory vectors.
3. **DB Schema Changes**:
   - Add `sync_status` (ENUM: 'LOCAL_ONLY', 'PENDING_SYNC', 'SYNCED') to `swarm_truth_embeddings` and `agent_missions`.
4. **UI Wireframes**:
   - The Hybrid Coordination UI should display a glowing "Syncing to Cloud Swarm" indicator using the OHC Aesthetic (`backdrop-filter: blur(20px) saturate(200%);`).
