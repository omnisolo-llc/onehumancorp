# Mission: Implement Shared Task List and Sub-Agent Orchestration

## Title
Implement Shared Task List and Sub-Agent Orchestration

## Problem Statement
The OHC Hybrid Architecture currently lacks a unified, resilient state machine and distributed queue for tracking multi-agent orchestration. The OHC swarm requires a decentralized "Shared Task List" to allow multiple sub-agents to claim, process, and complete complex, decomposed tasks concurrently while maintaining UI updates and robust state tracking.

## Research Report
Market analysis indicates that high-performance agent swarms (like those seen in competitive autonomous systems) rely on robust distributed state tracking and realtime messaging meshes.
1. Distributed Queuing: BullMQ-style or Celery-style queues backed by Redis are ideal for Cloud mode, but we must degrade gracefully to local SQLite structures for Standalone Desktop mode.
2. State Tracking: A resilient state machine mapped to our central database is necessary to coordinate long-running Teammate Mesh operations.
3. Memory & Consolidation: Vector DBs (pgvector/Pinecone) and AutoDream will be used later for long-term memory consolidation of tasks, but the immediate need is transactional tracking.
4. Visual Aesthetic: Competitors fall short on visual premium feel; all task tracking interfaces must employ the OHC Glassmorphism standards.

## Design Doc
1. **Database Schema:**
   - Add tables `shared_tasks`, `task_dependencies`, and `sub_agent_queues`.
   - Use the `convertBindVars` mechanism in database providers to automatically handle PostgreSQL to SQLite syntax changes (e.g., stripping `FOR UPDATE SKIP LOCKED` in Standalone mode).
2. **Backend API:**
   - Create orchestration endpoints in Go. Use precise structs for queuing logic. Ensure >95% test coverage.
3. **Realtime Mesh:**
   - Integrate with `production Redis Pub/Sub channels` for teammate mesh mailbox coordination.
4. **UI Design (Flutter/Dart):**
   - Components must extend `ConsumerWidget` / `ConsumerStatefulWidget` for Riverpod state.
   - Employ 'Premium' aesthetic tokens: `backdrop-filter: blur(20px) saturate(200%)`, `background: rgba(255, 255, 255, 0.05)`, and 'Outfit'/'Inter' typography.
