**OHC Hybrid Agentic OS Orchestration Architecture**

**Problem Statement:**
The OHC platform requires a comprehensive orchestration architecture to manage tasks, coordinate sub-agents, and track states seamlessly across Cloud-Native (K8s/PostgreSQL/Redis) and Standalone Desktop (SQLite/Local Bus) deployments, without sacrificing autonomy or the premium OHC user experience.

**Research Report:**
- Evaluated existing designs in docs/features/kairos/master_design_doc.md.
- Confirmed that Hybrid DB requirements dictate PostgreSQL NOW() and SQLite datetime('now') compatibility.
- Determined that Realtime Teammate Mesh APIs require Redis Pub/Sub for cloud, and an in-memory event bus for standalone.
- Identified AutoDream Data Pipeline requirements for pgvector in cloud and a lightweight SQLite fallback for local memory consolidation.
- Swarm Intelligence Protocol dictates memory sharing via .agent-task/memory/ and observability via .agent-task/status/.

**1. Shared Task List Architecture**
- **Schema**: id, title, description, status, assigned_agent, created_at, updated_at, parent_plan_id.
- **Hybrid Support**: Implement a DB abstraction layer handling Postgres NOW() vs. SQLite datetime('now').
- **Relationship**: Explicit parent_plan_id reference to prevent orphaned subtasks. Dependencies array MUST NOT include the pending parent task to avoid circular deadlocks.

**2. Realtime Teammate Mesh APIs**
- **Cloud Mode**: Utilize Redis Pub/Sub for mesh:tasks and mesh:coordination channels.
- **Standalone Mode**: Implement a fallback channel-based in-memory event bus using sync.RWMutex to degrade gracefully when Redis is absent.
- **Protocol**: Standardized JSON envelopes for agent-to-agent communication.

**3. AutoDream Data Pipeline**
- **Vector Embeddings**: Native Go []byte mappings.
- **Cloud Storage**: pgvector for long-term consolidation.
- **Local Storage**: Fallback to local SQLite or simple file-based vector storage for Standalone Mode.
- **Pipeline Cycle**: Background jobs (triggered by KAIROS) periodically summarize .agent-task/memory/ logs and commit to the Vector DB.

**4. Sub-Agent Orchestration & State Machine**
- **State Tracking**: Distributed state machine backed by Postgres/SQLite.
- **Coordination**: Distributed Redis locks (Cloud) or in-memory mutexes (Standalone) for concurrent resource access.
- **Queue**: Background queuing logic for spawning isolated sub-agents.
