# Title: Add Onboarding Verification Audit

## Problem Statement
Need a way to audit the "Day One" environment configuration via an HTTP endpoint.

## Research Report
The existing VerifyEnvironment logic in env_verifier.go is robust but not exposed via the server API, making automated verification difficult.

## Design Doc
Expose a new `GET /api/verify-environment` endpoint in `services/onboarding/server.go` and register it in `apps/onboarding/main.go`.

## Implementation Prompt
Implement the VerifyEnvironmentHandler and corresponding tests.

P1
