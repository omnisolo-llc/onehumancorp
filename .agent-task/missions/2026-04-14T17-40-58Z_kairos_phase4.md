# Design Doc
### Queue Architecture
```mermaid
sequenceDiagram
    participant MainAgent
    participant Queue as Redis/SQLite
    participant SubAgent
    MainAgent->>Queue: EnqueueJob(task_id, worker_class)
    SubAgent->>Queue: DequeueJob()
```

### Schema Definition
```sql
CREATE TABLE IF NOT EXISTS sub_agent_jobs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    task_id UUID REFERENCES shared_tasks_decomposition(id),
    worker_class VARCHAR NOT NULL,
    payload JSONB,
    status VARCHAR NOT NULL DEFAULT 'QUEUED',
    run_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
```
