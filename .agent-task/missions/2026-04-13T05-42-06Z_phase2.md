# Title: KAIROS Phase 2: Design the Realtime Teammate Mesh APIs

## Problem Statement
The Swarm needs a highly available realtime communication layer to broadcast task state changes, advertise capabilities, and enable agent coordination (Teammate Mesh) with zero friction.

## Research Report
Cloud-Native mode demands horizontal scalability, necessitating Redis Pub/Sub (rueidis). Standalone Desktop mode must operate without Redis, requiring in-memory Go channels or SQLite-backed WebSockets.

## Design Doc
Define an interface TeammateMesh with Publish, Subscribe, and Broadcast methods. Implement redis mesh using rueidis for cloud deployment and local mesh using Go channels for standalone. Standardize JSON payloads for event types like TASK_CLAIMED.

## Implementation Prompt
Design and implement the Realtime Teammate Mesh APIs in srcs/server/orchestration/. Implement both redis and local adapters fulfilling a common interface. Write unit tests for both implementations. Add an HTTP endpoint to broadcast to the mesh. Ensure all metrics are exported via OpenTelemetry.
