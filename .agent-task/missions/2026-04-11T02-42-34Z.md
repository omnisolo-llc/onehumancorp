# Problem Statement
Agents need a central Shared Task List to decompose complex feature requests and coordinate execution safely.

# Research Report
Requires PostgreSQL row-level locks (`FOR UPDATE SKIP LOCKED`) in Cloud-Native mode and standard transaction isolation in SQLite Standalone mode.

# Design Doc
Schema for `shared_tasks`: id, organization_id, title, status, assigned_agent_id, dependencies (JSONB).
