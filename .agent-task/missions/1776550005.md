# Title: Implement Growth Analytics Data Exporter

## Problem Statement
The growth analytics (invites, conversions) track successfully but are locked within the internal `analytics.Tracker` and Redis instance. We need a way to export this data for our internal OHC-SIP dashboards.

## Research Report
Adding an API endpoint `GET /api/v1/growth/analytics/export` in `apps/growth/main.go` that iterates through all referral stats and returns a JSON summary.

## Design Doc
1. Implement `GetAllReferrals` in `growth.ReferralRepository`.
2. Implement `GET /api/v1/growth/analytics/export` in `apps/growth/main.go`.
3. Return a JSON structure.
