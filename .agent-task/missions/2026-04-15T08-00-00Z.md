# Mission: Unexport RAG Sync Telemetry Metrics

## Problem
The metrics `RAGRecordsSyncedTotal` and `RAGSyncErrorsTotal` in `srcs/server/telemetry/rag_sync_metrics.go` are exported, which violates the architectural constraint that underlying metrics must be unexported when using `BufferMetricFunc` for local buffering enforcement.

## Solution
Rename the metrics to lowercase `ragRecordsSyncedTotal` and `ragSyncErrorsTotal`.
