# Hybrid MCP RAG Protocol (Offline-to-Cloud State Sync)

## Problem Statement
Competitors in the Agentic OS market force a binary choice: trade privacy for cloud-scale execution, or trade scalability for local privacy. Replit and OpenClaw index only what is in the cloud, and Claude Code indexes only local directories. OHC requires a unified "Hybrid MCP RAG Protocol" to synchronize a local SQLite RAG state to the cloud Postgres orchestration engine via OHC-SIP, allowing seamless operation switching and maintaining our "Unfair Advantage".

## Research Report
- **Execution Mode**: Cloud-native solutions (OpenClaw) fail offline. Local-first tools (Claude Code) lack scaled multi-tenant computation.
- **Data Sovereignty**: Highly sensitive datasets should remain local on the user's Standalone Desktop mode (SQLite).
- **Cloud Escalation**: When massive parallel computation is needed, the local client securely delegates generalized tasks to the K8s multi-tenant cloud without exposing the raw private dataset, syncing only required context payloads.
- **Visual Evidence**: Refer to `RESEARCH_REPORT_HYBRID_OS_AUDIT.md` for the Mermaid.js chart detailing the hybrid workflow.

## Design Doc

### 1. Database Schema
We will leverage the existing `agent_missions` and `swarm_memory` tables, but introduce a sync mechanism.

```sql
-- Track synced memories
CREATE TABLE IF NOT EXISTS local_cloud_sync_log (
    sync_id UUID PRIMARY KEY,
    memory_id TEXT NOT NULL,
    cloud_mission_id TEXT,
    synced_at TIMESTAMPTZ DEFAULT NOW(),
    FOREIGN KEY (memory_id) REFERENCES swarm_memory(key) ON DELETE CASCADE
);
```

### 2. Synchronization Daemon (Go Backend)
- **Interface**: `SwarmSynchronizer` in `srcs/server/orchestration/`.
- **Logic**: Periodically (or event-driven) check for local RAG embeddings that need to be escaladed to the cloud for heavy computation.
- **Payload Sanitization**: Ensure only aggregated/sanitized context is pushed to the cloud `agent_missions` table.

### 3. Mesh Integration
- Use the Teammate Mesh `mesh:tasks` to trigger synchronization jobs across the network.
