# Architecting the Premium Design Doc Generator

## Problem Statement
The OHC Hybrid Agentic OS requires that all architectural and aesthetic decisions be documented in "Premium Design Docs." Currently, there is no standardized, automated way for agents to generate these documents, ensuring they adhere to the "Visual Excellence Mandate" (Glassmorphism, 20px blur, Outfit/Inter typography).

## Research Report
- **Goal:** Design a system for agents to automatically generate premium Markdown/HTML design documents.
- **Context:** Design docs must clearly articulate how OHC implements AI OS features, including backend databases, sequence diagrams, and UI/UX decisions. They must look stunning when rendered.
- **Key Requirements:**
  1.  **Markdown with Inline CSS:** The generator must produce Markdown that embeds specific HTML/CSS structures to achieve the required aesthetic.
  2.  **Standardized Templates:** Define templates for Architectural Overviews, Database Schemas, API Contracts, and Sequence Diagrams.
  3.  **Automation:** Provide a Go library or CLI tool that agents can invoke to compile raw text/mermaid diagrams into the final premium format.

## Design Doc
### Premium Aesthetic Injection
The generator will wrap standard Markdown content in specific HTML `div` tags styled with the mandated CSS.

**Core CSS Tokens:**
```css
.ohc-premium-card {
    backdrop-filter: blur(20px) saturate(200%);
    background: rgba(255, 255, 255, 0.03);
    border: 1px solid rgba(255, 255, 255, 0.1);
    border-radius: 16px;
    padding: 24px;
    font-family: 'Outfit', 'Inter', sans-serif;
    color: #e0e0e0;
}
.ohc-premium-header {
    font-family: 'Outfit', sans-serif;
    font-weight: 700;
    background: linear-gradient(90deg, #ffffff, #a0a0a0);
    -webkit-background-clip: text;
    -webkit-text-fill-color: transparent;
}
```

### Document Structure Template
1.  **Header:** Title, Author (Agent ID), Date, Status (e.g., DRAFT, APPROVED).
2.  **Executive Summary:** High-level overview.
3.  **Architecture / Data Flow:** Embedded Mermaid diagrams.
4.  **Database Schema / API Contracts:** Code blocks and tables.
5.  **Aesthetic / UI Considerations:** Details on how the feature adheres to the visual mandate.

### Architecture Component
Create `srcs/server/docs/generator.go` (or a separate CLI tool if preferred).
Provide a struct `PremiumDocBuilder` with methods like `AddSection(title, content)`, `AddDiagram(mermaidCode)`, and `Render() string`.

## Implementation Prompt
**Title:** Implement Premium Design Doc Generator Library

**Instructions:**
1.  **Library Creation:** Create a new Go package `srcs/server/docs` (or similar logical location).
2.  **Builder Implementation:** Implement the `PremiumDocBuilder` struct. It should accept structured input (sections, diagrams, tables) and compile it into Markdown string.
3.  **CSS Injection:** Ensure the `Render()` method wraps the output in HTML blocks containing the exact CSS properties specified in the Visual Excellence Mandate (`backdrop-filter`, `background`, `font-family`).
4.  **Templates:** Include a set of predefined templates (e.g., `NewArchitectureDocTemplate()`) to ensure consistency.
5.  **Testing:** Write unit tests to verify the generated string contains the required CSS tokens and correctly formats the input content.

This tool will be used by the Orchestrator and Scribe agents to finalize and submit design documents via PR.
