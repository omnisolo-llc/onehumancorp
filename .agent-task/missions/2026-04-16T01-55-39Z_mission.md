# Title: Create Premium Styles and Systematically Hunt Friction in React Components

## Problem Statement
The KAIROS Orchestrator UI components in `apps/web/src/components/orchestration` lack strict adherence to the OHC-SIP (Stylistic Intent Profile) which dictates Glassmorphism, 20px blur, background `rgba(255, 255, 255, 0.03)`, and Outfit/Inter typography. We need a central `apps/web/src/styles/theme.ts` for reusing these premium tokens. In addition, the existing `TaskDAGViewer`, `TeammateMeshConsole`, and `SwarmOverview` need UX refinement to remove friction points (e.g. empty states, better layout, scrolling).

## Research Report
Currently, `apps/web/src/components/orchestration` contains three React components with hardcoded inline styles. We need to create the `apps/web/src/styles/` directory and define a premium theme object.

## Design Doc
1.  **Premium Theme**: Create `apps/web/src/styles/theme.ts` exporting `glassmorphism`, `typography`, and `colors`.
2.  **Component Upgrades**:
    *   `SwarmOverview.tsx`: Apply theme, improve layout spacing.
    *   `TaskDAGViewer.tsx`: Apply theme, add visual cues for different task statuses (e.g. colors for PENDING, COMPLETED), handle empty state.
    *   `TeammateMeshConsole.tsx`: Apply theme, ensure scrolling feels premium.
