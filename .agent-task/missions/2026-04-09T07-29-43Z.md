# Title
KAIROS: Orchestration of Teammate Mesh and AutoDream

# Problem Statement
The OHC platform requires Realtime Teammate Mesh APIs for agent coordination, and an AutoDream data pipeline for long-term memory consolidation, per the OHC architecture vision.

# Research Report
Based on OHC Hybrid Architecture:
- Teammate Mesh must use realtime channels (Redis Pub/Sub in Cloud, local equivalent in Standalone).
- AutoDream data pipelines need to consolidate agent findings into vector representations (pgvector or local equivalent).
- Database migration schemas must be designed for both.

# Design Doc
- **Teammate Mesh**: A realtime communication architecture allowing agents to coordinate via Redis Pub/Sub in Cloud mode or memory channels in Standalone mode. This includes distributed locking.
- **AutoDream Pipeline**: A batch or background process that retrieves recent Swarm execution memories and consolidates them into vector embeddings, tracking consolidation state.

# Implementation Prompt
- Implement the database migration files for AutoDream (`srcs/server/db/migrations/...`).
- Ensure the changes support PostgreSQL and SQLite gracefully.
- Do NOT implement the actual Go backend logic, only output the SQL schema designs as instructed in the orchestrator role.
