# Title: Implement Hybrid Agentic Failover Protocol (HAFP)

## Problem Statement
Competitors like Claude Code fail when local compute is exhausted, while OpenClaw is strictly cloud-bound. OHC's Hybrid Architecture must bridge this gap by allowing standalone local agents to seamlessly package their execution state and failover to the multi-tenant cloud when local resources (tokens, memory) are depleted.

## Research Report
The HAFP market audit reveals that seamlessly escalating a stalled local task to a cloud swarm without exposing private data is a "Blue Ocean" disruption. By serializing the state and utilizing SPIFFE identity encryption, OHC can provide unmatched resilience. See `RESEARCH_REPORT_HYBRID_FAILOVER.md`.

## Design Doc
1. **HAFP Serializer**: A component that snapshots the current `agent_session_data` and DAG state.
2. **Teammate Mesh Gateway**: A secure bridge using SPIRE certificates that transmits the encrypted payload to the Cloud.
3. **Cloud Injection**: The payload is deserialized and injected into the Cloud Postgres `agent_missions` table for Swarm execution.

## Implementation Prompt
**Role**: Implementer
**Task**: Implement the HAFP State Serializer and Teammate Mesh Gateway.
1. Create `srcs/server/orchestration/hafp/serializer.go` to snapshot DAG state.
2. Add the `TeammateMeshGateway` interface to securely transmit the payload.

4. Write tests for serialization and gateway transmission.
