# Mission: Implement KAIROS Orchestrator Core Layers

**Problem Statement**: The OHC swarm lacks a unified KAIROS orchestrator.

**Research Report**: We need to implement the Shared Task List, Teammate Mesh, and AutoDream Pipeline to support autonomous swarm orchestration based on the KAIROS design docs.

**Design Doc**: See `docs/architecture/KAIROS_DESIGN_DOC.md`.

**Implementation Prompt**:
Implement the `swarm_tasks` and `state_machine_transitions` tables in a new SQL migration file (`00X_kairos.sql`).
Create the `MeshTransport` interface in `srcs/server/orchestration/hub.go`.
Use the existing `swarm_memory` vector table (defined in `005_sip.sql`) for the AutoDream pipeline.
All database changes must support both PostgreSQL (with pgvector) and SQLite.

**Priority**: P0
**Estimated Scope**: Large
