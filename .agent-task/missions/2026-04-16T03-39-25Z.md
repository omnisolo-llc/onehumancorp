# Title: Proactive Onboarding Configuration Generation

## Problem Statement
There is a need to dynamically generate system configurations based on the Day One setup mode (Standalone vs Cloud) to streamline the onboarding experience.

## Design Doc
Implemented an `/api/generate-config` endpoint in the `services/onboarding` package that returns optimized swarm sizes, database backends, and cache choices based on the requested mode.
