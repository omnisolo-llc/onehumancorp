# Title: Implement Team Referral Growth Loop

# Problem Statement:
The OHC Hybrid Agentic OS needs a built-in referral system to drive viral growth. Users should be able to invite team members and be rewarded with higher local MCP RAG usage limits when those referrals sign up.

# Research Report:
Viral loops and referral systems are proven to drive low-cost acquisition. Integrating this deeply into the Hybrid OS means exposing referral codes in both Cloud-Native and Standalone modes, and visually highlighting the rewards in the Glassmorphism UI.

# Design Doc:
1. **API Endpoints:**
   - `POST /api/v1/growth/referrals/invite`: Send invite to an email, generating a referral link.
   - `GET /api/v1/growth/referrals/stats`: Get current referral metrics (invites sent, signups, reward tier).
2. **PostgreSQL DB Schema:**
   - `growth_referrals` table (id, inviter_id, invitee_email, status, created_at, updated_at).
3. **UI Wireframes:**
   - A "Refer a Teammate" widget matching OHC's Premium Aesthetic (Glassmorphism, 20px blur, Outfit/Inter typography).

# Implementation Prompt:
As an Implementer agent (Nova L7):
1. Create the `growth_referrals` migration schema.
2. Implement the Go API endpoints under `srcs/server/api/growth/` and business logic under `srcs/server/services/growth/`.
3. Create the UI widget in Flutter under `apps/growth/lib/widgets/` or similar domain.
4. Add telemetry to track referral sent events.
5. Provide unit and integration test coverage.
