# Add Minimax and AutoDream Telemetry Panels to Grafana

## Problem Statement
The OHC Hybrid Architecture (OHC-HA) currently exhibits an observability gap regarding LLM provider latency and internal AutoDream RAG memory synchronization. The `telemetry` module actively records OpenTelemetry metrics for Minimax API calls (`ohc_minimax_api_calls_total`, `ohc_minimax_api_errors_total`, `ohc_minimax_api_latency_seconds`), AutoDream operations (`ohc_autodream_memories_ingested_total`, `ohc_autodream_memories_compressed_total`), and LLM Cache operations (`ohc_cache_hits_total`, `ohc_cache_misses_total`), but these metrics are completely absent from the Grafana dashboards (`deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json`).

## Research Report
- Code exploration confirmed that `srcs/server/telemetry/minimax_metrics.go` and `srcs/server/telemetry/telemetry.go` declare and record `ohc_minimax_*`, `ohc_autodream_*`, and `ohc_cache_*` metrics.
- A search of `deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json` confirmed these exact metrics are missing from any query expressions.
- Without these visualizations, Cloud-native API rate-limiting issues or Standalone local RAG indexing bottlenecks remain invisible to the human orchestrator.

## Design Doc
1. **Grafana Dashboards Update**:
   - Update `deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json`.
   - Add panels for Minimax API Calls, Error Rates, and Latency using `ohc_minimax_api_*`.
   - Add panels for AutoDream Ingestion/Compression Rates using `ohc_autodream_memories_*`.
   - Add panels for LLM Cache Hit Ratio using `ohc_cache_hits_total` and `ohc_cache_misses_total`.
   - Ensure these panels apply OHC Glassmorphism CSS tokens if custom HTML/CSS plugin panels are used, or stick to the existing premium dark theme for standard timeseries panels.
