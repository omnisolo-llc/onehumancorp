# Implement KAIROS Core Orchestration Systems

**Problem Statement**:
The OHC Hybrid OS requires robust implementations for the Shared Task List, Teammate Mesh communication, and the autoDream memory consolidation pipeline to enable swarm intelligence and autonomous task decomposition.

**Research Report**:
Review of `KAIROS_AI_OS_PREMIUM_DESIGN.md` indicates the need for a PostgreSQL/SQLite compatible `shared_tasks_decomposition` table, a Centrifuge/Rueidis backed Teammate Mesh, and a pgvector `autodream_memories` table.

**Design Doc**:
Refer to `docs/architecture/KAIROS_AI_OS_HYBRID_MASTER_PLAN.md` and `CLAUDE_OHC.md` for complete database schemas, sequence diagrams, and UI/UX aesthetic guidelines.

**Implementation Prompt**:
Implement the following:
1. Create database migrations for `shared_tasks_decomposition` and `autodream_memories` (pgvector).
2. Implement `POST /api/v1/mesh/broadcast` in `srcs/server/orchestration/centrifuge_hub.go` using Rueidis (Cloud) and Go channels (Standalone).
3. Implement BullMQ/Celery worker payload structures in `srcs/server/orchestration/queue/queue.go`.
Ensure all code passes >90% test coverage and is verified via `bazelisk test //...`.
