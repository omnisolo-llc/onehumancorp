# Title: Realtime Teammate Mesh APIs (Orchestration)

**Problem Statement:**
Sub-agents need a low-latency, resilient mechanism to broadcast their intentions, claim tasks, and report completion status to other members of the Swarm. Without a realtime communication mesh, state synchronization will rely solely on database polling, leading to latency and excessive load.

**Research Report:**
According to `docs/KAIROS_ORCHESTRATOR_DESIGN.md` phase 2, the Teammate Mesh must implement a generic `MeshTransport` interface. It needs two core implementations: a `RedisMeshTransport` mapping to production Redis Pub/Sub channels (e.g., `mesh:tasks`, `mesh:coordination`) for Cloud-Native mode, and a `MemoryMeshTransport` for Standalone Mode.

**Design Doc:**
1.  **Transport Interface**: Define `MeshTransport` interface with `Publish(channel, message)` and `Subscribe(channel, handler)` methods.
2.  **Redis Implementation**: Implement `RedisMeshTransport` using the go-redis client.
3.  **Memory Implementation**: Implement `MemoryMeshTransport` using Go channels and sync primitives (sync.RWMutex) for local, single-process orchestration.
4.  **Mailbox Protocol**: Define strongly-typed Go structs for standard mesh events: `TaskClaimedEvent`, `TaskCompletedEvent`, `AgentStatusUpdateEvent`.

**Implementation Prompt:**
Implementer Agent, execute the following:
1.  Create `srcs/server/orchestration/hub.go` and define the `MeshTransport` interface.
2.  Create `srcs/server/orchestration/redis_transport.go` implementing `RedisMeshTransport`. Ensure connection pooling is configured.
3.  Create `srcs/server/orchestration/memory_transport.go` implementing `MemoryMeshTransport` using standard Go channels.
4.  Define event payloads in `srcs/server/orchestration/events.go` (e.g., `type TaskClaimedEvent struct { TaskID string; AgentID string }`).
5.  Add unit tests in `srcs/server/orchestration/hub_test.go` mocking the Redis client and testing memory transport concurrency.
6.  Verify tests pass: `bazelisk test //srcs/server/orchestration:orchestration_test`.
