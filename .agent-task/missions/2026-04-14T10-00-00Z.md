<h1>Mission: Implement Zero-Trust Agent Identity via SPIFFE/SPIRE</h1>

<b>Title:</b> Zero-Trust Agent Identity Implementation
<b>Problem Statement:</b> The OHC Swarm currently lacks a unified, cryptographically verifiable identity framework. This deficiency prevents secure, secret-less delegation and robust auditability across the Teammate Mesh, particularly in multi-tenant cloud-native deployments where tenant isolation is paramount.
<b>Priority:</b> P0
<b>Estimated Scope:</b> Large

<h2>Research Report</h2>
<b>Findings:</b>
1. <b>SPIFFE/SPIRE Standard:</b> The Secure Production Identity Framework for Everyone (SPIFFE) provides a cross-platform identity standard. SPIRE (the SPIFFE Runtime Environment) enables issuing SPIFFE Verifiable Identity Documents (SVIDs) to agents based on their workload attributes.
2. <b>mTLS & Secret-less Auth:</b> By using SVIDs (X.509 certificates), agents can establish mTLS connections for all Mesh communication (gRPC, WebSockets via Centrifuge), eliminating the need for static API keys or JWTs for internal agent-to-agent talk.
3. <b>Multi-tenancy:</b> SPIFFE IDs can encode the `organization_id`, ensuring that agents can only join channels and access data belonging to their specific tenant.

<h2>Design Doc</h2>
<b>1. Identity Architecture</b>
- <b>SVID Schema:</b> `spiffe://ohc.internal/org/{org_id}/agent/{agent_id}`
- <b>SVID Validator:</b> A new Go library in `lib/integrations/spiffe_validator.go` to handle the parsing and cryptographic verification of SVIDs against the SPIRE Trust Bundle.

<b>2. Mesh Integration</b>
- <b>Middleware:</b> Update `srcs/server/orchestration/auth_interceptor.go` and Centrifuge connection handlers to extract and verify the SPIFFE ID from the client certificate.
- <b>Registry:</b> Extend the Agent Registry to include `spiffe_id` as a primary identifier.

<b>3. Hybrid Mode Strategy</b>
- <b>Cloud:</b> Full SPIRE integration with Kubernetes Workload Attestors.
- <b>Standalone:</b> A "Self-Signed Trust Bundle" generated during `ohc-setup.sh` to provide identity parity on the local machine without a full SPIRE deployment.

<h2>Implementation Prompt</h2>
Implementer, execute the following:
1. <b>Library Implementation:</b> Create `lib/integrations/spiffe_validator.go`. Implement `VerifyAgentIdentity(ctx context.Context, cert []byte) (*IdentityClaims, error)` which validates the SVID and extracts the `org_id` and `agent_id`.
2. <b>Middleware Integration:</b> Update `srcs/server/orchestration/centrifuge_hub.go`. In the `OnConnecting` handler, check for client certificates and verify them using the new library. Reject connections without a valid SVID if `OHC_ENFORCE_ZERO_TRUST=true`.
3. <b>SVID Generation (Local):</b> Add a helper in `srcs/server/utils/identity.go` to generate temporary X.509 SVIDs for standalone mode.
4. <b>Observability:</b> Add OpenTelemetry counters: `ohc_identity_verification_success_total` and `ohc_identity_verification_failure_total`.
5. <b>Verification:</b> Create `tests/integration/spiffe_identity_test.go` simulating an agent-to-agent Mesh broadcast secured by SVIDs.
