# Problem Statement
OHC Swarm agents accumulate ephemeral session context rapidly, leading to context window overflow. A background pipeline is required to compress, embed, and consolidate these memories into a vector database for long-term semantic search.

# Research Report
- **Storage:** Use PostgreSQL with the `pgvector` extension for Cloud-Native exact nearest neighbor search. Fall back to text blob storage in SQLite for Standalone Mode.
- **Processing:** Utilize existing LLM clients to generate embeddings.
- **Schema Status:** The `autodream_memories` table already exists in migrations (`024_autodream_memories.sql` and `029_autodream_memories.sql`).

# Design Doc
**Architecture:** An `AutoDreamWorker` daemon running periodically to sweep ephemeral session data and write to the existing `autodream_memories` schema.
**UI Aesthetic:** Must apply `<style>body { backdrop-filter: blur(20px) saturate(200%); background: rgba(255, 255, 255, 0.03); font-family: 'Outfit', 'Inter', sans-serif; }</style>`.
