# Research Report
Realtime messaging is critical for Swarm Intelligence. We need a `POST /api/mesh/v2/broadcast` HTTP endpoint that pushes events to the Teammate Mesh. In Cloud-Native Mode, it must use Redis Pub/Sub (`rueidis`). In Standalone Mode, it must degrade to an in-memory Go channel broker.
