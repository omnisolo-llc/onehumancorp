# Title: Implement KAIROS Hybrid Architecture Shared Task Decomposition

## Problem Statement
The OHC Swarm needs a robust, scalable backend to manage and decompose shared tasks seamlessly across both Standalone and Cloud-Native modes, ensuring no race conditions when agents claim tasks.

## Research Report
Based on OHC's Hybrid Architecture (OHC-HA), we need a unified backend schema that works with PostgreSQL (using `SELECT FOR UPDATE SKIP LOCKED` for concurrency) and SQLite (using mutexes). References: `docs/architecture/KAIROS_AI_OS_HYBRID_ORCHESTRATION_MASTER.md` and `docs/architecture/kairos_shared_task_mesh.md`.

## Design Doc
See `docs/architecture/KAIROS_AI_OS_HYBRID_ARCH_DECOMPOSITION.md` for the full technical design, schema, and sequence diagrams.

## Implementation Prompt
1. Create a new SQL migration file in `srcs/server/db/migrations/` for the `shared_tasks_decomposition` table using PostgreSQL syntax.
2. Update `srcs/server/db/BUILD.bazel` to include the new migration file.
3. Implement a new Go repository interface and Postgres/SQLite provider implementations in `srcs/server/db/` to handle task claiming logic.
4. Ensure robust test coverage in `srcs/server/db/provider_test.go`.
