# Title: Integrate Hybrid Search MCP Server

## Problem Statement
The OHC Hybrid Architecture requires a seamless way for agents to search through internal documentation and web resources regardless of whether the system is running in Cloud-native Mode or Standalone Desktop Mode. Currently, agents lack a unified search Model Context Protocol (MCP) server that seamlessly transitions between local document indexing (SQLite FTS/Vector) in Standalone mode and distributed enterprise search (PostgreSQL pgvector / external web search APIs) in Cloud mode.

## Research Report
- **Market Context**: Most agentic systems rely on fixed search tools (e.g., exclusively Google/Brave API or exclusively local Milvus/ChromaDB). Claude Code only searches local file directories, while Replit relies on the cloud.
- **OHC Requirement**: We need a "Hybrid Search MCP Server" that dynamically selects the best search backend. In Standalone Mode, it should query local SQLite full-text search and embeddings for immediate, private context. In Cloud Mode, it should perform multi-tenant aware searches using pgvector and external provider APIs (e.g., Tavily or Brave) to enrich the context dynamically.
- **Tooling Discovery**: A unified MCP Server wrapping an interface like `mcp.SearchProvider` allows agents to use a single tool (`unified_search`) and let the orchestration Hub seamlessly route to Cloud or Local implementations based on `OHC_STANDALONE`.
- **Security & Multi-Tenancy**: In Cloud mode, search queries and retrieved context must be strictly isolated using `auth.Claims.OrganizationID` to prevent cross-tenant data leakage.

## Design Doc
- **Module Path**: `srcs/server/tools/searchmcp`
- **Architecture**:
  - Expose tools: `unified_search`, `index_document`.
  - Backed by an interface `mcp.SearchProvider`.
  - **Local Implementation (`LocalSearchProvider`)**: Queries local SQLite using FTS5 and limits external outbound requests to ensure privacy.
  - **Cloud Implementation (`CloudSearchProvider`)**: Queries PostgreSQL pgvector with tenant scoping (`WHERE tenant_id = $1`) and falls back to an external web search API if configured.
  - Injects `auth.Claims` from the context for security isolation.
