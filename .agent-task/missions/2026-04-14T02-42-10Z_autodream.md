# Mission: KAIROS autoDream Memory Consolidation Pipeline
## Problem Statement
The OHC swarm requires a long-term memory system to consolidate agent interactions into durable knowledge.

## Research Report
Background workers need to parse `.agent-task/memory/*.yml` files, generate embeddings, and store them in PostgreSQL with pgvector for efficient similarity search.

## Design Doc
**Database Schema (PostgreSQL):**
```sql
CREATE TABLE IF NOT EXISTS consolidated_memory (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    content TEXT NOT NULL,
    embedding vector(1536),
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
```

## Implementation Prompt
1. Add a migration file `srcs/server/db/migrations/` to create `consolidated_memory` using the pgvector extension.
2. Implement an `AutoDreamWorker` in `srcs/server/orchestration/autodream_worker.go` that runs periodically.
3. Add a test in `srcs/server/orchestration/autodream_worker_test.go` verifying basic functionality.
