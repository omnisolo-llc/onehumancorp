# Problem Statement
Complex tasks often require delegating work to specialized sub-agents. The Shared Task List needs to seamlessly interface with the background Sub-Agent Orchestration Queue.

# Research Report
Instead of executing long-running logic inline during a state transition, the orchestrator should drop a message into `sub_agent_jobs` and let dedicated workers pick it up.

# Design Doc
Refer to `docs/architecture/kairos_task_decomposition_design.md`.

# Implementation Prompt
Implement middleware that intercepts tasks reaching the `EXECUTE` stage. If the task has an `assigned_agent_id` corresponding to a background sub-agent pool, create a job in `sub_agent_jobs` and track its execution. Write test coverage validating the integration between tasks and jobs.
