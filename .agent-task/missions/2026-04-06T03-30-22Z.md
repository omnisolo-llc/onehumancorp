# 🗺️ Guide: [new onboarding feature] Interactive Standalone Mode Audit

## Problem Statement
New developers evaluating OHC in Standalone Desktop Mode often face friction when attempting to run local hybrid tools because they are unsure if SQLite migrations have successfully executed or if their `.env` matches the CLI's expectations.

## Implementation Details
1. I will extend the `ohc_hybrid_cli.sh` script to add an explicit "Standalone DB Health Check".
2. The check will verify if `sqlite3` is installed and attempt to read the tables from `local_standalone.db`.
3. This creates a true "Day One" safety net that aligns with our Onboarding Truth guidelines.
