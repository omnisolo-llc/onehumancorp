# UI Glassmorphism Update for _ChannelCard

## Problem Statement
The channels screen list cards did not use the mandated OHC Glassmorphism visual tokens (blur, high saturation, tactile animations).

## Research Report
Inspecting `channels_screen.dart` revealed `_ChannelCard` was a standard stateless widget that needed an upgrade to a `StatefulWidget` wrapping an `AnimatedScale` and `BackdropFilter` with `ui.ImageFilter.blur(sigmaX: 20.0, sigmaY: 20.0)` to meet the aesthetic standards.

## Design Doc
Replaced the `StatelessWidget` with a `StatefulWidget` using `SingleTickerProviderStateMixin` and `MouseRegion`. This provides hover states that trigger `AnimationController` for smooth scale transitions (1.0 to 1.02) and dynamic opacity shifts in the backdrop.

## Implementation Prompt
Update `_ChannelCard` to feature glassmorphism UI correctly, maintain full compatibility with `ChatChannel` model, and ensure no backend data providers are broken or mocked.
