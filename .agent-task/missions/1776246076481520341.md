# Title: Implement Vector Memory Visualizer Widget

## Problem Statement
The OHC Hybrid Agentic OS requires a visual component to display vector memories stored via the AutoDream pipeline. As the Palette agent, we need to create a high-fidelity Flutter widget in `srcs/app/lib/widgets/` to visualize these memories using Glassmorphism, bringing parity between backend observability and front-end delight.

## Research Report
Currently, the AutoDream system consolidates memories into `pgvector`, but there's no UI component to display these compressed memories. A dedicated `VectorMemoryVisualizerWidget` is required.

## Design Doc
1. Create `srcs/app/lib/widgets/vector_memory_visualizer.dart`.
2. Implement Glassmorphism styling (`sigmaX: 20.0`, `sigmaY: 20.0`, `Color.fromRGBO(255, 255, 255, 0.03)`).
3. Use 'Outfit' or 'Inter' typography.
4. Add micro-animations using `AnimationController` for memory node pulses.
5. Write tests in `srcs/app/test/widgets/vector_memory_visualizer_test.dart`.

## Implementation Prompt
Implement `VectorMemoryVisualizerWidget` as a `StatefulWidget` displaying simulated vector nodes (small circular indicators or lines). Ensure adherence to the Visual Excellence Mandate and include proper tests.
