# Mission: Preflight Verification Endpoint

## Problem Statement
The onboarding flow currently provisions state but lacks a robust "Preflight" verification step before actual provisioning occurs. This causes friction when users attempt to provision Cloud-native or Standalone environments without properly configuring pre-requisites.

## Design Doc
Expose a `POST /api/wizard/preflight` endpoint in `services/onboarding/server.go` and register it in `apps/onboarding/main.go`. It will accept the proposed deployment mode and return a list of verified checks to ensure the "Day One" experience is frictionless.
