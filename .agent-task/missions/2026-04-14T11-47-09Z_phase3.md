# Problem Statement
When Shared Tasks finish, their output and intermediate reasoning are lost unless deliberately saved. We need to feed completed task outcomes into the long-term memory vector database.

# Research Report
The autoDream vector architecture utilizes `pgvector` on Cloud and SQLite-VSS locally. We should trigger the existing memory consolidation worker when a high-priority task enters the `DONE` state.

# Design Doc
Refer to `docs/architecture/kairos_task_decomposition_design.md` and `docs/features/kairos/autodream_pipeline.md`.

# Implementation Prompt
Extend the Shared Task completion logic to enqueue an asynchronous job for the autoDream pipeline. The job payload should contain the `task_id` and the `result` payload. Provide integration tests.
