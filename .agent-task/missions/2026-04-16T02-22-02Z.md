# Title: Implement Free-Tier Invite Quotas for Growth Loop

## Problem Statement
To optimize viral coefficient without incurring massive abuse, we need to implement a free-tier quota system for team invites. This directly drives acquisition while protecting resources in the Hybrid Agentic OS.

## Research Report
Current `ReferralService` does not limit the number of invites a sender can process. Adding a `QuotaService` that enforces a maximum number of invites per user (e.g., 5 for free tier) will create a viral loop upgrade path.

## Design Doc
1. `services/growth/quota.go`: `QuotaService` with `CheckAndIncrement(ctx, userID)`
2. `lib/analytics/growth_metrics.go`: Add telemetry for `quota_exceeded`.
3. Update `services/growth/BUILD.bazel` and `lib/analytics/BUILD.bazel` if needed.

## Implementation Prompt
Implement `QuotaService` in `services/growth/` and integrate `quota_exceeded` metric in `lib/analytics/`. Add thorough tests to verify behavior.
