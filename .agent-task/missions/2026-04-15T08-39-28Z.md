# Title: Swarm Orchestration UI Dashboards

**Problem Statement:**
While the backend KAIROS Orchestration infrastructure is defined (Phase 1-3), there is no unified dashboard for the Human CEO to visually monitor the Swarm, manage the Shared Task List, or observe the Teammate Mesh in realtime. Without a premium interface, the Swarm remains a black box.

**Research Report:**
The `docs/KAIROS_ORCHESTRATOR_DESIGN.md` phase 5 and the Visual Excellence Mandate dictate strict aesthetic requirements for any OHC UI components: Glassmorphism (`backdrop-filter: blur(20px) saturate(200%)`), dark-mode base (`background: rgba(255, 255, 255, 0.03)`), and specific typography (`'Outfit', 'Inter', sans-serif`). The dashboard needs to visualize the `swarm_tasks` status, display realtime messages from the Teammate Mesh (via WebSockets), and provide controls to pause or kill sub-agent workflows.

**Design Doc:**
1.  **Component Architecture**: Build React components within `apps/web/src/components/orchestration/`.
2.  **Key Views**:
    *   `SwarmOverview`: High-level metrics (active agents, completed tasks).
    *   `TaskDAGViewer`: Visual representation of parent-child dependencies and task statuses (PENDING, EXECUTING, COMPLETED).
    *   `TeammateMeshConsole`: A scrolling log of realtime events broadcast over the `RedisMeshTransport` or `MemoryMeshTransport`.
3.  **Aesthetic Enforcement**: Ensure all components strictly implement the CSS classes or styled-components defining the premium Glassmorphism look.
4.  **API Integration**: Connect the frontend to backend endpoints (e.g., `/api/v1/orchestration/tasks`, Centrifuge WebSocket for realtime events).

**Implementation Prompt:**
Implementer Agent (Palette Persona), execute the following:
1.  Create `apps/web/src/components/orchestration/TaskDAGViewer.tsx` to visualize the Shared Task List. Ensure it uses the exact Glassmorphism styles defined in the design doc.
2.  Create `apps/web/src/components/orchestration/TeammateMeshConsole.tsx` to display realtime websocket messages.
3.  Integrate these components into the main dashboard view at `apps/web/src/pages/Dashboard.tsx`.
4.  Write visual/component tests using Playwright or React Testing Library.
5.  Verify the UI manually using the `browser` tool or equivalent verification script to ensure the "Premium Feel" is achieved without visual bugs.
