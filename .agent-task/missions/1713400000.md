# Simplify Cloud vs Standalone Onboarding Modes

Implement explicit config profiles in `services/onboarding/server.go` for the onboarding wizard:

1. Add `CloudProfile` and `StandaloneProfile` helper functions that return pre-configured `EnvConfig` setups.
2. Update `VerifyEnvironment` in `services/onboarding/env_verifier.go` to explicitly require `DATABASE_URL` ONLY for cloud mode, and fallback to `sqlite://local.db` for standalone.
3. Expose a new `/api/wizard/profile` endpoint in `services/onboarding/server.go` and `apps/onboarding/main.go` that returns these preset profiles to the UI.
4. Add unit tests for the new profile endpoint and the modified verification logic.
