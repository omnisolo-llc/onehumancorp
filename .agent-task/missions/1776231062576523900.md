# Title: KAIROS AI OS AutoDream Implementation

## Problem Statement
The OHC Hybrid OS requires robust orchestration logic to correctly route decomposed tasks using Teammate Mesh and AutoDream consolidation. The AutoDream memory consolidation pipeline must vectorize architectural decisions and successful task executions into `autodream_memories` using `pgvector`.

## Research Report
The current implementation of `SharedTaskOrchestrator` in `tasks_db.go` successfully manages `shared_tasks_v4` state transitions. However, the system is missing the top-level master loop needed to decompose features. We need a distributed Sub-Agent spawning queue that integrates with `queue.go`.

## Design Doc
1. Define a `JobQueue` schema and struct in `srcs/server/orchestration/queue.go`
2. Define a BullMQ worker mapping that delegates a High-Level Task into `SharedTaskDB` records.
3. Hook up `AutoDream` memory vectorization using pgvector upon completion.
4. Update `srcs/server/orchestration/tasks.go` to publish Mesh Events and consolidate to `AutoDream` on task COMPLETION.

## Implementation Prompt
Update `srcs/server/orchestration/tasks.go` to publish Mesh Events and consolidate to `AutoDream` on task COMPLETION. Hook into `SharedTaskOrchestrator` to detect task transitions to 'COMPLETED'. Send the `payload` and `deliberation_log` through the `AutoDream` service for vectorization.
