<h1>Mission: Implement KAIROS AI OS Foundation</h1>
<b>Title:</b> Implement KAIROS Orchestration (Shared Task List, Teammate Mesh, AutoDream)
<br>
<b>Problem Statement:</b> The OHC Hybrid Agentic OS requires scalable, robust backend foundations to orchestrate a vast swarm of AI agents, handling both Cloud-Native mode with PostgreSQL/Redis and Standalone Desktop mode with SQLite/In-Memory structures.
<br>
<b>Research Report:</b> Competitors struggle with balancing local privacy and cloud scalability. The OHC-HA architecture uses Hybrid RAG workflows. By using PostgreSQL with FOR UPDATE SKIP LOCKED combined with an SQLite fallback using explicit transactions, we achieve unparalleled horizontal scaling and local performance.
<br>
<b>Design Doc:</b>
<br>
<b>1. Shared Task List (Distributed State Machine)</b><br>
<b>PostgreSQL Schema:</b><br>
<code>
CREATE TABLE IF NOT EXISTS shared_tasks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    organization_id VARCHAR NOT NULL,
    title VARCHAR NOT NULL,
    description TEXT,
    status VARCHAR NOT NULL DEFAULT 'PENDING',
    agent_id VARCHAR,
    priority VARCHAR NOT NULL DEFAULT 'P2',
    payload JSONB,
    parent_plan_id TEXT,
    dependencies JSONB NOT NULL DEFAULT '[]',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
</code><br>
<b>SQLite Fallback Schema:</b><br>
<code>
CREATE TABLE IF NOT EXISTS shared_tasks (
    id TEXT PRIMARY KEY,
    organization_id TEXT NOT NULL,
    title TEXT NOT NULL,
    description TEXT,
    status TEXT NOT NULL DEFAULT 'PENDING',
    agent_id TEXT,
    priority TEXT NOT NULL DEFAULT 'P2',
    payload TEXT,
    parent_plan_id TEXT,
    dependencies TEXT NOT NULL DEFAULT '[]',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
</code><br>
<b>2. Teammate Mesh APIs</b><br>
Endpoints: POST /api/mesh/broadcast and GET /api/mesh/subscribe.<br>
Payload Contract (OHC-SIP Compliant):<br>
<code>
{
    "agent_id": "sub_agent_xyz123",
    "action": "TaskCompleted",
    "status": "success",
    "payload": { "task_id": "task_abc", "result": "..." }
}
</code><br>
<b>3. AutoDream Data Pipelines</b><br>
Polls .agent-task/memory/*.yml, generates LLM embeddings, stores in pgvector (autodream_memories).<br>
