# Title: Implement Cross-Mode Mission Handoff for Teammate Mesh

## Problem Statement
The OHC swarm requires a seamless mechanism to hand off and broadcast tasks across different agents, regardless of whether the system is running in Cloud Mode (PostgreSQL/Redis) or Standalone Desktop Mode (SQLite/Local). The Teammate Mesh currently lacks a unified handoff abstraction to seamlessly broadcast tasks (`EventTaskBroadcast`).

## Research Report
- Standalone Mode: Lacks Redis, so tasks must be written locally and possibly polled or signaled via local channels.
- Cloud Mode: Uses Redis Pub/Sub (`mesh:tasks`) to fan out tasks to all subscribers across multiple pods.
- We need an adapter that checks the environment and gracefully handles the task broadcast.

## Design Doc
1. **Handoff Interface**:
   - Create `srcs/server/interop/handoff.go`.
   - Implement `CrossModeHandoff` which takes a `db.Provider` and optional `rueidis.Client`.
2. **Logic**:
   - `BroadcastTask(ctx context.Context, task EventTaskBroadcast)`:
     - Always persist the task to `shared_tasks` (using `db.Provider`).
     - If `rueidis.Client` is not nil, marshal the task and publish it to the `mesh:tasks` channel.

## Implementation Prompt
- Implement `CrossModeHandoff` and ensure proper testing for both standalone and cloud modes.
