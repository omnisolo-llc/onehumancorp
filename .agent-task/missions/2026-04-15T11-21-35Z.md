# Title: Phase 8 - Stateful Episodic Memory & LangGraph Checkpointing

## Problem Statement
One Human Corp agents currently suffer from "Agent Amnesia"—the inability to persist complex execution states across disjointed sessions. While AutoDream handles long-term semantic memory, it does not preserve the fine-grained execution graph state required for reliable task resumption and multi-step reasoning recovery. This results in lost progress when sessions are interrupted or when scaling across the Hybrid Architecture.

## Implementation Details
1. Created `056_langgraph_checkpoints.sql` defining `swarm_checkpoints` table with `thread_id` and `checkpoint_id` tracking.
2. Implemented `pg_saver.go` containing `PGSaver` struct using `db.Provider`. It intelligently handles both PostgreSQL and SQLite DB contexts using UPSERT.
3. Implemented `pg_saver_test.go` with an in-memory SQLite provider to test the save and retrieve cycle.
4. Integrated CheckpointSaver into the `DefaultTaskOrchestrator`.
