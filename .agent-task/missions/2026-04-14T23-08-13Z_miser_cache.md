# Problem Statement
API calls to LLMs for generating responses and embeddings represent a significant operational cost. Duplicate or similar queries generated by the Swarm Intelligence Protocol are frequently sent to the LLM API, resulting in redundant token spending. We need a way to cache these responses locally to reduce API costs.

# Design Doc
Implement a local cache for LLM prompts/responses and embeddings in `lib/pricing/cache.go`.

- **LocalEmbeddingCache**: A thread-safe, in-memory cache to store LLM responses with a Time-To-Live (TTL).
- **Methods**:
  - `Get(prompt string) (string, bool)`
  - `Set(prompt, response string)`
  - `Clear()`
  - `Prune() int`

Write unit tests in `lib/pricing/cache_test.go` to ensure correctness and thread safety. Include the new files in `lib/pricing/BUILD.bazel`.
