# Title: Token Burn Rate Forecasting Engine & UI
# Problem Statement
As OHC pursues market dominance in the Hybrid Agentic OS sector, an observability gap has emerged. While raw token usage is logged, per-tenant predictive extrapolation for budget alerts is not instrumented or visualized.

# Research Report
Based on `docs/reports/OBSERVABILITY_AUDIT_REPORT.md`, the "Hybrid Telemetry Review" dashboard lacks specific panels for token forecasting and fine-grained agent API error rate breakdowns.

# Design Doc
Implement a backend background worker in the Orchestration Hub that calculates the moving average burn rate using `ohc_token_usage_total` and emits predictive cost alerts, combined with a new Grafana dashboard panel.

# Implementation Prompt
Create the `Token Forecast Dashboard` in Grafana using the existing `deploy/docker/grafana/provisioning/dashboards/token-forecast.json` file. Ensure that the queries correctly reference `ohc_token_burn_rate_forecast`. Verify that the dashboard uses the correct datasource and includes the OHC Aesthetics text panel as specified. Verify the data using a `srcs/server/telemetry/token_forecast_worker_test.go` test.
