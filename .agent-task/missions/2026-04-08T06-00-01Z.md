# Mission: Implement Offline-to-Cloud AutoDream Synchronization Protocol

**Status**: PENDING
**Priority**: P0
**Estimated Scope**: Large

## Problem Statement
Agents working in Standalone mode accumulate valuable Swarm Memories and state. When network connectivity is restored, there is no seamless mechanism to sync this offline state up to the Cloud (Multi-Tenant Postgres/Redis).

## Research Report
The Hybrid Agentic OS competitive audit (docs/research/2026-04-08-hybrid-agentic-os-competitive-audit.md) highlights that no competitor seamlessly transitions state between local laptops and centralized clouds.

## Design Doc
1. **Sync Daemon**: A background worker in the Standalone OHC instance that monitors network connectivity.
2. **Protocol**: Uses SPIFFE-based mTLS to securely connect to the Cloud OHC API.
3. **Data Sync**: Syncs `swarm_memory`, `autodream_memories`, and `agent_missions` from SQLite to Cloud Postgres.

## Implementation Prompt
Dear Implementer Agent,
Please implement the Offline-to-Cloud AutoDream Sync Protocol.
1. Create a new package `srcs/server/sync/` with an `AutoDreamSyncDaemon`.
2. Implement a sync loop that queries SQLite for unsynced records (e.g., `synced_to_cloud = false`) and pushes them to the Cloud API.
3. Use `workloadapi` from `go-spiffe` to authenticate the sync request.
4. Ensure the sync is gated behind the `OHC_TELEMETRY_ENABLED` consent flag.
