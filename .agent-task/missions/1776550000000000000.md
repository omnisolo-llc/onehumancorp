# Day One Setup Thin Client Mode

## Problem Statement
The OHC Hybrid Architecture supports three modes: Cloud-Native Mode, Standalone Desktop Mode, and Thin Client Mode. Currently, `env_verifier.go` in `services/onboarding` only supports `standalone` and `cloud` modes. It needs to support `thin_client` mode as well.

## Design Doc
1. Update `VerifyEnvironment` in `services/onboarding/env_verifier.go` to accept "thin_client" as a valid `OHC_SOURCE_MODE`.
2. Add a new configuration property for remote endpoints in `EnvConfig` (e.g. `RemoteEndpoint string`).
3. If the mode is "thin_client", require a new environment variable `OHC_REMOTE_ENDPOINT`.
4. Update tests in `env_verifier_test.go` to cover `thin_client` mode (valid and missing endpoint).
5. Ensure `apps/onboarding/main.go` and other files build correctly.
