# Title: Integrate Omni-Context Sub-agent Routing for Hybrid OS

## Problem Statement
Current agent OS architectures (like Claude Code and Replit Agent) suffer from context latency and grounding drift because sub-agents must explicitly fetch project rules (e.g., `AGENTS.md`, `CLAUDE.md`) at runtime using file system tools. This increases time-to-first-token, inflates inference costs, and risks task drift if the agent fails to fetch the correct files. While OpenClaw routes via channels and OpenCode uses project files, neither perfectly bridges the gap across the cloud-to-standalone environments automatically.

OHC has an "Unfair Advantage" because its Swarm Intelligence Protocol (OHC-SIP) allows us to inject this context systematically at delegation time. This mission initiates the Omni-Context Sub-agent Routing pattern.

## Research Report
The market audit (documented in `RESEARCH_REPORT.md` and `RESEARCH_REPORT_HYBRID.md`) reveals that pre-injecting global project context directly into the sub-agent prompt payload is a high-value "Blue Ocean" disruption. By leveraging the Swarm Intelligence Protocol (OHC-SIP) and the existing `agent_missions` framework, OHC can eliminate tool-call latency for grounding, achieving perfect architectural alignment deterministically.

## Design Doc
1. **Context Injector Mechanism:** Create a centralized context injector that runs when a mission is initialized/delegated.
2. **Payload Augmentation:** When a mission is created, the system should synchronously scan the repository root for key files (e.g., `AGENTS.md`, `CLAUDE.md`).
3. **DB Injection:** The contents of these files should be appended to the mission `payload` or context blob under a clear delimiter, such as `[SYSTEM GROUNDING]`.
4. **Data Layer Verification:** Ensure this payload is seamlessly distributed across the hybrid boundary, working robustly whether locally backed by SQLite or synced via Postgres.

## Implementation Prompt
**Role:** Implementer
**Task:** Build Omni-Context Routing into the Orchestrator.

1. **Locate Delegation Logic:** Identify where new records are inserted into the `agent_missions` or task delegation frameworks.
2. **Implement File Scanner:** Add a utility function to safely read `AGENTS.md` and `CLAUDE_OHC.md` from the context root. Handle cases where these files might not exist gracefully.
3. **Modify Payload:** Before the payload string/JSON is written to the database, append the file contents under a header:
   ```
   [SYSTEM GROUNDING]
   <contents of AGENTS.md>
   ```
4. **Testing:** Write unit tests demonstrating that when a mission is created, the resulting payload contains the file text. Ensure graceful degradation.
5. **Database Updates:** Verify no column size limits are breached in PostgreSQL or SQLite.
6. **Execute Tests:** Run `bazelisk test //srcs/server/...` to confirm everything works.
