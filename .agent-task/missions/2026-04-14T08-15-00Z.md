**Title**: Enhance Observability: Sub-Agent Queue and autoDream Vector Latencies

**Problem Statement:**
The OHC Hybrid Agentic OS lacks crucial observability for Sub-Agent queue wait times and autoDream vector compression latencies. Without separating these metrics by Cloud-Native vs Standalone modes, we cannot detect scaling bottlenecks.

**Research Report:**
- Current State: telemetry tracks queue lengths and execution duration, but not wait time between enqueue and start.
- autoDream Consolidation: Memory consolidation lacks histogram tracking for vector embeddings pipeline.

**Design Doc:**
1. Telemetry Additions: SubAgentQueueWaitTime and AutoDreamCompressionLatency (metric.Float64Histogram).
2. API Contracts: RecordSubAgentQueueWaitTime and RecordAutoDreamCompressionLatency.
3. Architecture: Distinguish between standalone and cloud using deployment_mode attribute.

**Implementation Prompt:**
1. Initialize Metrics in srcs/server/telemetry/telemetry.go.
2. Instrument Queue in srcs/server/orchestration/queue/worker.go using time.Since(job.CreatedAt).
3. Instrument autoDream in srcs/server/orchestration/autodream.go in compressSessionData.
4. Testing: Write tests in srcs/server/telemetry/telemetry_test.go. Set DATABASE_URL to sqlite://:memory: for SQLite tests.

**Priority:** P1 (High)
**Estimated Scope:** Medium
