# Mission: KAIROS Orchestration Teammate Mesh Architecture
## Problem Statement
Agents require a highly available realtime communication layer for task assignment and status updates.

## Research Report
The architecture dictates `LocalTeammateMesh` utilizing the `mesh:tasks` and `mesh:coordination` channels over Redis Pub/Sub in Cloud-Native mode, and in-memory Go channels for Standalone Mode.

## Design Doc
**Architecture:**
- Create a generic `TeammateMesh` interface in `srcs/server/orchestration/mesh/mesh.go` supporting `Publish(channel, msg)` and `Subscribe(channel)`.
- Create `RedisMesh` using `rueidis` for distributed pub/sub.
- Create `LocalTeammateMesh` using Go channels for standalone.

## Implementation Prompt
1. Define the `TeammateMesh` interface in `srcs/server/orchestration/mesh/mesh.go`.
2. Implement `RedisMesh` and `LocalTeammateMesh` matching the interface.
3. Integrate the mesh into the `TaskOrchestrator` to publish events when a task status changes.
