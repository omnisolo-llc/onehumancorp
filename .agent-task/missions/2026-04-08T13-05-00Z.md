# Title: Bridge Remaining Observability Gaps (Hybrid Sync, AutoDream, and Caching)

**Priority:** P2
**Estimated Scope:** Medium

## Problem Statement
While recent telemetry updates have bridged several critical gaps (Token Burn Rate, SQLite Concurrency), an ongoing audit of the OHC Hybrid Architecture (OHC-HA) reveals that critical system components still lack visual observability in our centralized Grafana dashboards. Specifically, Hybrid Synchronization latencies (`ohc.sync.latency_ms`, `sync_completed_count`, `sync_failed_count`), AutoDream RAG queries (`ohc_autodream_query_duration_seconds`, `ohc_autodream_sync_duration_seconds`), and LLM Response Caching (`ohc_cache_hits_total`, `ohc_cache_misses_total`) are instrumented in the backend but lack Grafana dashboard visualization. This prevents proactive bottleneck detection for cloud-sync delays and local AI token waste.

## Research Report
As a RESEARCHER agent, I cross-referenced the active backend metrics exported by OpenTelemetry (`srcs/server/telemetry/telemetry.go`) with the currently provisioned Grafana dashboard (`deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json`).
Key findings:
- **Hybrid Data Sync:** In Cloud-Native vs Standalone modes, understanding how frequently Standalone nodes push metrics/data to the cloud is paramount. The backend exposes `ohc.sync.latency_ms`, `sync_completed_count`, `sync_failed_count`, and `sync_daemon_batch_size`.
- **AutoDream Latency:** The system emits `ohc_autodream_query_duration_seconds` and `ohc_autodream_sync_duration_seconds`, but no P95 latency panels exist to compare AutoDream speed locally (SQLite) vs Cloud (pgvector).
- **LLM Token Conservation:** To understand whether our token caching is effective across tenants, we need visibility into `ohc_cache_hits_total` vs `ohc_cache_misses_total`.
Competitors rely heavily on caching observability to control costs. Ensuring these metrics are highly visible is crucial for Hybrid Agentic OS self-correction.

## Design Doc
1. **Grafana Dashboards Update (`deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json`)**:
   - Add a new "Hybrid Sync Latency (P95)" panel targeting `histogram_quantile(0.95, rate(ohc.sync.latency_ms_bucket[5m]))` or equivalent expression.
   - Add a new "AutoDream P95 Latency" panel targeting `histogram_quantile(0.95, sum by (le, deployment_mode) (rate(ohc_autodream_query_duration_seconds_bucket[5m])))`.
   - Add a new "LLM Cache Hit Ratio" panel targeting `sum(rate(ohc_cache_hits_total[5m])) / (sum(rate(ohc_cache_hits_total[5m])) + sum(rate(ohc_cache_misses_total[5m])))`.
