# Day One Setup Environment Verification Refactoring
Implement Day One setup simplified environments checking for Standalone Desktop Mode and Cloud-native K8s environment.

## Problem
The `RunDiagnostics` function in `srcs/server/services/onboarding/diagnostics.go` is not verifying the `.ohc-local-data` and `.ohc-cloud-data` directories that are provisioned by `ProvisionEnvironment` in `provisioner.go`.
It also hardcodes `runtime`, `memory`, and `status` which don't map to `db`, `blob`, and `config` dirs actually created by the provisioner.
Additionally, the system needs to support simplified checking of these directories.

## Solution
1. Update `RunDiagnostics` in `srcs/server/services/onboarding/diagnostics.go` to accept a boolean `isCloud`.
2. Map the checking logic to use the same directories defined in `CheckEnvironment` in `provisioner.go`.
3. Update `diagnostics_test.go` to match the new behavior.
4. Integrate `RunDiagnostics` inside `RunDayOneSetup` in `dayone.go` as an automated audit step before setting up.
