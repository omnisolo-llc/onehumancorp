# Problem Statement
The KAIROS AI OS architecture needs to be implemented. This requires establishing the Shared Task List using PostgreSQL and SQLite, developing the Teammate Mesh using CentrifugeNode and Redis/Memory transports, and deploying the AutoDream vector data pipelines using pgvector to track state and memory across the swarm.

# Research Report
- Based on `CLAUDE_OHC.md` and OHC Core Values, the orchestration layer requires a durable backend. PostgreSQL `FOR UPDATE SKIP LOCKED` enables safe concurrent task assignment in Cloud Mode, while SQLite transaction isolations handle Standalone Mode.
- Realtime communication depends on WebSockets multiplexed via `CentrifugeNode` and horizontal scaling via Redis Pub/Sub (`mesh:tasks`, `mesh:presence`).
- Memory is managed by the AutoDream pipeline, extracting `.agent-task/memory/*.yml` and injecting pgvector embeddings for nearest-neighbor semantic retrieval.

# Design Doc
**Shared Task List Database Schema:**
```sql
CREATE TABLE IF NOT EXISTS swarm_tasks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    mission_id TEXT NOT NULL,
    parent_plan_id TEXT,
    dependencies JSONB NOT NULL DEFAULT '[]',
    title TEXT NOT NULL,
    status TEXT NOT NULL DEFAULT 'PENDING',
    assigned_agent_id TEXT,
    payload JSONB,
    locked_until TIMESTAMPTZ,
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS state_machine_transitions (
    id TEXT PRIMARY KEY,
    entity_id TEXT NOT NULL,
    entity_type TEXT NOT NULL,
    from_state TEXT NOT NULL,
    to_state TEXT NOT NULL,
    agent_id TEXT,
    reason TEXT,
    occurred_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_sm_entity ON state_machine_transitions(entity_id, entity_type);
```

**Teammate Mesh Architecture:**
- **Transports:** `RedisMeshTransport` (Cloud, production Redis Pub/Sub) and `MemoryMeshTransport` (Standalone).
- **Queueing:** Enqueues jobs via `RedisTaskQueue` or `SQLiteTaskQueue`.
- **APIs:** Implement standard HTTP POSTs and updated gRPC contracts (`srcs/proto/hub.proto`): `AdvertiseCapabilities`, `DiscoverAgents`, `StreamMeshEvents`.

**AutoDream Vector Data Pipeline:**
```sql
CREATE TABLE IF NOT EXISTS consolidated_memory (
    id TEXT PRIMARY KEY,
    organization_id TEXT NOT NULL,
    agent_id TEXT,
    content TEXT NOT NULL,
    embedding vector(1536),
    source_type TEXT NOT NULL,
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX ON consolidated_memory USING hnsw (embedding vector_l2_ops);
```
