# Title: Implement Grafana Observability for Standalone Metric Sync

## Problem Statement
The Standalone Desktop mode now successfully buffers local agent execution telemetry and syncs it to the Cloud DB when online, ensuring full Swarm Intelligence observability. However, this synchronization process is completely invisible in our current Grafana dashboards. Metrics such as `ohc_sync_escalations_total`, `ohc_sync_latency_seconds`, `ohc_sync_payload_size_bytes`, and `ohc_sync_daemon_batch_size` are emitted by the backend but not visualized. This creates a critical observability gap where sync failures, latency spikes, or payload bloat in Standalone mode cannot be monitored or alerted upon.

## Research Report
During a hybrid telemetry audit, an analysis of `srcs/server/telemetry/telemetry.go` revealed the existence of `ohc_sync_*` metrics (e.g., `RecordSyncLatency`, `RecordSyncPayloadSize`). A subsequent search of `deploy/docker/grafana/provisioning/dashboards/` confirmed that these metrics are missing from all provisioned dashboards, including `hybrid-telemetry.json` and `infra-observability.json`.
In Cloud-Native mode, these metrics might be zero, but in Standalone mode, they represent the critical health of the local-to-cloud data bridge. Without visualizing them, we cannot diagnose mode-specific throughput bottlenecks related to telemetry synchronization.

## Design Doc
1. **Dashboard Update:** Modify `deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json` to include a new row or set of panels dedicated to "Standalone Sync Telemetry".
2. **New Panels:**
   - **Sync Latency (P95):** A timeseries panel visualizing `histogram_quantile(0.95, rate(ohc_sync_latency_seconds_bucket[5m]))`.
   - **Sync Payload Size:** A timeseries panel visualizing the average payload size `rate(ohc_sync_payload_size_bytes_sum[5m]) / rate(ohc_sync_payload_size_bytes_count[5m])`.
   - **Sync Batch Size:** A timeseries panel for `ohc_sync_daemon_batch_size`.
   - **Sync Escalations Rate:** A timeseries panel for `rate(ohc_sync_escalations_total[5m])`.
3. **Aesthetics:** Adhere to the Visual Excellence Mandate by using standard OHC Glassmorphism JSON configuration for the new panels where applicable.
