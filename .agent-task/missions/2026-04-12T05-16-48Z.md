# Mission: Shared Task List Decomposition (KAIROS Phase 1)

## Problem Statement
The OHC Agentic OS needs a structured way to decompose complex feature requests into actionable, sequenced tasks. The "Shared Task List" must serve as the durable state machine where multiple agents can claim sub-tasks concurrently without race conditions.

## Research Report
The current Orchestration layer lacks a centralized persistence mechanism for distributed task claiming. Based on `docs/architecture/kairos_hybrid_os_design.md` and `docs/architecture/kairos/shared_task_list_design.md`, we need a robust backend schema. In Cloud-Native mode, we will use PostgreSQL with `FOR UPDATE SKIP LOCKED` for concurrency.

## Design Doc
**Architecture Component:** `Shared Task List` DB Schema
**Target File:** `srcs/server/db/migrations/000007_shared_tasks.up.sql` (increment migration number as needed)

**Schema Definition:**
```sql
CREATE TABLE IF NOT EXISTS shared_tasks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    organization_id VARCHAR NOT NULL,
    title VARCHAR NOT NULL,
    description TEXT,
    status VARCHAR NOT NULL DEFAULT 'PENDING',
    agent_id VARCHAR,
    priority VARCHAR NOT NULL DEFAULT 'P2',
    payload JSONB,
    parent_plan_id TEXT,
    dependencies JSONB NOT NULL DEFAULT '[]',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
```

We also need the Go model definition in `srcs/server/orchestration/models.go` (or similar appropriate location) mapping to this schema.
