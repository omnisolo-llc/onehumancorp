# Title: Team Referral Viral Loop

## Problem Statement
The OHC platform needs a mechanism to track viral growth via team referrals, allowing users to invite others and tracking accepted invites.

## Research Report
Implemented metrics in `lib/analytics` using OpenTelemetry, and referral management logic in `services/growth`.

## Design Doc
1. `lib/analytics/metrics.go` for `RecordInvite` and `RecordInviteAcceptance` metrics.
2. `services/growth/referral.go` for generating and accepting referral codes via UUID.
3. Appropriate tests with >90% coverage for both packages.

## Implementation Prompt
Implement the referral system with UUIDs and connect it to OpenTelemetry metrics.
