# Title: Dynamic Viral Quota & Invite Acceptance

# Problem Statement
We needed to implement a dynamic quota increase loop based on successful team referrals to drive viral growth, and provide an endpoint for users to accept an invite.

# Solution
Added `GetReferralByID` using a Redis reverse index in `referrals_repo.go`. Modified `quota_service.go` to dynamically increase the quota limit by 50 for each successful `SIGNED_UP` referral from the user's `GetStats`. Added the `/api/v1/growth/referrals/accept` endpoint in `apps/growth/main.go` to transition invites to `SIGNED_UP` and trigger the reward.
