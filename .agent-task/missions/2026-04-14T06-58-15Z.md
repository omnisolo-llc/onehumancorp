# Implement Shared Task List and Teammate Mesh

## Problem Statement
The OHC swarm requires a shared task list and real-time teammate mesh to orchestrate complex tasks seamlessly. Currently, there is a lack of structured coordination and memory consolidation, hindering the swarm's ability to act as a unified entity.

## Research Report
Competitive analysis reveals that existing solutions (Claude Code, OpenClaw, Replit Agent) lack a cohesive hybrid approach that allows for both air-gapped local execution and scalable cloud orchestration. OHC's Hybrid Architecture (OHC-HA) provides a unique opportunity to build a "Blue Ocean" feature: Hybrid Local-Private RAG with MCP & SPIRE Cloud Sync. To support this, we must first build the foundational orchestration primitives: the Shared Task List and Teammate Mesh.

## Design Doc
See `docs/architecture/KAIROS_ORCHESTRATION_FEATURES_DESIGN.md` for detailed designs.
Key architectural pillars:
1. **Distributed State Machine (Shared Task List):** Database-backed state machine for `shared_tasks`. Uses Postgres `FOR UPDATE SKIP LOCKED` for cloud, and SQLite with explicit transactions for standalone. Includes `parent_plan_id` to prevent subtask orphaning. Dependencies are tracked via the `dependencies` column (do NOT append parent ID to dependencies to avoid deadlocks).
2. **Teammate Mesh (Real-time Transport):** Unified API (`POST /api/mesh/v2/broadcast`) routing events via Redis Pub/Sub (Cloud) or In-Memory Transport (Standalone).
3. **autoDream Pipeline (Omni-Context Memory):** Background workers consolidating `.agent-task/memory/*.yml` to pgvector (Cloud) or SQLite-VSS (Local).

## Implementation Prompt
Implement the Shared Task List and Teammate Mesh based on the provided design doc (`docs/architecture/KAIROS_ORCHESTRATION_FEATURES_DESIGN.md`).
- Implement the database schemas for both PostgreSQL and SQLite fallbacks. Ensure queries handle JSON arrays correctly using `db.IsSQLite()`.
- Implement the Task Claiming Workflow using explicit transactions and locking mechanisms. Ensure parent IDs are properly assigned to `parent_plan_id` and NOT added to the `dependencies` array.
- Implement the `POST /api/mesh/v2/broadcast` API endpoint.
- Implement the basic structure for the autoDream memory consolidation pipeline.
Ensure all new features degrade gracefully in Standalone Mode and include comprehensive tests.
