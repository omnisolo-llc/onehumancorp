# Title: Implement AutoDream Pipeline Widget in React

## Problem Statement
The Flutter version of the dashboard includes an AutoDreamPipelineWidget, but the React version (`apps/web/src/pages/Dashboard.tsx`) lacks a premium visual representation of this process.

## Design Doc
1. Create `AutoDreamPipelineWidget.tsx` in `apps/web/src/components/orchestration/`.
2. Implement an animated pipeline showing the flow of data from a raw task completion to a vector memory using React and CSS.
3. Integrate it into `apps/web/src/pages/Dashboard.tsx`.
4. Add a test in `apps/web/test/components.test.tsx`.
