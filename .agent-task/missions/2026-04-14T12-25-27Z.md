<h1>Mission: Instrument Core Features with Complete OpenTelemetry Metrics</h1>

<b>Title:</b> Add Missing OpenTelemetry Metrics to Core Swarm Features
<br>
<b>Problem Statement:</b> The KAIROS foundation (`10-02-18Z`), SPIFFE Identity integration (`10-00-00Z`), and CRDT Sync (`10-05-00Z`) features lack complete OpenTelemetry metrics in the core telemetry package. This violates the Full-Spectrum Observability core value.
<br>
<b>Research Report:</b>
1. Existing metrics cover basic operations but not the new identity framework, sync conflicts, or state machine transitions.
2. The `telemetry.go` file needs to be updated with `IdentityVerificationSuccessTotal`, `IdentityVerificationFailureTotal`, `SyncConflictsResolvedTotal`, and `OmniContextBytesRouted`.
3. Grafana dashboards in production rely on these exact metric names.
<br>
<b>Design Doc:</b>
Add the following metric definitions to `srcs/server/telemetry/telemetry.go` and expose methods to increment them:
- `IdentityVerificationSuccessTotal` (`metric.Int64Counter`)
- `IdentityVerificationFailureTotal` (`metric.Int64Counter`)
- `SyncConflictsResolvedTotal` (`metric.Int64Counter`)
- `OmniContextBytesRouted` (`metric.Int64Counter`)
<br>
<b>Implementation Prompt:</b>
Implementer, add the new metrics to `srcs/server/telemetry/telemetry.go`. Initialize them in the `InitWithMeter` function and create wrapper functions `RecordIdentityVerification(ctx context.Context, success bool)`, `RecordSyncConflictResolved(ctx context.Context)`, and `RecordOmniContextBytes(ctx context.Context, bytes int64)`.
<br>
<b>Priority:</b> P0<br>
<b>Estimated Scope:</b> Medium
