# Mission: Teammate Mesh APIs (Orchestration)

**Problem Statement**: Agents require a highly available, low-latency communication layer to coordinate realtime task updates.

**Research Report**:
- Needs to support Pub/Sub models.
- Channels needed: `mesh:tasks`, `mesh:coordination`, `mesh:ultraplan`.

**Design Doc**:
- Cloud Mode: `RedisMeshTransport` via Redis Pub/Sub (`rueidis`).
- Standalone Mode: `MemoryMeshTransport` via local memory bus.

**Implementation Prompt**:
- Implement `MeshTransport` interface in Go with both Redis and In-Memory backends.
- Integrate with `CentrifugeNode` hub.

**Priority**: P0
**Estimated Scope**: Medium
