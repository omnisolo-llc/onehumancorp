# Title: Implement OHC Hybrid CLI Master Menu

## Problem Statement
New developers lack a single unified interactive entry point to navigate the multiple onboarding scripts (`ohc-setup.sh`, `ohc-env-wizard.sh`, `ohc-diagnostics.sh`, etc.), introducing friction to the "Day One" experience.

## Research Report
The OHC Hybrid Architecture (OHC-HA) mandates zero friction and maximum visual delight. An interactive bash wrapper that uses the OHC-SIP premium aesthetic colors will unify the Day One onboarding flow.

## Design Doc
- Create `deploy/scripts/ohc_hybrid_cli.sh`.
- Present a menu with options to run Developer Setup, Configure Environment, Run Diagnostics, Launch Quick Start, and Provision AI Agent.
- Match existing OHC-SIP aesthetic guidelines (e.g., specific ANSI color codes).

## Implementation Prompt
Create a new bash script `deploy/scripts/ohc_hybrid_cli.sh` that provides a `while true` loop for interactive script selection, wrapping the existing tools in `deploy/scripts/`. Ensure it handles user input and runs the correct sub-scripts.
