# Research Report
To support complex workflows, we must implement a centralized Postgres database table to act as a state machine for task decomposition and assignment. The schema must include row-level locking (`FOR UPDATE SKIP LOCKED`) to ensure atomicity.

# Design Doc
See `docs/architecture/kairos_hybrid_os_orchestration_design.md` for full design blueprints and sequence diagrams. The `shared_tasks` table is the source of truth for all complex operations executed by the swarm.
