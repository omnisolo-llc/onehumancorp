# Standalone Metrics Observability Gap

**Priority:** P1
**Estimated Scope:** Medium

## Problem Statement
During the execution of hybrid metric mappings, a secondary observability gap was identified. Several core telemetry functions in `srcs/server/telemetry/telemetry.go` fail to invoke the `BufferMetricFunc` in Standalone mode, leading to data loss when the system operates offline or syncs to the cloud.

## Research Report
A follow-up audit shows the following critical metrics are excluded from the standalone SQLite buffer:
- `RecordTokenBurnRate`
- `RecordTeammateMeshBroadcast`
- `RecordTeammateMeshDirectMessage`
- `RecordSyncEscalation`
- `RecordSyncLatency`
- `RecordSyncPayloadSize`
- `RecordSyncDaemonBatchSize`
- `RecordSwarmTaskTransition`
- `RecordAutoDreamSyncLatency`
- `RecordAutoDreamQueryLatency`
- `RecordMeshBroadcast`
- `RecordMeshLatency`

Without these metrics, Cloud Grafana dashboards will exhibit severe blindspots regarding local Swarm Task state transitions and Mesh sync performance.

## Design Doc
1. **Target Module**: `srcs/server/telemetry/telemetry.go`
2. **Logic Extension**: Update each missing `Record*` function.
3. **Pattern**:
   - Check if `BufferMetricFunc != nil`.
   - Construct a JSON payload using a map of the function's parameters.
   - Apply `RedactInterfacePII` to the payload map.
   - Invoke `BufferMetricFunc(ctx, "metric_name", payloadString)`.
