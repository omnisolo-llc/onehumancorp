# Design Doc: KAIROS AI OS Orchestration

## Architecture
The orchestration layer consists of three core pillars:
1. **Shared Task List**: A durable state machine in PostgreSQL using `FOR UPDATE SKIP LOCKED` to prevent collisions between horizontally scaled worker pods. Degrades to SQLite transactions locally.
2. **Teammate Mesh**: A real-time communication mesh using `CentrifugeNode` and Redis Pub/Sub for agents to broadcast state and coordinate.
3. **AutoDream Pipeline**: A background queue that compresses ephemeral session logs via LLMs and embeds them into `swarm_memory` using `pgvector` for exact semantic search.
