# Title: KAIROS AutoDream Memory Consolidation

## Problem Statement
Long-term episodic memory needs to be embedded and consolidated into pgvector (or pinecone) for intelligent swarm retrieval.

## Research Report
- Ephemeral task logs grow rapidly.
- We must chunk, embed (via OpenAI ada-002 or MiniMax), and store these memories in a vector space during idle "Dream" cycles.

## Design Doc
**Data Pipelines:**
- A background worker (`AutoDreamDaemon`) runs periodically.
- Sweeps `completed` tasks from `shared_tasks`.
- Calls LLM to summarize and generate an embedding vector.
- Stores in `agent_memories` table: `CREATE TABLE agent_memories ( id UUID, embedding vector(1536), content TEXT );`

## Implementation Prompt
Implementer, build the AutoDream pipeline:
1. Create a daemon in `srcs/server/orchestration/autodream.go`.
2. Implement a `Consolidate()` function that batches recent tasks, generates embeddings, and inserts them into pgvector.
3. Write unit tests utilizing a mock LLM client to verify the pipeline logic.
