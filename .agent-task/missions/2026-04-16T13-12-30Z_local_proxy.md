Title: [research] Implement Local Stateful Execution Proxy for Hybrid Agentic OS
Problem Statement: Pure cloud agents lack local context. OHC needs a local proxy to securely execute terminal commands and sync state to the cloud.
Research Report: Claude Code uses local execution efficiently. OHC must merge this with cloud swarm intelligence. See docs/research/hybrid-agentic-os-audit.md for full report.
Design Doc:
1. Architecture: Integrate a local proxy execution component alongside the existing `srcs/server/agents/local_provider.go` to intercept terminal execution requests.
2. Mechanism: Run a local agent provider that listens for execution requests from the cloud Orchestrator, runs them in the local environment securely (via sandbox features developed in Epic 5335), and writes output to the local SQLite SIPDB.
Implementation Prompt:
Implementer:
1. Create a proxy module adjacent to `srcs/server/agents/local_provider.go` that defines a proxy structure for local execution.
2. Implement an execution routing method that receives terminal calls, executes them securely, and syncs the stdout/stderr to local database.
3. Write unit tests for the execution routing logic.
Priority: P1
Estimated Scope: Large
