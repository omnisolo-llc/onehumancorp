# Title: Implement Sub-Agent Orchestration Queue

**Problem Statement:**
KAIROS must spawn, manage, and monitor isolated sub-agents executing background tasks.

**Research Report:**
The queue uses a state-machine driven backend: `sub_agent_queue` table with states QUEUED, RUNNING, COMPLETED, FAILED.

**Design Doc:**
```sql
CREATE TABLE IF NOT EXISTS sub_agent_queue (
    id TEXT PRIMARY KEY,
    organization_id TEXT NOT NULL,
    parent_task_id TEXT NOT NULL,
    payload JSONB,
    status TEXT NOT NULL DEFAULT 'QUEUED',
    worker_id TEXT,
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
```
Workflow: KAIROS pushes a sub-task. Queue Manager polls QUEUED tasks and dispatches to a new sub-agent.
