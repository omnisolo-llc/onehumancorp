# Title: Implement KAIROS Master Orchestration DB and APIs

## Problem Statement
The OHC Swarm requires a robust backend to handle task decomposition, real-time coordination, and long-term memory consolidation as designed by the KAIROS Orchestrator.

## Research Report
The KAIROS Master Orchestration design outlines the need for a `shared_tasks_decomposition` table for task tracking, Redis Pub/Sub channels for the Teammate Mesh, and an `autodream_memories` table with pgvector support for long-term memory.

## Design Doc
See `docs/architecture/KAIROS_HYBRID_AI_OS_MASTER_ORCHESTRATION_DESIGN.md` for the full database schema, sequence diagrams, and Teammate Mesh Redis channel definitions.

## Implementation Prompt
Implement the database migrations for `shared_tasks_decomposition` and `autodream_memories`. Ensure the migrations degrade gracefully to SQLite for standalone mode. Implement the Redis Pub/Sub event emitters for `mesh:events:task_created`, `mesh:events:status_update`, and `mesh:locks:acquire`. Write comprehensive tests ensuring >90% coverage and verifying hybrid fallback compatibility.
