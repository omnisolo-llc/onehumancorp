# Title
KAIROS: AutoDream Data Pipeline Architecture

# Problem Statement
OHC's long-term memory consolidation system, AutoDream, is required to persist architectural insights and agent findings. The system needs data pipelines to generate and store LLM vector embeddings in both Cloud (pgvector) and Standalone modes.

# Research Report
Based on OHC Hybrid Architecture:
- AutoDream requires consolidating `.agent-task/memory/` and Swarm execution logs into vector representations.
- Database schemas must be designed to store these vector embeddings.

# Design Doc
- **Schema**:
    - `autodream_consolidations`: `id`, `source_memory_id`, `vector_embedding`, `summary`, `created_at`.
- The pipeline will periodically process pending raw memories, use an LLM embedding model to create vectors, and store them in `autodream_consolidations` or `swarm_memory_embeddings`.

# Implementation Prompt
- Implement the database migration files for the AutoDream pipeline (`srcs/server/db/migrations/...`).
- Ensure the changes support PostgreSQL (pgvector) and SQLite gracefully.
- Do NOT implement the actual Go backend logic, only output the SQL schema designs as instructed in the orchestrator role.
