# Architect Hybrid MCP RAG Synchronization Protocol

## Problem Statement
RAG states are siloed between local Standalone and Cloud-Native modes.

## Research Report
OHC-HA requires a bridge for long-term memory consistency.

## Design Doc
Design a synchronizer daemon that polls local SQLite 'rag_records' and pushes them to cloud PostgreSQL 'pgvector' indices.

## Implementation Prompt
Implement 'srcs/server/orchestration/hybrid_sync/daemon.go' to manage the local-to-cloud memory synchronization. Use OHC-SIP for state tracking.
