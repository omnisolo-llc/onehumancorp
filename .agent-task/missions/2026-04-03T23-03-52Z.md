# Title: Complete Observability Visualization Gap: Expose Missing Metrics in Grafana

## Problem Statement
The OHC Hybrid Architecture relies heavily on accurate, full-spectrum observability to determine system health across Cloud-Native (Multi-Tenant) and Standalone (Local Desktop) modes. A recent observability gap analysis has identified that while high-fidelity metrics such as `api_rate_limit_exceeded_count`, `ohc_cache_hits_total`, `sync_completed_count`, `sync_failed_count`, and `ohc.sync.escalations.count` are instrumented in the backend (`srcs/server/telemetry/telemetry.go`), they are completely absent from our visual dashboards in Grafana. This creates a critical blind spot for diagnosing cloud escalation and API rate limit bottlenecks in hybrid modes.

## Research Report
- Instrumenting code with Prometheus metrics is only half the observability equation. The OHC core directive requires all features to expose high-fidelity metrics *with corresponding Grafana visualizations*.
- The current `deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json` dashboard lacks queries (`expr`) for newly added rate limit trackers and hybrid sync metrics.
- Missing metrics:
  - `api_rate_limit_exceeded_count` (recently added by Implementer mission `1775164000_proactive_implement_api_rate_limit_metrics.yml`)
  - `sync_completed_count`
  - `sync_failed_count`
  - `ohc.sync.escalations.count`
  - `ohc_cache_hits_total`
  - `ohc_cache_misses_total`

## Design Doc
1. **Target Dashboard**: Modify `deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json`.
2. **New Panels**:
   - **Rate Limits**: Add a Time Series or Stat panel displaying the rate of `api_rate_limit_exceeded_count` (e.g., `rate(api_rate_limit_exceeded_count[5m])`).
   - **Hybrid Sync Health**: Add a panel tracking the success vs failure rate of Standalone-to-Cloud syncs (`rate(sync_completed_count[5m])` vs `rate(sync_failed_count[5m])`).
   - **Sync Escalations**: Add a panel for `rate(ohc.sync.escalations.count[5m])` to track tasks that require cloud escalation.
   - **LLM Cache Efficiency**: Add a panel for `rate(ohc_cache_hits_total[5m])` vs `rate(ohc_cache_misses_total[5m])` to visualize AutoDream/LLM cache efficiency.
