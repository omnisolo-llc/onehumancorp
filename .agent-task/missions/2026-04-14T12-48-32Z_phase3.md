# Research Report
The Swarm Intelligence Protocol dictates that agent memory (`.agent-task/memory/*.yml`) must be consolidated into a searchable Vector DB. We will use PostgreSQL with the `pgvector` extension to build the `autodream_memories` table and provide semantic search.
