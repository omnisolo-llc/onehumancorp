# Title: Prompt Tuning Wizard

## Problem Statement
We need an intuitive way for users to tune prompts without needing prompt-engineering knowledge.
Users should be able to select personality, domain focus, and example interactions to tune an agent.

## Design Protocol
Follow OHC Premium Design Standards: Glassmorphism (`backdrop-filter: blur(20px) saturate(200%)`, `background: rgba(255, 255, 255, 0.03)`), and Outfit/Inter typography.

## Requirements
- Triggered from agent card menu -> "Tune this agent".
- Personality & tone: Radio tiles (Formal / Friendly / Concise / Detailed / Custom).
- Domain focus: Tags/chips (user can pick).
- Example interactions: Up to 3 sample Q&A pairs.
- Live preview: Split-pane showing generated prompt vs chat sandbox.
- Save button: Persists prompt to backend and shows a toast.
