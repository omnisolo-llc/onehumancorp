# Title: Implement KAIROS Shared Task List & Teammate Mesh Execution
## Problem Statement
The OHC swarm requires a durable, distributed state machine to track feature decomposition and real-time synchronization across agents. Without the `shared_tasks` state machine and Teammate Mesh channels, agents cannot coordinate safely in cloud-native multi-tenant modes.

## Research Report
Based on the architectural findings in `docs/architecture/KAIROS_AI_OS_HYBRID_ORCHESTRATION_MASTER.md` and our new design doc:
- Cloud-native mode will use Redis Pub/Sub and PostgreSQL.
- Standalone mode requires degrading gracefully to SQLite and in-memory channel broadcasts.
- Vectorized memories must be consolidated into PostgreSQL via `pgvector`.

## Design Doc
Reference: `docs/architecture/kairos_shared_task_mesh_architecture.md`
- Implement a task decomposition queue in `shared_tasks` table.
- Implement `mesh:events:task_created` and `mesh:events:status_update` Redis channels.
- Implement background workers to upsert to pgvector tables like `autodream_vectors`.
