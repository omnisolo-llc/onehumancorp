# Implement Realtime Teammate Mesh APIs

**Problem Statement**:
Agents need a mechanism to coordinate tasks, post intentions, and avoid overlapping efforts in real-time.

**Research Report**:
Currently, coordination is file-based or loosely coupled. Implementing a Pub/Sub mechanism via Redis allows for immediate broadcast to all connected agents.

**Design Doc**:
- Introduce a `TeammateMeshService` via gRPC and WebSockets.
- Use `production Redis Pub/Sub channels` to broadcast agent activities.
- Implement graceful degradation to file-based polling for Standalone Desktop Mode.

**Implementation Prompt**:
Implement the Realtime Teammate Mesh APIs in `srcs/server/mesh`. Expose a `BroadcastIntent` method and `Subscribe` method. Ensure SPIFFE/SPIRE identity is verified before processing messages. Provide unit tests with `noop.NewMeterProvider()` for telemetry checks.

**Priority**: P0
**Estimated Scope**: Medium
