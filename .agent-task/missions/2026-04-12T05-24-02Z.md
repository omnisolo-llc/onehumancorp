# Title: Add AutoDream Metrics to Hybrid Telemetry Grafana Dashboard

## Problem Statement
An observability gap exists in the OHC Hybrid Architecture telemetry. While AutoDream metrics (`ohc_autodream_memories_ingested_total`, `ohc_autodream_memories_compressed_total`, `ohc_autodream_sync_duration_seconds`, `ohc_autodream_query_duration_seconds`) are correctly instrumented in `srcs/server/telemetry/telemetry.go`, they are missing from the Hybrid Telemetry Grafana dashboard. This obscures the efficiency and latency of RAG memory operations across Cloud and Standalone deployments.

## Research Report
- **Market Context**: Full-spectrum observability is a core value of the OHC-HA architecture, enabling the human orchestrator to self-correct swarm intelligence.
- **OHC Requirement**: The Swarm analytics require full coverage. The file `deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json` currently visualizes general task metrics but completely omits the AutoDream domain.
- **Data Flow**: To bridge this gap, we must append panels to the `hybrid-telemetry.json` dashboard that query the OpenTelemetry Prometheus metrics for AutoDream.

## Design Doc
- **Module Path**: `deploy/docker/grafana/provisioning/dashboards/hybrid-telemetry.json`.
- **Architecture**:
  - Add a new "Row" panel titled "AutoDream Vector Memory (RAG)".
  - Add a "Timeseries" panel plotting `ohc_autodream_memories_ingested_total` and `ohc_autodream_memories_compressed_total`.
  - Add a "Timeseries" panel plotting the duration distributions for `ohc_autodream_sync_duration_seconds` and `ohc_autodream_query_duration_seconds`.
  - All new panels must adhere strictly to the "Premium" visual style (Glassmorphism, transparent backgrounds).
