# 🗺️ Guide: [new onboarding feature] Day One AI Readiness Check

## Problem Statement
The onboarding wizard properly checks for database requirements but misses validating AI provider configurations (e.g., API keys). This can lead to a degraded "Day One" experience if agents boot without intelligence.

## Design Doc
Update `handleWizardOnboardingVerify` in `srcs/server/dashboard/handlers_wizard.go`.
Add a diagnostic check verifying that at least one AI API key (`GEMINI_API_KEY`, `ANTHROPIC_API_KEY`, or `OPENAI_API_KEY`) is present in the environment or configuration. If none exist, append a "missing" status for AI Readiness. Ensure existing tests reflect this change.
