# Title: Observability Gap Analysis: Growth Metrics Dashboard Missing

# Problem Statement:
The `services/growth` service emits several key metrics using OpenTelemetry, including `growth_viral_invite_sent_total`, `growth_viral_invite_accepted_total`, `growth_ab_test_impression_total`, `growth_ab_test_conversion_total`, `ohc_growth_quota_exceeded_total`, and `ohc_growth_quota_usage_incremented_total` as defined in `lib/analytics/growth_metrics.go`. However, an audit of the Grafana dashboards (`deploy/docker/grafana/provisioning/dashboards/`) reveals that these growth-specific metrics are entirely unvisualized. This violates the "Full-Spectrum Observability" core value.

# Research Report:
- The codebase already initializes `go.opentelemetry.io/otel/metric` counters for the above metrics in `lib/analytics/growth_metrics.go`.
- The metrics track essential product-led growth events: viral invites, A/B test funnels, and feature quota limit hits.
- Searches in the `deploy/docker/grafana/provisioning/dashboards/` directory for these metric names yielded no results. We are missing a centralized view for the Growth/Product team to understand platform vitality.

# Design Doc:
1. **Target:** Create a new dashboard definition `deploy/docker/grafana/provisioning/dashboards/growth-vitality.json` and optionally include it in `deploy/helm/ohc/dashboards/growth-vitality.json`.
2. **Panels:**
   - **Viral Invites Funnel:** A panel comparing `growth_viral_invite_sent_total` vs. `growth_viral_invite_accepted_total` as rates to track conversion.
   - **A/B Test Conversions:** A panel charting `growth_ab_test_impression_total` vs `growth_ab_test_conversion_total`.
   - **Quota Exhaustion Warnings:** A time-series or stat panel for `ohc_growth_quota_exceeded_total` to track potential upsell targets.
3. **Aesthetics:** Adhere to the OHC Premium Aesthetic (where applicable in Grafana panel titles and descriptions, keeping them clean and minimal).

# Implementation Prompt:
As an Implementer agent:
1. Create a new file `deploy/docker/grafana/provisioning/dashboards/growth-vitality.json` containing a valid Grafana Dashboard JSON schema.
2. Ensure the dashboard includes PromQL queries for `growth_viral_invite_sent_total`, `growth_viral_invite_accepted_total`, `growth_ab_test_impression_total`, `growth_ab_test_conversion_total`, `ohc_growth_quota_exceeded_total`, and `ohc_growth_quota_usage_incremented_total`.
3. Update `deploy/docker/grafana/provisioning/dashboards/dashboards.yaml` if necessary to ensure the new dashboard is provisioned.
4. Verify the dashboard JSON is syntactically valid.
