<h1>Mission: Implement Hybrid CRDT Sync & Omni-Context Routing</h1>

<b>Title:</b> Advanced Memory Sync and Sub-agent Routing
<b>Problem Statement:</b> The OHC Hybrid Architecture requires a seamless way to synchronize state and route context between Standalone (local) and Cloud-Native (remote) environments. Offline modifications to shared tasks must resolve conflicts gracefully, and sub-agents must receive immediate, high-density context without expensive database round-trips.
<b>Priority:</b> P0
<b>Estimated Scope:</b> Large

<h2>Research Report</h2>
<b>Findings:</b>
1. <b>CRDT Sync:</b> Conflict-free Replicated Data Types (CRDTs) allow for decentralized state resolution. For `shared_tasks`, a State-based CRDT (using LWW-Element-Set) is suitable to handle status updates and description edits across distributed nodes.
2. <b>Omni-Context Routing:</b> Sub-agents are often spawned in isolated environments. Injecting the "Omni-Context" (relevant mission history, system directives, and current task DAG) directly into the environment or via a high-speed gRPC stream significantly reduces "time-to-first-action."
3. <b>Hybrid RAG:</b> Local SQLite vector embeddings (AutoDream) must be synchronized to Cloud pgvector instances to maintain a global "Swarm Truth."

<h2>Design Doc</h2>
<b>1. Hybrid Sync Mechanism (CRDT)</b>
- <b>Schema Update:</b> Add `vector_clock JSONB` and `last_writer_id TEXT` to the `shared_tasks` table.
- <b>Sync Protocol:</b> Implement `CRDTPuller` and `CRDTPusher` as Model Context Protocol (MCP) tools. Agents will use these tools to perform delta-syncs between local and remote stores.

<b>2. Omni-Context Sub-agent Routing</b>
- <b>Context Injection:</b> When spawning a sub-agent (via `SubAgentSpawner`), create an ephemeral `OmniContext` payload containing:
  - Compressed recent memory (from AutoDream).
  - Relevant `AGENTS.md` and `CLAUDE_OHC.md` instructions.
  - Upstream task dependencies.
- <b>Transport:</b> Deliver this via a specialized gRPC method `StreamMeshEvents` on the Teammate Mesh.

<b>3. AutoDream Vector Sync</b>
- <b>Pipeline:</b> A background worker in `srcs/server/orchestration/hybrid_sync/` that watches the `consolidated_memory` table and pushes local embeddings to the remote cloud endpoint using `OHC-SIP` compliance.

<h2>Implementation Prompt</h2>
Implementer, execute the following:
1. <b>CRDT Implementation:</b> Implement a simple LWW (Last-Writer-Wins) CRDT resolver in `srcs/server/orchestration/hybrid_sync/crdt.go`. Apply it to `shared_tasks` updates.
2. <b>Sync Tools:</b> Implement `CRDTPush` and `CRDTPull` endpoints in the Teammate Mesh REST gateway.
3. <b>Omni-Context Injection:</b> Update `srcs/server/orchestration/sub_agent.go`. Modify `SpawnIsolated` to bundle the `OmniContext` payload into the agent's environment variables (base64-encoded) or a temporary mounted file.
4. <b>Telemetry:</b> Record `ohc_sync_conflicts_resolved_total` and `ohc_omni_context_bytes_routed`.
5. <b>Verification:</b> Write a test `srcs/server/orchestration/hybrid_sync/sync_test.go` that simulates a task being modified offline in Standalone mode and successfully synced to a Cloud provider mock.
