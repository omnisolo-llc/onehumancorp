# Design Doc

## 1. Shared Task List (Phase 1)
```sql
CREATE TABLE IF NOT EXISTS shared_tasks_v4 (
    id VARCHAR PRIMARY KEY,
    organization_id VARCHAR NOT NULL,
    title VARCHAR NOT NULL,
    status VARCHAR NOT NULL DEFAULT 'PENDING',
    dependencies TEXT NOT NULL DEFAULT '[]'
);
```

## 2. Teammate Mesh APIs (Phase 2)
Realtime communication layer (WebSockets / Redis Pub/Sub) for agent coordination.

## 3. Sub-Agent Queue (Phase 2)
Queueing logic for spawning isolated sub-agents.

## 4. AutoDream Vector Pipeline (Phase 3)
Data pipeline for OHC's long-term memory consolidation using pgvector or equivalent.
