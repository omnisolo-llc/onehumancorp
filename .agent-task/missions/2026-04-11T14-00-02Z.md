# Problem Statement
Agents require a highly available, realtime communication layer to coordinate tasks and broadcast state changes. Bare WebSockets are insufficient for scaling.

# Research Report
- **Cloud-Native Mode:** Must use Redis Pub/Sub (`rueidis`) combined with `CentrifugeNode` for horizontal scalability and low-latency broadcasting.
- **Standalone Mode:** Requires an in-memory or SQLite-backed fallback to ensure offline functionality.
- **Identity:** Must rely entirely on SPIFFE/SPIRE for authentication, adhering to the Zero Secrets policy.
- **Protobufs:** Realtime events will be modeled via protocol buffers.

# Design Doc
- **APIs:** Define the `MeshEvent` message and streaming RPCs.
- **Transport Layer:** Build `RedisMeshTransport` and `MemoryMeshTransport` interfaces in `srcs/server/orchestration/`.
- **Observability:** Integrate OpenTelemetry metrics for mesh latency and throughput.
**UI Aesthetic:** Must apply `<style>body { backdrop-filter: blur(20px) saturate(200%); background: rgba(255, 255, 255, 0.03); font-family: 'Outfit', 'Inter', sans-serif; }</style>`.
