# Mission: Hybrid MCP RAG Protocol Sync Daemon (Phase 4)

**Problem Statement:** Following Phases 1-3, OHC needs a robust daemon to continuously synchronize the local SQLite state into the cloud Postgres database for scaled computing tasks without exposing raw private datasets.

**Research Report:**
- Competitors fail to provide graceful offline-to-cloud syncs.
- `docs/architecture/oracle_hybrid_rag_master_plan.md` outlines a Local-to-Cloud State Synchronizer.
- We must build this in the `srcs/server/orchestration/` domain.

### Competitive Market Audit

| Feature Area | Claude Code / Replit | OpenClaw | **OHC Vision (Hybrid Sync)** |
| :--- | :--- | :--- | :--- |
| **Local Execution Telemetry** | Ephemeral or non-existent | Fails Offline (Cloud only) | **Persistent Local Buffer (SQLite)** |
| **Cloud Synchronization** | None | Real-time only | **Batched, PII-scrubbed Cloud Sync** |
| **Observability Posture** | Blind spots on local compute | Full visibility, zero privacy | **Full visibility, complete privacy** |

**Design Doc:**
- The daemon should poll the local SQLite `agent_missions` table.
- Tasks requiring cloud escalation should be batched and transmitted to the multi-tenant K8s pods.
