# Implement Shared Task List State Machine

**Problem Statement**:
Complex feature requests need to be decomposed into shared tasks. Without a reliable state machine and distributed locks, agents may duplicate work or fail to complete tasks sequentially.

**Research Report**:
Current workflow relies on simple YAML files. A robust schema (PostgreSQL for cloud, SQLite for desktop) is required. Redis distributed locks are necessary for cloud mode.

**Design Doc**:
- Implement a `Task` struct mapping to a PostgreSQL `tasks` table with `status` enum.
- In Standalone mode, use `SELECT ...` instead of `SELECT FOR UPDATE` to avoid SQLite locking issues.
- Expose a `CreateTask` and `ClaimTask` API.

**Implementation Prompt**:
Please implement the `db.Provider` interface methods for the Shared Task List. Include `ClaimTask(ctx context.Context, taskID string) error`. Use Redis for distributed locking in cloud mode. Create the exact DB schema and migrations. Add >90% test coverage for the new models.
