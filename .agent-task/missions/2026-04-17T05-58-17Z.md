# OHC Mission: Implement Shared Task List, Teammate Mesh, and AutoDream pipelines

**Problem Statement:**
The OHC Agentic OS needs a robust orchestration framework to manage task decomposition, inter-agent communication, and long-term memory consolidation. Without this, swarm intelligence fails as agents clash and context is lost.

**Research Report:**
Based on the architecture defined in `docs/architecture/kairos_shared_task_mesh_queue_orchestration.md` and related design documents, the KAIROS orchestrator depends on three pillars:
1. **Shared Task List Decomposition:** Uses a SQL database (PostgreSQL with `FOR UPDATE SKIP LOCKED` or SQLite) to manage tasks, avoiding collisions via state machines.
2. **Realtime Teammate Mesh APIs:** Uses Redis Pub/Sub (or local Go channels) for low-latency sub-millisecond communication between agents.
3. **AutoDream Data Pipelines:** Converts closed tasks and episodic memories into embeddings stored in a vector database (`pgvector` in PG, JSON blob in SQLite) for semantic recall.
4. **Sub-Agent Queue:** A durable queue for executing scoped background tasks.

**Design Doc:**
- **Shared Task List Schema:** `shared_tasks_decomposition` table (id, organization_id, title, status, etc).
- **Sub-Agent Queue Schema:** `sub_agent_queue` table (id, organization_id, parent_task_id, payload, status, etc).
- **AutoDream Memory Schema:** `autodream_memories` table (id, task_id, embedding, etc).
- **Teammate Mesh API:** `/api/mesh/broadcast` for agent state synchronization.
- **Architectural constraint:** Maintain hybrid consistency, supporting both cloud-native (PostgreSQL/Redis) and Standalone mode (SQLite/local channels).

**Implementation Prompt:**
You are the Implementer agent. Your task is to execute the KAIROS Orchestration plan:
1. Initialize the PostgreSQL / SQLite database schemas for `shared_tasks_decomposition`, `sub_agent_queue`, and `autodream_memories` based on `docs/architecture/kairos_shared_task_mesh_queue_orchestration.md`. Ensure `pgvector` compatibility.
2. Implement the API endpoints for the Realtime Teammate Mesh, specifically the HTTP broadcast endpoint (`POST /api/mesh/broadcast`).

4. Build the AutoDream embedding consolidation worker stub to process completed tasks.
