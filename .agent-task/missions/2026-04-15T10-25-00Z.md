# Title: Phase 8 - Stateful Episodic Memory & LangGraph Checkpointing

## Problem Statement
One Human Corp agents currently suffer from "Agent Amnesia"—the inability to persist complex execution states across disjointed sessions. While AutoDream handles long-term semantic memory, it does not preserve the fine-grained execution graph state required for reliable task resumption and multi-step reasoning recovery. This results in lost progress when sessions are interrupted or when scaling across the Hybrid Architecture.

## Research Report
Market analysis of leading agentic frameworks (Claude Code, CrewAI, AutoGen) identifies "Stateful Checkpointing" as a critical enterprise requirement. By integrating **LangGraph Checkpointing** with a native PostgreSQL backend, OHC can achieve robust cross-session persistence. This leverages the OHC Zero-Lock stack, ensuring that even in Standalone Mode (using SQLite), agents can recover their reasoning context from the `swarm_checkpoints` table.

Key Findings:
- LangGraph's `BaseCheckpointSaver` interface provides the necessary abstraction.
- PostgreSQL `JSONB` with indexing on `thread_id` and `checkpoint_id` is the optimal persistence target.
- Hybrid Mode requires a unified interface that degrades to SQLite transactions in Standalone Mode.

## Design Doc
### 1. Database Schema (PostgreSQL/SQLite)
We require a high-concurrency table to store serialized agent states.

```sql
CREATE TABLE IF NOT EXISTS swarm_checkpoints (
    thread_id TEXT NOT NULL,
    checkpoint_id TEXT NOT NULL,
    parent_id TEXT,
    checkpoint JSONB NOT NULL,
    metadata JSONB DEFAULT '{}',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (thread_id, checkpoint_id)
);

CREATE INDEX idx_checkpoints_thread_parent ON swarm_checkpoints (thread_id, parent_id);
```

### 2. Go Interface & Service
Implement the `Checkpointer` service in `srcs/server/checkpointer/`.

```go
type CheckpointSaver interface {
    GetCheckpoint(ctx context.Context, threadID string) (*Checkpoint, error)
    PutCheckpoint(ctx context.Context, threadID string, checkpoint *Checkpoint) error
    ListCheckpoints(ctx context.Context, threadID string) ([]Checkpoint, error)
}
```

### 3. Hybrid Resilience
- **Cloud Mode**: Concurrent writes managed by PostgreSQL `UPSERT`.
- **Standalone Mode**: SQLite-backed persistence with local mutex coordination.
