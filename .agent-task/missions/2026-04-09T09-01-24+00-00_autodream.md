# Problem Statement
Agents generate vast amounts of session data and memory context. Without a process to consolidate this, agents will quickly exhaust their LLM context windows. We need the "autoDream Data Pipeline" to periodically sweep ephemeral memory, chunk it, embed it, and store it in a long-term vector database.

# Research Report
- Based on `CLAUDE_OHC.md` and KAIROS feature docs, the AutoDream pipeline must support PostgreSQL (via `pgvector`) in Cloud-Native mode and SQLite (with JSON blob fallbacks) in Standalone Desktop mode.
- We need a database schema for `autodream_memories`.

# Design Doc
**Architecture:**
- A background worker (`AutoDreamWorker`) will periodically query `agent_session_data` for sessions that need consolidation.
- It will chunk the data, use the configured LLM to generate summaries and embeddings.
- It will persist the embeddings into `autodream_memories`.

**Database Schema:**
```sql
CREATE EXTENSION IF NOT EXISTS vector;

CREATE TABLE IF NOT EXISTS autodream_memories (
    id TEXT PRIMARY KEY,
    organization_id TEXT NOT NULL,
    agent_id TEXT,
    content TEXT NOT NULL,
    embedding vector(1536), -- JSON text blob in SQLite
    source_type TEXT NOT NULL,
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_autodream_org ON autodream_memories(organization_id);
```

You are an Implementer agent. Your mission is to implement the "autoDream Data Pipeline".
1. Create a database migration for `autodream_memories` in `srcs/server/db/migrations/`. Name it appropriately (e.g., `024_autodream_memories.sql`). Ensure you create distinct statements for Postgres vs SQLite if adding columns.
2. Add the migration to `embedsrcs` in `srcs/server/db/BUILD.bazel`.
3. Implement the worker logic in `srcs/server/orchestration/autodream_worker.go`.
4. The worker should lock the `agent_session_data` row during processing. For Postgres, use `SELECT 1 FROM agent_session_data WHERE session_id = $1 FOR UPDATE SKIP LOCKED`. For SQLite, use local locking logic.
5. Provide unit tests for `autodream_worker.go`. Use `bazelisk test //srcs/server/orchestration/...` to verify your code.
