# Title: Implement SPIFFE-Gated Local-to-Cloud MCP Proxying (Elastic Swarm Bursting)

## Problem Statement
Competitors like Claude Code and Replit Agent operate in isolated environments (pure-local or pure-cloud), lacking seamless hybrid degradation. OHC's unique "Hybrid Agentic OS" requires the ability for a Standalone Desktop agent to securely delegate massive compute tasks to the Cloud-Native Multi-Tenant Postgres/Redis environment without exposing raw private local datasets. Currently, while there is a mechanism to synchronize simple state, OHC lacks a zero-trust, SPIFFE-gated Model Context Protocol (MCP) proxy to safely execute these "Swarm Bursting" payloads across boundaries.

## Research Report
See `docs/research/2026-hybrid-os-benchmark.md` for the full competitive audit and architecture visualization.

## Design Doc
1. **Architecture**:
   - `MCP Proxy Node`: A lightweight gRPC service on the Standalone Desktop that wraps local tools.
   - `Cloud Gateway`: An ingress endpoint in the OHC Cloud that accepts `agent_missions` with `status='CLOUD_ESCALATION'`.
   - **SPIFFE Federation**: The local desktop daemon will securely acquire an SVID. The `Cloud Gateway` authenticates this SVID via `interop.ValidateSPIFFEID`.
2. **Database Flow**:
   - The task is inserted into the local `agent_missions` table with `status='CLOUD_ESCALATION'`.
   - The `Sync Daemon` picks this up and forwards it to the cloud.
   - The cloud executes the task via MCP and writes the result back over the same mTLS-secured tunnel.

## Implementation Prompt
1. Create `srcs/server/orchestration/hybrid_mcp_proxy.go`.
2. Define the `MCPProxy` struct that implements a gRPC stream.
3. In `hybrid_mcp_proxy.go`, implement the `ValidateAndExecute` method:
   - Must extract the SPIFFE SVID from the incoming gRPC context.
   - Must validate the trust domain matches the configured OHC federation.
   - If valid, process the `CLOUD_ESCALATION` mission payload.
4. Add unit tests in `srcs/server/orchestration/hybrid_mcp_proxy_test.go` ensuring 90%+ coverage, testing both valid and invalid SPIFFE SVID rejections.
